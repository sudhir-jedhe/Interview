Show me how to integrate deep key transformation into an API middleware layer or fetch wrapper.

Integrating deep key casing transformation into an API layer allows your JavaScript frontend (which typically operates in `camelCase`) to seamlessly interact with backend services (which often use `snake_case`).

Here is how to set up automatic transformation for both the **Client-Side (Fetch Wrapper)** and the **Server-Side (Express.js Middleware)**.

---

## 1. Client-Side: Fetch Interceptor Wrapper

This custom `fetch` wrapper automatically converts outgoing request body keys to `snake_case` and incoming response body keys to `camelCase`.

```javascript
// Re-using our key transformation functions
const keysToCamelCase = (obj) => deepTransformKeys(obj, toCamelCase);
const keysToSnakeCase = (obj) => deepTransformKeys(obj, toSnakeCase);

async function apiFetch(url, options = {}) {
  const headers = new Headers(options.headers || {});
  let body = options.body;

  // 1. Transform outgoing payload to snake_case if sending JSON
  if (body && typeof body === 'object' && !(body instanceof FormData)) {
    headers.set('Content-Type', 'application/json');
    body = JSON.stringify(keysToSnakeCase(body));
  }

  const response = await fetch(url, {
    ...options,
    headers,
    body,
  });

  // 2. Extract content type
  const contentType = response.headers.get('content-type');

  // Parse error responses gracefully
  if (!response.ok) {
    let errorData = null;
    if (contentType && contentType.includes('application/json')) {
      errorData = keysToCamelCase(await response.json());
    }
    throw new Error(errorData?.message || `HTTP Error: ${response.status}`);
  }

  // 3. Transform incoming response payload to camelCase
  if (contentType && contentType.includes('application/json')) {
    const data = await response.json();
    return keysToCamelCase(data);
  }

  return response;
}

```

### Usage Example

```javascript
// Request sent: { user_id: 101, first_name: "Alice" }
// Response received: { status_code: 200, is_active: true } -> converted to { statusCode: 200, isActive: true }
const userProfile = await apiFetch('/api/users', {
  method: 'POST',
  body: {
    userId: 101,
    firstName: 'Alice'
  }
});

console.log(userProfile.isActive); // true

```

## 2. Server-Side: Express.js Middleware

This Express middleware automatically transforms incoming `req.body` and `req.query` to `camelCase` for clean internal controller usage, and monkey-patches `res.json` so outgoing responses are sent back in `snake_case`.

```javascript
const express = require('express');

const caseTransformationMiddleware = (req, res, next) => {
  // 1. Transform incoming Request Body and Query Params to camelCase
  if (req.body && typeof req.body === 'object') {
    req.body = keysToCamelCase(req.body);
  }
  if (req.query && typeof req.query === 'object') {
    req.query = keysToCamelCase(req.query);
  }

  // 2. Intercept outgoing Response JSON and convert to snake_case
  const originalJson = res.json;

  res.json = function (data) {
    if (data && typeof data === 'object') {
      data = keysToSnakeCase(data);
    }
    return originalJson.call(this, data);
  };

  next();
};

// Application Setup
const app = express();

app.use(express.json()); // Body parser must come first
app.use(caseTransformationMiddleware);

app.post('/api/users', (req, res) => {
  // Access camelCase properties inside controller logic
  const { firstName, lastName } = req.body;
  console.log(`Received: ${firstName} ${lastName}`);

  // Send camelCase object; middleware automatically converts output to snake_case
  res.json({
    userId: 42,
    accountStatus: 'active'
  });
});

```

## 3. Key Operational Considerations

* **Skip Binary & Form Data:** Ensure your transformation logic ignores instances like `FormData`, `Blob`, `Buffer`, or `ArrayBuffer` payloads (e.g., file uploads).
* **Performance Impact:** For very large arrays or huge JSON trees (thousands of nodes), deep recursive tree traversal introduces CPU overhead. If payload performance becomes a bottleneck, consider using faster pre-compiled schemas or specialized npm packages like `camelcase-keys`.

In Axios, you can implement global key-casing transformations by attaching **Axios Interceptors**.

The **Request Interceptor** converts outgoing request payloads to `snake_case` before they leave the browser, and the **Response Interceptor** converts incoming response payloads to `camelCase` before your code receives them.

---

## 1. Setting Up the Axios Instance with Interceptors

```javascript
import axios from 'axios';

// Create a dedicated Axios instance
const apiClient = axios.create({
  baseURL: 'https://api.example.com',
  headers: {
    'Content-Type': 'application/json',
  },
});

// Helper check: Only transform plain objects / arrays (skip FormData, Blob, Buffer, etc.)
const isPlainObjectOrArray = (data) => {
  if (!data || typeof data !== 'object') return false;
  if (data instanceof FormData || data instanceof Blob || data instanceof ArrayBuffer) {
    return false;
  }
  return true;
};

// --- 1. Outgoing Request Interceptor (camelCase -> snake_case) ---
apiClient.interceptors.request.use(
  (config) => {
    if (config.data && isPlainObjectOrArray(config.data)) {
      config.data = keysToSnakeCase(config.data);
    }
    
    // Optional: Convert URL query params as well
    if (config.params && isPlainObjectOrArray(config.params)) {
      config.params = keysToSnakeCase(config.params);
    }

    return config;
  },
  (error) => Promise.reject(error)
);

// --- 2. Incoming Response Interceptor (snake_case -> camelCase) ---
apiClient.interceptors.response.use(
  (response) => {
    if (response.data && isPlainObjectOrArray(response.data)) {
      response.data = keysToCamelCase(response.data);
    }
    return response;
  },
  (error) => {
    // Also convert error payload keys if the server returns JSON errors
    if (error.response?.data && isPlainObjectOrArray(error.response.data)) {
      error.response.data = keysToCamelCase(error.response.data);
    }
    return Promise.reject(error);
  }
);

export default apiClient;

```

---

## 2. Usage Example

When calling API endpoints using `apiClient`, you write all your code using frontend `camelCase` conventions—Axios handles the backend translation transparently:

```javascript
import apiClient from './apiClient';

async function createUser() {
  try {
    // Request payload sent as: { first_name: "John", user_role: "admin" }
    // Query params sent as: ?include_profile_details=true
    const response = await apiClient.post(
      '/users',
      {
        firstName: 'John',
        userRole: 'admin',
      },
      {
        params: { includeProfileDetails: true },
      }
    );

    // Raw server response: { user_id: 101, is_active: true }
    // Transformed response received:
    console.log(response.data.userId);   // 101
    console.log(response.data.isActive); // true
  } catch (error) {
    // Transformed error response received:
    console.error(error.response?.data?.errorMessage);
  }
}

```

## 3. Alternative: `transformRequest` & `transformResponse`

If you prefer not to use interceptors, Axios provides built-in `transformRequest` and `transformResponse` options at the instance level.

```javascript
const apiClient = axios.create({
  baseURL: 'https://api.example.com',
  
  // Runs before sending the request
  transformRequest: [
    (data, headers) => {
      if (data && isPlainObjectOrArray(data)) {
        return JSON.stringify(keysToSnakeCase(data));
      }
      return data;
    },
  ],

  // Runs right after receiving the response
  transformResponse: [
    (data) => {
      if (typeof data === 'string') {
        try {
          data = JSON.parse(data);
        } catch (e) {
          return data; // Return string as-is if not valid JSON
        }
      }
      return isPlainObjectOrArray(data) ? keysToCamelCase(data) : data;
    },
  ],
});

```

### Differences to Keep in Mind

* **Interceptors** run **after** default JSON serialization during requests, and **after** JSON parsing during responses, making them easier to work with raw JavaScript objects.
* **`transformRequest` / `transformResponse**` run **before** Axios handles default JSON parsing/stringification, requiring manual `JSON.stringify` / `JSON.parse` operations inside the transformer array.
