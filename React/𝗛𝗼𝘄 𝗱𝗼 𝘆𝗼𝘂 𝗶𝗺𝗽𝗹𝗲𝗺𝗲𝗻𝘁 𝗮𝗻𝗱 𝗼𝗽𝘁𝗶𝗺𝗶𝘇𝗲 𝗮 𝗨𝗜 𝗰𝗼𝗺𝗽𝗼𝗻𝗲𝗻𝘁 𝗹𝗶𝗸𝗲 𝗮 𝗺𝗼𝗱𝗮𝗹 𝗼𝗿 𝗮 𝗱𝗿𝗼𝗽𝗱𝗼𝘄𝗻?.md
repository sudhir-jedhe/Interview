Building and optimizing interactive overlay components (like modals, dropdowns, and tooltips) requires balancing DOM performance, accessibility (WAI-ARIA), keyboard interactions, and cleanup lifecycles.

---

### 1. The Core Mechanics: Event Delegation, `useRef`, and Closing Events

#### A. Outside-Click Detection (`useRef` vs. Event Delegation)

* **`useRef` (Target Identification):** Holds a reference to the DOM element without triggering re-renders. We check `ref.current.contains(event.target)` to determine whether an interaction occurred inside or outside the container.
* **Event Delegation (Window/Document Listener):** Rather than attaching event listeners to every individual outside element, we attach a single global listener (`pointerdown` or `mousedown`) to the `document` or `window`. When an event bubbles up, the single listener inspects the event's origin.
* **Why `pointerdown` over `click`?** `pointerdown` fires immediately on mouse down, pen contact, or touch before any focus shifts or touch-emulation delays occur, making the dismiss action feel instant.

#### B. Escape Key Handling (`keydown`)

* Modals and dropdowns must close when the user presses `Escape`.
* Listening to `keydown` on `window` guarantees the keypress is intercepted even if focus is on a child element (e.g., an input inside the modal).
* Calling `event.stopPropagation()` on nested overlays ensures only the topmost overlay closes per keypress.

#### C. Focus Trapping & Scroll Locking

* **Focus Management:** When a modal opens, focus must shift into the modal, stay trapped inside while tabbing, and restore to the triggering button when closed.
* **Scroll Locking:** Setting `document.body.style.overflow = 'hidden'` prevents background page scrolling while a modal is mounted.

### 2. Custom Reusable Hook: `useDismissableOverlay`

This reusable hook handles outside clicks, `Escape` key presses, and listener cleanup:

```typescript
import { useEffect, useRef } from 'react';

interface UseDismissableOverlayOptions {
  isOpen: boolean;
  onClose: () => void;
  /** Ignores outside clicks when clicking specific elements like the toggle button */
  ignoreRef?: React.RefObject<HTMLElement | null>;
}

export function useDismissableOverlay<T extends HTMLElement>({
  isOpen,
  onClose,
  ignoreRef,
}: UseDismissableOverlayOptions) {
  const containerRef = useRef<T | null>(null);

  useEffect(() => {
    if (!isOpen) return;

    // 1. Outside Click via Event Delegation
    const handlePointerDown = (event: PointerEvent) => {
      const target = event.target as Node;
      
      // Do nothing if click is inside the overlay or inside the trigger button
      if (
        containerRef.current?.contains(target) ||
        ignoreRef?.current?.contains(target)
      ) {
        return;
      }

      onClose();
    };

    // 2. Escape Key Press Handling
    const handleKeyDown = (event: KeyboardEvent) => {
      if (event.key === 'Escape') {
        event.stopPropagation();
        onClose();
      }
    };

    // Attach delegated listeners
    document.addEventListener('pointerdown', handlePointerDown);
    document.addEventListener('keydown', handleKeyDown);

    // Cleanup listeners when component unmounts or closes
    return () => {
      document.removeEventListener('pointerdown', handlePointerDown);
      document.removeEventListener('keydown', handleKeyDown);
    };
  }, [isOpen, onClose, ignoreRef]);

  return containerRef;
}

```

### 3. Production Dropdown Component Implementation

```tsx
import React, { useState, useRef } from 'react';
import { useDismissableOverlay } from './useDismissableOverlay';

interface DropdownItem {
  id: string;
  label: string;
  onClick: () => void;
}

export const Dropdown: React.FC<{ items: DropdownItem[] }> = ({ items }) => {
  const [isOpen, setIsOpen] = useState(false);
  const triggerRef = useRef<HTMLButtonElement | null>(null);

  const menuRef = useDismissableOverlay<HTMLDivElement>({
    isOpen,
    onClose: () => setIsOpen(false),
    ignoreRef: triggerRef,
  });

  return (
    <div style={{ position: 'relative', display: 'inline-block' }}>
      <button
        ref={triggerRef}
        type="button"
        aria-haspopup="menu"
        aria-expanded={isOpen}
        onClick={() => setIsOpen((prev) => !prev)}
        style={{
          padding: '8px 16px',
          borderRadius: '6px',
          border: '1px solid #cbd5e1',
          background: '#fff',
          cursor: 'pointer',
        }}
      >
        Options {isOpen ? '▲' : '▼'}
      </button>

      {isOpen && (
        <div
          ref={menuRef}
          role="menu"
          tabIndex={-1}
          style={{
            position: 'absolute',
            top: '100%',
            left: 0,
            marginTop: '6px',
            minWidth: '180px',
            backgroundColor: '#ffffff',
            borderRadius: '8px',
            boxShadow: '0 10px 15px -3px rgba(0, 0, 0, 0.1)',
            border: '1px solid #e2e8f0',
            padding: '4px 0',
            zIndex: 50,
          }}
        >
          {items.map((item) => (
            <button
              key={item.id}
              role="menuitem"
              type="button"
              onClick={() => {
                item.onClick();
                setIsOpen(false);
                triggerRef.current?.focus(); // Return focus to trigger
              }}
              style={{
                width: '100%',
                textAlign: 'left',
                padding: '8px 16px',
                border: 'none',
                background: 'transparent',
                cursor: 'pointer',
                fontSize: '14px',
              }}
            >
              {item.label}
            </button>
          ))}
        </div>
      )}
    </div>
  );
};

```

### 4. Production Modal with React Portal & Focus Lock

Modals should render into a **React Portal** (`createPortal`) at `document.body` to avoid clipping caused by parent `overflow: hidden` or `z-index` stacking context traps.

```tsx
import React, { useEffect, useRef } from 'react';
import { createPortal } from 'react-dom';
import { useDismissableOverlay } from './useDismissableOverlay';

interface ModalProps {
  isOpen: boolean;
  onClose: () => void;
  title: string;
  children: React.ReactNode;
}

export const Modal: React.FC<ModalProps> = ({ isOpen, onClose, title, children }) => {
  const modalContentRef = useDismissableOverlay<HTMLDivElement>({
    isOpen,
    onClose,
  });

  const previousActiveElementRef = useRef<HTMLElement | null>(null);

  useEffect(() => {
    if (isOpen) {
      // 1. Store currently focused element to restore upon close
      previousActiveElementRef.current = document.activeElement as HTMLElement;

      // 2. Prevent background body scrolling
      const originalOverflow = document.body.style.overflow;
      document.body.style.overflow = 'hidden';

      // 3. Shift focus to modal container
      modalContentRef.current?.focus();

      return () => {
        document.body.style.overflow = originalOverflow;
        // Restore focus to triggering button
        previousActiveElementRef.current?.focus();
      };
    }
  }, [isOpen, modalContentRef]);

  if (!isOpen) return null;

  return createPortal(
    <div
      role="presentation"
      style={{
        position: 'fixed',
        inset: 0,
        backgroundColor: 'rgba(15, 23, 42, 0.65)',
        backdropFilter: 'blur(2px)',
        display: 'flex',
        alignItems: 'center',
        justifyContent: 'center',
        zIndex: 9999,
      }}
    >
      <div
        ref={modalContentRef}
        role="dialog"
        aria-modal="true"
        aria-labelledby="modal-headline"
        tabIndex={-1}
        style={{
          backgroundColor: '#ffffff',
          borderRadius: '12px',
          width: '100%',
          maxWidth: '480px',
          padding: '24px',
          boxShadow: '0 25px 50px -12px rgba(0, 0, 0, 0.25)',
          outline: 'none',
        }}
      >
        <div style={{ display: 'flex', justifyContent: 'space-between', marginBottom: '16px' }}>
          <h3 id="modal-headline" style={{ margin: 0, fontSize: '18px' }}>
            {title}
          </h3>
          <button
            type="button"
            onClick={onClose}
            aria-label="Close modal"
            style={{ border: 'none', background: 'transparent', cursor: 'pointer', fontSize: '16px' }}
          >
            ✕
          </button>
        </div>

        <div>{children}</div>
      </div>
    </div>,
    document.body
  );
};

```

### 5. Performance Optimizations for Overlays

1. **Passive Event Listeners:**
When using event listeners on scroll/pointer events, use `{ passive: true }` if you do not call `event.preventDefault()`, which prevents blocking the browser's compositor thread.
2. **Conditional Mounting vs. CSS Toggling:**
Unmount overlay children when closed (`if (!isOpen) return null;`) rather than hiding via `display: none` to release memory, detach DOM subtrees, and stop unnecessary internal re-renders.
3. **GPU Layer Acceleration:**
Apply `transform: translate3d(0, 0, 0)` or `will-change: transform, opacity` to backdrop and modal transition animations so opening transitions render at 60fps on the GPU without triggering browser reflows/repaints.
4. **Portal Stacking & Layering:**
Rendering into `document.body` via `createPortal` decouples the overlay from parent DOM trees, bypassing ancestor CSS rules like `transform`, `filter`, or `contain` that create isolated stacking contexts and break fixed-position elements.
