- How would you handle large data sets efficiently in a table with client- or server-side filtering?
- Discuss how to modularize the table headers, pagination, and rows.

Building a filterable, sortable, and paginated data table component is a core Frontend Low-Level Design (LLD) challenge. It tests your mastery over **data architecture, performance optimization at scale, component modularization, and URL-driven state synchronization**.

Below is a complete design and implementation guide.

---

# 1. Architectural Strategy: Client-Side vs. Server-Side

```text
                               ┌─────────────────────────┐
                               │       Data Volume       │
                               └────────────┬────────────┘
                                            │
                  ┌─────────────────────────┴─────────────────────────┐
                  ▼                                                   ▼
        Small/Medium (< 5,000 items)                         Large (> 5,000+ items)
      ┌──────────────────────────────┐                   ┌──────────────────────────────┐
      │     Client-Side Data Table   │                   │     Server-Side Data Table   │
      ├──────────────────────────────┤                   ├──────────────────────────────┤
      │ • Fetch entire dataset once  │                   │ • Fetch 1 page at a time     │
      │ • Filter/Sort in JS memory   │                   │ • Send search, sort & page   │
      │ • Instant zero-latency UI    │                   │   params in API query string │
      └──────────────────────────────┘                   └──────────────────────────────┘

```

| Feature               | Client-Side Engine                                                | Server-Side Engine                                                                             |
| --------------------- | ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Data Fetching**     | Single fetch on mount or background refresh.                      | Re-fetch triggered on every page, filter, or sort change.                                      |
| **Filtering/Sorting** | Executed in-memory via JS array methods (`.filter()`, `.sort()`). | Executed by Database SQL/NoSQL engine (`WHERE`, `ORDER BY`, `LIMIT/OFFSET`).                   |
| **URL Sync**          | Optional.                                                         | **Essential.** Query params (`?page=2&sortBy=name&order=asc&search=john`) enable deep-linking. |
| **Best Used For**     | Dashboards, admin tools with finite records.                      | Enterprise search, analytics logs, e-commerce product catalogs.                                |

# 2. Modular Component Architecture

To prevent creating a massive monolithic `DataTable.tsx` component, divide the design into five single-responsibility sub-components:

```text
 <DataTableContainer /> (Handles State / API / URL Sync)
    ├── <TableSearchFilter /> (Debounced Search Input)
    └── <Table />
          ├── <TableHeader /> (Sort Icons & Column Headers)
          ├── <TableBody />
          │     └── <TableRow /> (Data Rendering & Custom Cell Renderers)
          └── <TablePagination /> (Page Controls & Items-Per-Page Selector)

```

### B. Custom Hook: Client-Side Table Engine (`useDataTable.ts`)

This custom hook encapsulates all filtering, sorting, and pagination logic, memoizing results so heavy processing only runs when state actually changes.

```typescript
import { useState, useMemo } from 'react';
import { ColumnDef, TableState, SortDirection } from './table.types';

export function useDataTable<T extends Record<string, any>>(
  data: T[],
  columns: ColumnDef<T>[],
  initialPageSize = 10
) {
  const [state, setState] = useState<TableState<T>>({
    searchQuery: '',
    sortColumn: null,
    sortDirection: null,
    currentPage: 1,
    pageSize: initialPageSize,
  });

  // 1. Filter Data
  const filteredData = useMemo(() => {
    if (!state.searchQuery.trim()) return data;

    const query = state.searchQuery.toLowerCase();
    return data.filter((row) =>
      Object.values(row).some((value) =>
        String(value).toLowerCase().includes(query)
      )
    );
  }, [data, state.searchQuery]);

  // 2. Sort Data
  const sortedData = useMemo(() => {
    if (!state.sortColumn || !state.sortDirection) return filteredData;

    const { sortColumn, sortDirection } = state;

    return [...filteredData].sort((a, b) => {
      const aVal = a[sortColumn];
      const bVal = b[sortColumn];

      if (aVal === bVal) return 0;
      if (aVal === null || aVal === undefined) return 1;
      if (bVal === null || bVal === undefined) return -1;

      const comparison = String(aVal).localeCompare(String(bVal), undefined, {
        numeric: true,
      });

      return sortDirection === 'asc' ? comparison : -comparison;
    });
  }, [filteredData, state.sortColumn, state.sortDirection]);

  // 3. Paginate Data
  const paginatedData = useMemo(() => {
    const startIndex = (state.currentPage - 1) * state.pageSize;
    return sortedData.slice(startIndex, startIndex + state.pageSize);
  }, [sortedData, state.currentPage, state.pageSize]);

  const totalPages = Math.ceil(sortedData.length / state.pageSize) || 1;

  // Actions
  const handleSearch = (query: string) => {
    setState((prev) => ({ ...prev, searchQuery: query, currentPage: 1 }));
  };

  const handleSort = (columnKey: keyof T | string) => {
    setState((prev) => {
      let newDirection: SortDirection = 'asc';

      if (prev.sortColumn === columnKey) {
        if (prev.sortDirection === 'asc') newDirection = 'desc';
        else if (prev.sortDirection === 'desc') newDirection = null;
      }

      return {
        ...prev,
        sortColumn: newDirection ? columnKey : null,
        sortDirection: newDirection,
        currentPage: 1,
      };
    });
  };

  const setPage = (page: number) => {
    setState((prev) => ({
      ...prev,
      currentPage: Math.max(1, Math.min(page, totalPages)),
    }));
  };

  const setPageSize = (size: number) => {
    setState((prev) => ({ ...prev, pageSize: size, currentPage: 1 }));
  };

  return {
    state,
    paginatedData,
    totalRecords: sortedData.length,
    totalPages,
    handleSearch,
    handleSort,
    setPage,
    setPageSize,
  };
}

```

### C. Sub-Components (Modular Headers, Pagination, Search)

#### 1. Search Bar with Debouncing (`TableSearchFilter.tsx`)

Prevents excessive re-renders on every keystroke.

```tsx
import React, { useState, useEffect } from 'react';

interface Props {
  onSearch: (query: string) => void;
  debounceMs?: number;
}

export const TableSearchFilter: React.FC<Props> = ({ onSearch, debounceMs = 300 }) => {
  const [value, setValue] = useState('');

  useEffect(() => {
    const handler = setTimeout(() => onSearch(value), debounceMs);
    return () => clearTimeout(handler);
  }, [value, onSearch, debounceMs]);

  return (
    <input
      type="text"
      value={value}
      onChange={(e) => setValue(e.target.value)}
      placeholder="Search records..."
      style={{ padding: '8px 12px', width: '250px', marginBottom: '16px' }}
    />
  );
};

```

#### 2. Modular Table Header (`TableHeader.tsx`)

```tsx
import React from 'react';
import { ColumnDef, SortDirection } from './table.types';

interface HeaderProps<T> {
  columns: ColumnDef<T>[];
  sortColumn: keyof T | string | null;
  sortDirection: SortDirection;
  onSort: (key: keyof T | string) => void;
}

export function TableHeader<T>({
  columns,
  sortColumn,
  sortDirection,
  onSort,
}: HeaderProps<T>) {
  return (
    <thead>
      <tr style={{ backgroundColor: '#f1f5f9', borderBottom: '2px solid #e2e8f0' }}>
        {columns.map((col) => {
          const isSorted = sortColumn === col.key;
          return (
            <th
              key={String(col.key)}
              onClick={() => col.sortable && onSort(col.key)}
              style={{
                padding: '12px',
                textAlign: 'left',
                cursor: col.sortable ? 'pointer' : 'default',
                userSelect: 'none',
              }}
            >
              {col.header}
              {col.sortable && (
                <span style={{ marginLeft: '6px', fontSize: '12px' }}>
                  {isSorted ? (sortDirection === 'asc' ? '▲' : '▼') : '↕'}
                </span>
              )}
            </th>
          );
        })}
      </tr>
    </thead>
  );
}
```

#### 3. Modular Table Pagination (`TablePagination.tsx`)

```tsx
import React from 'react';

interface PaginationProps {
  currentPage: number;
  totalPages: number;
  pageSize: number;
  totalRecords: number;
  onPageChange: (page: number) => void;
  onPageSizeChange: (size: number) => void;
}

export const TablePagination: React.FC<PaginationProps> = ({
  currentPage,
  totalPages,
  pageSize,
  totalRecords,
  onPageChange,
  onPageSizeChange,
}) => {
  return (
    <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginTop: '16px' }}>
      <span style={{ fontSize: '14px', color: '#64748b' }}>
        Showing {totalRecords === 0 ? 0 : (currentPage - 1) * pageSize + 1} to{' '}
        {Math.min(currentPage * pageSize, totalRecords)} of {totalRecords} records
      </span>

      <div style={{ display: 'flex', gap: '8px', alignItems: 'center' }}>
        <select
          value={pageSize}
          onChange={(e) => onPageSizeChange(Number(e.target.value))}
          style={{ padding: '6px' }}
        >
          {[10, 25, 50, 100].map((size) => (
            <option key={size} value={size}>
              {size} per page
            </option>
          ))}
        </select>

        <button onClick={() => onPageChange(currentPage - 1)} disabled={currentPage === 1}>
          Previous
        </button>
        <span style={{ fontSize: '14px' }}>
          Page {currentPage} of {totalPages}
        </span>
        <button onClick={() => onPageChange(currentPage + 1)} disabled={currentPage === totalPages}>
          Next
        </button>
      </div>
    </div>
  );
};
```

### D. Assembling the Main Data Table Container Component (`DataTable.tsx`)

```tsx
import React from 'react';
import { ColumnDef } from './table.types';
import { useDataTable } from './useDataTable';
import { TableSearchFilter } from './TableSearchFilter';
import { TableHeader } from './TableHeader';
import { TablePagination } from './TablePagination';

interface DataTableProps<T> {
  data: T[];
  columns: ColumnDef<T>[];
  initialPageSize?: number;
}

export function DataTable<T extends Record<string, any>>({
  data,
  columns,
  initialPageSize = 10,
}: DataTableProps<T>) {
  const {
    state,
    paginatedData,
    totalRecords,
    totalPages,
    handleSearch,
    handleSort,
    setPage,
    setPageSize,
  } = useDataTable(data, columns, initialPageSize);

  return (
    <div style={{ width: '100%', overflowX: 'auto' }}>
      <TableSearchFilter onSearch={handleSearch} />

      <table style={{ width: '100%', borderCollapse: 'collapse', textAlign: 'left' }}>
        <TableHeader
          columns={columns}
          sortColumn={state.sortColumn}
          sortDirection={state.sortDirection}
          onSort={handleSort}
        />
        <tbody>
          {paginatedData.length === 0 ? (
            <tr>
              <td colSpan={columns.length} style={{ padding: '24px', textAlign: 'center' }}>
                No records found.
              </td>
            </tr>
          ) : (
            paginatedData.map((row, rowIndex) => (
              <tr key={row.id || rowIndex} style={{ borderBottom: '1px solid #e2e8f0' }}>
                {columns.map((col) => (
                  <td key={String(col.key)} style={{ padding: '12px' }}>
                    {col.render ? col.render(row) : String(row[col.key] ?? '')}
                  </td>
                ))}
              </tr>
            ))
          )}
        </tbody>
      </table>

      <TablePagination
        currentPage={state.currentPage}
        totalPages={totalPages}
        pageSize={state.pageSize}
        totalRecords={totalRecords}
        onPageChange={setPage}
        onPageSizeChange={setPageSize}
      />
    </div>
  );
}

```

# Key Performance & LLD Optimization Checklist

1. **Memoization:** Wrap row data transformations in `useMemo()` inside custom hooks so sorting or filtering 10,000 records doesn't re-run unless relevant state variables change.
2. **Debounced Search Input:** Debouncing search input prevents state updates on every keypress, saving CPU cycles.
3. **DOM Virtualization for Extreme Datasets:** If client-side rendering exceeds $1,000+$ DOM rows simultaneously without pagination, integrate `react-window` or `TanStack Table` to virtualize table body rows.
