Designing a responsive, production-ready sidebar navigation component (like those found in modern dashboards or SaaS products) requires addressing **mobile vs. desktop layout shifts, accessible submenu toggling, smooth CSS/framer-motion animations, and active route highlighting**.

Below is a complete System Design and Low-Level Design (LLD) breakdown, followed by a full production TypeScript and React implementation.

---

# 1. Responsiveness Strategy & Architecture

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │                              VIEWPORT                                  │
 ├────────────────────────────────────┬───────────────────────────────────┤
 │        DESKTOP (≥ 768px)           │           MOBILE (< 768px)        │
 ├────────────────────────────────────┼───────────────────────────────────┤
 │ • Fixed/Sticky Sidebar             │ • Off-canvas Sliding Drawer       │
 │ • Expanded (250px) OR              │ • Triggered via Hamburger Button  │
 │   Collapsed Icon-Only (64px)       │ • Rendered via React Portal       │
 │ • Permanent DOM Presence           │ • Backdrop overlay dims background│
 └────────────────────────────────────┴───────────────────────────────────┘

```

### Key Architectural Decisions

1. **Avoid Conditional Rendering for Layout Shifts:**

* **Anti-Pattern:** Using JS window-resize listeners (`window.innerWidth < 768`) to conditionally unmount the desktop sidebar and mount the mobile drawer causes layout thrashing and hydrations bugs in Server-Side Rendering (SSR) frameworks like Next.js.
- **Best Practice:** Keep the same DOM structure and toggle layout states using **CSS Media Queries** and **CSS Variables** or utility classes (e.g., Tailwind `md:block hidden`).

1. **Mobile Overlay via React Portals:**
When open on mobile screens, render the sidebar backdrop and off-canvas drawer via `createPortal(..., document.body)` so `z-index` stacking contexts or `overflow: hidden` rules on parent layout containers never clip the mobile navigation drawer.
2. **Accessibility (a11y) & Keyboard Navigation:**

* Use `<nav>` semantic markup.
- Bind `aria-expanded` and `aria-controls` to collapsible submenus.
- Close the mobile drawer on `Escape` key press or when the user navigates to a new route.

### Step 2: Recursive Sidebar Item Component (`SidebarItem.tsx`)

Handles recursive rendering of multi-level submenus, collapse animations, and active state route matching.

```tsx
import React, { useState, useEffect } from 'react';
import { NavItem } from './sidebar.types';

interface SidebarItemProps {
  item: NavItem;
  activePath: string;
  onNavigate: (path: string) => void;
  isSidebarCollapsed: boolean;
  depth?: number;
}

export const SidebarItem: React.FC<SidebarItemProps> = ({
  item,
  activePath,
  onNavigate,
  isSidebarCollapsed,
  depth = 0,
}) => {
  const hasChildren = Boolean(item.children && item.children.length > 0);
  
  // Check if current path or any nested child path matches active route
  const isChildActive = (nodes?: NavItem[]): boolean => {
    if (!nodes) return false;
    return nodes.some((child) => child.path === activePath || isChildActive(child.children));
  };

  const isActive = item.path === activePath;
  const isParentOfActive = isChildActive(item.children);

  // Auto-expand submenu if a child route is active
  const [isOpen, setIsOpen] = useState<boolean>(isParentOfActive);

  useEffect(() => {
    if (isParentOfActive) {
      setIsOpen(true);
    }
  }, [isParentOfActive, activePath]);

  const handleClick = () => {
    if (hasChildren) {
      // Toggle submenu open/close if icon-only mode is inactive
      if (!isSidebarCollapsed) {
        setIsOpen((prev) => !prev);
      }
    } else if (item.path) {
      onNavigate(item.path);
    }
  };

  return (
    <li className="sidebar-item-container">
      <button
        onClick={handleClick}
        className={`sidebar-link ${isActive ? 'active' : ''} ${isParentOfActive ? 'child-active' : ''}`}
        style={{ paddingLeft: `${depth * 16 + 12}px` }}
        aria-expanded={hasChildren ? isOpen : undefined}
      >
        <span className="sidebar-icon">{item.icon || '•'}</span>
        
        {/* Hide label text when sidebar is in collapsed icon-only mode */}
        {!isSidebarCollapsed && (
          <span className="sidebar-label">{item.label}</span>
        )}

        {hasChildren && !isSidebarCollapsed && (
          <span className={`sidebar-arrow ${isOpen ? 'open' : ''}`}>
            ▾
          </span>
        )}
      </button>

      {/* SUBMENU ANIMATED TOGGLE */}
      {hasChildren && !isSidebarCollapsed && (
        <div className={`submenu-wrapper ${isOpen ? 'expanded' : 'collapsed'}`}>
          <ul className="submenu-list">
            {item.children!.map((child) => (
              <SidebarItem
                key={child.id}
                item={child}
                activePath={activePath}
                onNavigate={onNavigate}
                isSidebarCollapsed={isSidebarCollapsed}
                depth={depth + 1}
              />
            ))}
          </ul>
        </div>
      )}
    </li>
  );
};

```

### Step 3: Main Responsive Sidebar Component (`Sidebar.tsx`)

Combines Desktop Collapsible Sidebar and Mobile Off-Canvas Drawer with Backdrop Portal.

```tsx
import React, { useState, useEffect } from 'react';
import { createPortal } from 'react-dom';
import { SidebarProps } from './sidebar.types';
import { SidebarItem } from './SidebarItem';

export const ResponsiveSidebar: React.FC<SidebarProps> = ({
  navConfig,
  activePath,
  onNavigate,
}) => {
  // State for Desktop Sidebar Collapse (Expanded: 250px vs Collapsed: 64px)
  const [isDesktopCollapsed, setIsDesktopCollapsed] = useState(false);

  // State for Mobile Drawer Open/Close
  const [isMobileOpen, setIsMobileOpen] = useState(false);

  // Close mobile drawer on route change
  const handleNavigate = (path: string) => {
    onNavigate(path);
    setIsMobileOpen(false);
  };

  // Close mobile drawer when pressing ESC key
  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'Escape' && isMobileOpen) {
        setIsMobileOpen(false);
      }
    };
    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, [isMobileOpen]);

  const sidebarContent = (
    <aside
      className={`sidebar-root ${
        isDesktopCollapsed ? 'desktop-collapsed' : 'desktop-expanded'
      } ${isMobileOpen ? 'mobile-open' : ''}`}
    >
      {/* Header / Brand Logo */}
      <div className="sidebar-header">
        {!isDesktopCollapsed && <span className="brand-title">Dashboard</span>}
        <button
          className="collapse-toggle-btn desktop-only"
          onClick={() => setIsDesktopCollapsed(!isDesktopCollapsed)}
          aria-label="Toggle Sidebar Collapse"
        >
          {isDesktopCollapsed ? '➔' : ''}
        </button>
      </div>

      {/* Navigation List */}
      <nav className="sidebar-nav">
        <ul>
          {navConfig.map((item) => (
            <SidebarItem
              key={item.id}
              item={item}
              activePath={activePath}
              onNavigate={handleNavigate}
              isSidebarCollapsed={isDesktopCollapsed}
            />
          ))}
        </ul>
      </nav>
    </aside>
  );

  return (
    <>
      {/* Mobile Top Navigation Bar with Hamburger Toggle */}
      <header className="mobile-header mobile-only">
        <button
          className="hamburger-btn"
          onClick={() => setIsMobileOpen(true)}
          aria-label="Open Navigation Menu"
        >
          ☰
        </button>
        <span className="brand-title">Dashboard</span>
      </header>

      {/* Main Sidebar Render */}
      <div className="sidebar-wrapper">
        {sidebarContent}

        {/* Mobile Backdrop Overlay (Rendered via Portal) */}
        {isMobileOpen &&
          createPortal(
            <div
              className="mobile-backdrop mobile-only"
              onClick={() => setIsMobileOpen(false)}
              aria-hidden="true"
            />,
            document.body
          )}
      </div>
    </>
  );
};

```

# Key Interview Takeaways

1. **Zero Layout Shift (CLS):** Media queries shift the sidebar off-screen on mobile viewports without forcing React to unmount component trees.
2. **Smooth Collapsible Submenus:** Uses the CSS Grid `grid-template-rows: 0fr` to `1fr` transition trick, avoiding fixed `max-height` hacks for dynamic heights.
3. **Route Auto-Expand:** The `useEffect` hook inspects child routes and automatically expands parent submenus when navigating directly to a deep URL path.
