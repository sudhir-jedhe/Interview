 What are Context-Locked Action Tokens?
Context-Locked Action Tokens are temporary security tokens that work only for one specific action and one specific request.

The token is connected to:
 👉 The action
 👉 The user session
 👉 The device
 👉 The request details

💡 Why do websites use it?
 👉 To stop stolen tokens from being reused
 👉 To protect important actions
 👉 To stop request changes
 👉 To improve application security

💡 Where is it used?
 👉 Bank transfers
 👉 Payment confirmation
 👉 Password changes
 👉 Updating account details
 👉 Adding a new beneficiary

Example Token context_token: "ctx_8a7b6c_secure"
