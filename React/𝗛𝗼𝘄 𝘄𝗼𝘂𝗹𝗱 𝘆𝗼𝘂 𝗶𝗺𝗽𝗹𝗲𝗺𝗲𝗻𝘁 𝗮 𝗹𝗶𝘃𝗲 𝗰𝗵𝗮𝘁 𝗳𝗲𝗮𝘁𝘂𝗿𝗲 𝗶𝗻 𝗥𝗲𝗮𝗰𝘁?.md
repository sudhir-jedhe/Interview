Building a production-ready **Live Chat feature** in React involves choosing the right communication protocol, managing real-time chat state, rendering auto-scrolling message streams, and handling transient states like typing indicators and message delivery statuses.

Below is a complete Low-Level Design (LLD) breakdown and production implementation.

---

# 1. Real-Time Communication Strategy

```text
               ┌────────────────────────────────────────────────┐
               │         Communication Protocol Options         │
               └───────────────────────┬────────────────────────┘
                                       │
            ┌──────────────────────────┴──────────────────────────┐
            ▼                                                     ▼
     1. WebSockets (Socket.io / WS)                       2. Long Polling / SSE
  ┌─────────────────────────────────────┐               ┌─────────────────────────────────────┐
  │ • Full-duplex bidirectional stream  │               │ • Unidirectional or HTTP request loop│
  │ • Instant delivery (< 20ms)         │               │ • High server load / request latency│
  │ • Supports typing indicators & presence│            │ • Simple to set up behind firewalls │
  └─────────────────────────────────────┘               └─────────────────────────────────────┘

```

| Feature              | WebSockets / Socket.io (Recommended)                                                                     | Long Polling / SSE                                                                                        |
| -------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Data Flow**        | **Full-Duplex:** Client and server send/receive data simultaneously over a single persistent TCP socket. | **Half-Duplex:** Client continuously re-establishes HTTP connections to poll for new messages.            |
| **Latency**          | **Near Zero ($< 20\text{ms}$):** Ideal for instant messaging, typing indicators, and online presence.    | **High ($500\text{ms} - 2,000\text{ms}$):** Polling overhead creates delays and wastes network bandwidth. |
| **Transient Events** | Native support for transient events (e.g., `user_typing`, `user_online`).                                | Impractical for high-frequency events like typing indicators due to HTTP request overhead.                |

# 2. State & Transient Status Mechanics

To prevent lag and state corruption in a busy chat room, separate **Persistent Message State** from **Transient UI States**:

```text
 ┌────────────────────────────────────────────────────────┐
 │                      Chat State                        │
 ├────────────────────────────┬───────────────────────────┤
 │  Persistent State          │  Transient State          │
 │  • Messages Array          │  • Typing Users Set       │
 │  • Message Delivery Status │  • Online/Offline Status  │
 │    ('sending'|'sent'|'failed')│  • Connection Retry Count │
 └────────────────────────────┴───────────────────────────┘

```

1. **Typing Status Debouncing:** When a user types, emit `typing_start` immediately, but debounce `typing_stop` by $1.5 - 2\text{ seconds}$ after the last keystroke.
2. **Auto-Scrolling:** Automatically scroll the chat container to the bottom *only* if the user is already near the bottom. If they scroll up to read history, refrain from snapping them back down when new messages arrive.
3. **Optimistic Message Delivery:** Append outgoing messages to the local message array immediately with a `status: 'sending'` flag. Update to `status: 'sent'` or `status: 'failed'` based on server acknowledgment.

### B. Custom Hook: WebSocket Chat Manager (`useLiveChat.ts`)

Encapsulates WebSocket connection lifecycle, message sending, typing status debouncing, and auto-scrolling logic.

```typescript
import { useState, useEffect, useRef, useCallback } from 'react';
import { io, Socket } from 'socket.io-client';
import { ChatMessage } from './chat.types';

const SOCKET_SERVER_URL = 'http://localhost:4000';

export function useLiveChat(roomId: string, currentUser: { id: string; name: string }) {
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [typingUsers, setTypingUsers] = useState<Set<string>>(new Set());
  const [isConnected, setIsConnected] = useState<boolean>(false);

  const socketRef = useRef<Socket | null>(null);
  const typingTimeoutRef = useRef<NodeJS.Timeout | null>(null);

  // Initialize Socket Connection
  useEffect(() => {
    const socket = io(SOCKET_SERVER_URL, {
      query: { roomId, userId: currentUser.id },
      transports: ['websocket'],
    });

    socketRef.current = socket;

    socket.on('connect', () => setIsConnected(true));
    socket.on('disconnect', () => setIsConnected(false));

    // Listen for incoming messages from server
    socket.on('receive_message', (newMessage: ChatMessage) => {
      setMessages((prev) => {
        // Prevent duplicates if message was optimistically added locally
        const exists = prev.some((m) => m.id === newMessage.id);
        if (exists) {
          return prev.map((m) => (m.id === newMessage.id ? { ...newMessage, status: 'sent' } : m));
        }
        return [...prev, { ...newMessage, status: 'sent' }];
      });
    });

    // Listen for typing events
    socket.on('user_typing_status', ({ userId, userName, isTyping }) => {
      if (userId === currentUser.id) return;

      setTypingUsers((prev) => {
        const updated = new Set(prev);
        if (isTyping) {
          updated.add(userName);
        } else {
          updated.delete(userName);
        }
        return updated;
      });
    });

    return () => {
      socket.disconnect();
    };
  }, [roomId, currentUser.id]);

  // Send Message with Optimistic UI Update
  const sendMessage = useCallback(
    (text: string) => {
      if (!text.trim() || !socketRef.current) return;

      const tempId = `msg_${Date.now()}_${Math.random().toString(36).substr(2, 4)}`;

      const optimisticMessage: ChatMessage = {
        id: tempId,
        senderId: currentUser.id,
        senderName: currentUser.name,
        text,
        timestamp: new Date().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' }),
        status: 'sending',
      };

      // 1. Optimistically append message to local UI
      setMessages((prev) => [...prev, optimisticMessage]);

      // 2. Stop typing indicator immediately upon sending
      emitTypingStatus(false);

      // 3. Emit message to WebSocket server with acknowledgment callback
      socketRef.current.emit('send_message', optimisticMessage, (response: { success: boolean }) => {
        setMessages((prev) =>
          prev.map((m) =>
            m.id === tempId
              ? { ...m, status: response.success ? 'sent' : 'failed' }
              : m
          )
        );
      });
    },
    [currentUser]
  );

  // Handle Typing Indicator with Debouncing
  const emitTypingStatus = (isTyping: boolean) => {
    if (!socketRef.current) return;
    socketRef.current.emit('typing', {
      roomId,
      userId: currentUser.id,
      userName: currentUser.name,
      isTyping,
    });
  };

  const handleInputChange = () => {
    emitTypingStatus(true);

    // Debounce stopping typing indicator after 1.5 seconds of inactivity
    if (typingTimeoutRef.current) clearTimeout(typingTimeoutRef.current);

    typingTimeoutRef.current = setTimeout(() => {
      emitTypingStatus(false);
    }, 1500);
  };

  return {
    messages,
    typingUsers: Array.from(typingUsers),
    isConnected,
    sendMessage,
    handleInputChange,
  };
}

```

### C. Live Chat UI Component (`LiveChat.tsx`)

Handles rendering, user interactions, and auto-scrolling behavior.

```tsx
import React, { useState, useRef, useEffect } from 'react';
import { useLiveChat } from './useLiveChat';

interface LiveChatProps {
  roomId: string;
  currentUser: { id: string; name: string };
}

export const LiveChat: React.FC<LiveChatProps> = ({ roomId, currentUser }) => {
  const { messages, typingUsers, isConnected, sendMessage, handleInputChange } = useLiveChat(
    roomId,
    currentUser
  );

  const [inputText, setInputText] = useState('');
  const messagesEndRef = useRef<HTMLDivElement | null>(null);

  // Auto-scroll to bottom when new messages arrive
  const scrollToBottom = () => {
    messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' });
  };

  useEffect(() => {
    scrollToBottom();
  }, [messages, typingUsers]);

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (!inputText.trim()) return;

    sendMessage(inputText);
    setInputText('');
  };

  return (
    <div
      style={{
        width: '400px',
        height: '550px',
        border: '1px solid #cbd5e1',
        borderRadius: '12px',
        display: 'flex',
        flexDirection: 'column',
        boxShadow: '0 4px 12px rgba(0,0,0,0.1)',
        backgroundColor: '#ffffff',
      }}
    >
      {/* Header */}
      <div
        style={{
          padding: '12px 16px',
          borderBottom: '1px solid #e2e8f0',
          display: 'flex',
          justifyContent: 'space-between',
          alignItems: 'center',
          backgroundColor: '#f8fafc',
          borderTopLeftRadius: '12px',
          borderTopRightRadius: '12px',
        }}
      >
        <strong style={{ fontSize: '16px' }}>Room: {roomId}</strong>
        <span
          style={{
            fontSize: '12px',
            color: isConnected ? '#16a34a' : '#dc2626',
            fontWeight: 600,
          }}
        >
          {isConnected ? '🟢 Connected' : '🔴 Disconnected'}
        </span>
      </div>

      {/* Message List Stream */}
      <div
        style={{
          flex: 1,
          padding: '16px',
          overflowY: 'auto',
          display: 'flex',
          flexDirection: 'column',
          gap: '10px',
        }}
      >
        {messages.map((msg) => {
          const isMe = msg.senderId === currentUser.id;

          return (
            <div
              key={msg.id}
              style={{
                alignSelf: isMe ? 'flex-end' : 'flex-start',
                maxWidth: '75%',
              }}
            >
              <div
                style={{
                  fontSize: '11px',
                  color: '#64748b',
                  marginBottom: '2px',
                  textAlign: isMe ? 'right' : 'left',
                }}
              >
                {msg.senderName} • {msg.timestamp}
              </div>

              <div
                style={{
                  padding: '10px 14px',
                  borderRadius: '16px',
                  backgroundColor: isMe ? '#3b82f6' : '#f1f5f9',
                  color: isMe ? '#ffffff' : '#0f172a',
                  borderBottomRightRadius: isMe ? '2px' : '16px',
                  borderBottomLeftRadius: isMe ? '16px' : '2px',
                  wordBreak: 'break-word',
                }}
              >
                {msg.text}
              </div>

              {/* Status Indicator */}
              {isMe && (
                <div
                  style={{
                    fontSize: '10px',
                    textAlign: 'right',
                    color: msg.status === 'failed' ? '#ef4444' : '#94a3b8',
                    marginTop: '2px',
                  }}
                >
                  {msg.status === 'sending' && '⏳ Sending...'}
                  {msg.status === 'sent' && '✓ Sent'}
                  {msg.status === 'failed' && '✖ Failed'}
                </div>
              )}
            </div>
          );
        })}

        {/* Dynamic Typing Indicator */}
        {typingUsers.length > 0 && (
          <div
            style={{
              fontSize: '12px',
              fontStyle: 'italic',
              color: '#64748b',
              marginTop: '4px',
            }}
          >
            💬 {typingUsers.join(', ')} {typingUsers.length === 1 ? 'is' : 'are'} typing...
          </div>
        )}

        <div ref={messagesEndRef} />
      </div>

      {/* Input Form */}
      <form
        onSubmit={handleSubmit}
        style={{
          padding: '12px',
          borderTop: '1px solid #e2e8f0',
          display: 'flex',
          gap: '8px',
        }}
      >
        <input
          type="text"
          value={inputText}
          onChange={(e) => {
            setInputText(e.target.value);
            handleInputChange();
          }}
          placeholder="Type a message..."
          style={{
            flex: 1,
            padding: '8px 12px',
            borderRadius: '20px',
            border: '1px solid #cbd5e1',
            outline: 'none',
          }}
        />
        <button
          type="submit"
          disabled={!isConnected}
          style={{
            padding: '8px 16px',
            borderRadius: '20px',
            border: 'none',
            backgroundColor: '#3b82f6',
            color: '#ffffff',
            fontWeight: 600,
            cursor: 'pointer',
            opacity: isConnected ? 1 : 0.5,
          }}
        >
          Send
        </button>
      </form>
    </div>
  );
};

```

# Key Interview Takeaways

1. **Optimistic Updates:** Outgoing messages appear instantly on the UI with a `sending` status badge before the server acknowledges receipt.
2. **Debounced Typing Indicator:** Eliminates unnecessary WebSocket chatter by debouncing `typing_stop` events using a timer (`1,500ms`).
3. **Auto-Scroll Behavior:** Integrates a `messagesEndRef` that automatically scrolls the chat container to show new incoming messages.
