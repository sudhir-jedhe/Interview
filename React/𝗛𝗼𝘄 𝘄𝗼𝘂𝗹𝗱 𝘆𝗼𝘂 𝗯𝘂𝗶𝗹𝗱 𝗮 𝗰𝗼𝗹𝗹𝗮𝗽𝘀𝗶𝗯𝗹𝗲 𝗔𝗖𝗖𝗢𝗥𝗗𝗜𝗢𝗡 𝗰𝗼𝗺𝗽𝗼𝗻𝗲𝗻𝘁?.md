Designing a production-ready **Accordion Component** in React involves managing single vs. multiple expanded states, delivering smooth CSS height transition animations without layout glitches, and strictly adhering to WAI-ARIA keyboard accessibility standards.

Below is a complete Low-Level Design (LLD) breakdown and production TypeScript implementation.

---

# 1. State Model & Expansion Behavior

An accordion should flexible enough to support both expansion modes:

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │                        Accordion Expansion Modes                       │
 ├────────────────────────────────────┬───────────────────────────────────┤
 │     Single-Active (Default)        │       Multiple-Active             │
 ├────────────────────────────────────┼───────────────────────────────────┤
 │ • `allowMultiple = false`          │ • `allowMultiple = true`          │
 │ • State: `string | null`           │ • State: `Set<string>` or `Array` │
 │ • Opening Section A automatically  │ • Sections expand/collapse        │
 │   collapses Section B.             │   independently of each other.    │
 └────────────────────────────────────┴───────────────────────────────────┘

```

### Key Architectural Decisions

1. **State Normalization:** Internal state is best tracked using a `Set<string>` or array of section IDs regardless of mode. When `allowMultiple` is `false`, the set simply contains at most one item.
2. **Smooth CSS Grid Auto-Height Animations:** Animating CSS `height` from `0` to `auto` traditionally requires dirty JavaScript DOM measurements (`scrollHeight`). Modern CSS avoids this using **CSS Grid (`grid-template-rows: 0fr` $\rightarrow$ `1fr`)**, which provides pure 60fps animations without JavaScript layout recalculations.
3. **WAI-ARIA Accordion Pattern:**

* Header buttons use `aria-expanded="true|false"` and `aria-controls="panel-id"`.
- Panel elements use `role="region"` and `aria-labelledby="button-id"`.
- Full keyboard support: `ArrowDown`, `ArrowUp`, `Home`, and `End` keys navigate focus seamlessly across accordion headers.

### Step 2: Main Accordion Component (`Accordion.tsx`)

```tsx
import React, { useState, useRef, useCallback } from 'react';
import { AccordionProps } from './accordion.types';

export const Accordion: React.FC<AccordionProps> = ({
  items,
  allowMultiple = false,
  defaultExpandedIds = [],
  onChange,
}) => {
  const [expandedIds, setExpandedIds] = useState<Set<string>>(
    new Set(defaultExpandedIds)
  );

  const headerRefs = useRef<Map<string, HTMLButtonElement>>(new Map());

  // Toggle Section Expansion
  const toggleItem = useCallback(
    (id: string) => {
      setExpandedIds((prev) => {
        const next = new Set(prev);

        if (next.has(id)) {
          next.delete(id);
        } else {
          if (!allowMultiple) {
            next.clear(); // Clear all other sections in single-active mode
          }
          next.add(id);
        }

        onChange?.(Array.from(next));
        return next;
      });
    },
    [allowMultiple, onChange]
  );

  // WAI-ARIA Keyboard Navigation
  const handleKeyDown = (e: React.KeyboardEvent, index: number) => {
    const enabledItems = items.filter((item) => !item.disabled);
    const currentIndex = enabledItems.findIndex((item) => item.id === items[index].id);

    let nextItem: (typeof items)[0] | undefined;

    if (e.key === 'ArrowDown') {
      nextItem = enabledItems[(currentIndex + 1) % enabledItems.length];
    } else if (e.key === 'ArrowUp') {
      nextItem = enabledItems[(currentIndex - 1 + enabledItems.length) % enabledItems.length];
    } else if (e.key === 'Home') {
      nextItem = enabledItems[0];
    } else if (e.key === 'End') {
      nextItem = enabledItems[enabledItems.length - 1];
    }

    if (nextItem) {
      e.preventDefault();
      headerRefs.current.get(nextItem.id)?.focus();
    }
  };

  return (
    <div className="accordion-root" style={{ width: '100%', maxWidth: '600px' }}>
      {items.map((item, index) => {
        const isExpanded = expandedIds.has(item.id);
        const buttonId = `accordion-btn-${item.id}`;
        const panelId = `accordion-panel-${item.id}`;

        return (
          <div
            key={item.id}
            className="accordion-item"
            style={{
              borderBottom: '1px solid #e2e8f0',
              overflow: 'hidden',
            }}
          >
            {/* ACCORDION HEADER BUTTON */}
            <h3>
              <button
                id={buttonId}
                ref={(el) => {
                  if (el) headerRefs.current.set(item.id, el);
                  else headerRefs.current.delete(item.id);
                }}
                type="button"
                aria-expanded={isExpanded}
                aria-controls={panelId}
                disabled={item.disabled}
                onClick={() => toggleItem(item.id)}
                onKeyDown={(e) => handleKeyDown(e, index)}
                style={{
                  width: '100%',
                  display: 'flex',
                  justifyContent: 'space-between',
                  alignItems: 'center',
                  padding: '16px',
                  background: 'none',
                  border: 'none',
                  fontSize: '16px',
                  fontWeight: 600,
                  color: item.disabled ? '#94a3b8' : '#0f172a',
                  cursor: item.disabled ? 'not-allowed' : 'pointer',
                  textAlign: 'left',
                }}
              >
                <span>{item.title}</span>
                <span
                  style={{
                    transform: isExpanded ? 'rotate(180deg)' : 'rotate(0deg)',
                    transition: 'transform 0.25s ease',
                    fontSize: '12px',
                  }}
                >
                  ▼
                </span>
              </button>
            </h3>

            {/* ACCORDION CONTENT PANEL (Animated via CSS Grid) */}
            <div
              id={panelId}
              role="region"
              aria-labelledby={buttonId}
              className={`accordion-panel-wrapper ${isExpanded ? 'expanded' : 'collapsed'}`}
              style={{
                display: 'grid',
                transition: 'grid-template-rows 0.3s cubic-bezier(0.4, 0, 0.2, 1)',
              }}
            >
              <div style={{ overflow: 'hidden' }}>
                <div style={{ padding: '0 16px 16px 16px', color: '#475569', fontSize: '14px', lineHeight: '1.6' }}>
                  {item.content}
                </div>
              </div>
            </div>
          </div>
        );
      })}
    </div>
  );
};

```

# Key LLD Takeaways

1. **Pure CSS Auto-Height Animation:** Uses the `grid-template-rows: 0fr` to `1fr` transition trick to smoothly animate variable content heights without relying on JS layout measurements or expensive DOM reflows.
2. **Keyboard Navigation (WAI-ARIA):** Full support for `ArrowUp`/`ArrowDown`, `Home`, and `End` keys lets keyboard-only users navigate between accordion headers naturally.
3. **Flexible State Normalization:** Toggling between `allowMultiple = true` and `allowMultiple = false` requires zero component rewrite because state internally manages a normalized `Set<string>`.
