Here is a clean, accessible **Hamburger Toggle Menu** built with React, Lucide icons, and Tailwind CSS. It handles open/close states, animated icon transitions, click-outside detection, and keyboard accessibility (Escape key to close).

---

### Animated Hamburger Menu Component

```jsx
import React, { useState, useRef, useEffect } from 'react';
import { Menu, X, Home, Info, Briefcase, Mail, ChevronRight } from 'lucide-react';

const MENU_ITEMS = [
  { label: 'Home', href: '#home', icon: Home },
  { label: 'About', href: '#about', icon: Info },
  { label: 'Services', href: '#services', icon: Briefcase },
  { label: 'Contact', href: '#contact', icon: Mail },
];

export default function HamburgerMenu() {
  const [isOpen, setIsOpen] = useState(false);
  const menuRef = useRef(null);

  const toggleMenu = () => setIsOpen((prev) => !prev);
  const closeMenu = () => setIsOpen(false);

  // Close menu when clicking outside
  useEffect(() => {
    const handleClickOutside = (event) => {
      if (menuRef.current && !menuRef.current.contains(event.target)) {
        closeMenu();
      }
    };
    document.addEventListener('mousedown', handleClickOutside);
    return () => document.removeEventListener('mousedown', handleClickOutside);
  }, []);

  // Close menu on ESC key press
  useEffect(() => {
    const handleKeyDown = (event) => {
      if (event.key === 'Escape') closeMenu();
    };
    document.addEventListener('keydown', handleKeyDown);
    return () => document.removeEventListener('keydown', handleKeyDown);
  }, []);

  return (
    <nav ref={menuRef} className="relative font-sans">
      {/* --- Hamburger Trigger Button --- */}
      <button
        type="button"
        onClick={toggleMenu}
        aria-expanded={isOpen}
        aria-label={isOpen ? 'Close menu' : 'Open menu'}
        className="p-2.5 text-gray-700 bg-white border border-gray-200 rounded-lg shadow-sm hover:bg-gray-50 focus:outline-none focus:ring-2 focus:ring-indigo-500 transition-all"
      >
        <div className="relative w-6 h-6 flex items-center justify-center">
          {/* Animated Icon Swap */}
          <Menu
            className={`w-6 h-6 absolute transition-all duration-300 transform ${
              isOpen ? 'rotate-90 opacity-0 scale-75' : 'rotate-0 opacity-100 scale-100'
            }`}
          />
          <X
            className={`w-6 h-6 absolute transition-all duration-300 transform ${
              isOpen ? 'rotate-0 opacity-100 scale-100' : '-rotate-90 opacity-0 scale-75'
            }`}
          />
        </div>
      </button>

      {/* --- Dropdown / Slide Menu --- */}
      {isOpen && (
        <div className="absolute right-0 mt-2 w-56 bg-white border border-gray-100 rounded-xl shadow-xl py-2 z-50 animate-in fade-in zoom-in-95 duration-150">
          <ul className="space-y-1 px-1.5">
            {MENU_ITEMS.map((item) => {
              const Icon = item.icon;
              return (
                <li key={item.label}>
                  <a
                    href={item.href}
                    onClick={closeMenu}
                    className="flex items-center justify-between px-3 py-2 text-sm text-gray-700 rounded-lg hover:bg-indigo-50 hover:text-indigo-600 font-medium transition-colors group"
                  >
                    <div className="flex items-center gap-2.5">
                      <Icon className="w-4 h-4 text-gray-400 group-hover:text-indigo-600 transition-colors" />
                      <span>{item.label}</span>
                    </div>
                    <ChevronRight className="w-3.5 h-3.5 text-gray-300 group-hover:text-indigo-400 transition-colors" />
                  </a>
                </li>
              );
            })}
          </ul>
        </div>
      )}
    </nav>
  );
}

```

### Pure CSS Animated Hamburger (Alternative)

If you prefer a classic CSS-animated 3-line hamburger morphing into an **X** without swapping icons:

```jsx
function AnimatedCSSHamburger({ isOpen, onClick }) {
  return (
    <button
      onClick={onClick}
      aria-expanded={isOpen}
      aria-label="Toggle menu"
      className="p-3 bg-white border rounded-lg shadow-sm focus:outline-none focus:ring-2 focus:ring-indigo-500"
    >
      <div className="w-5 h-4 relative flex flex-col justify-between">
        <span
          className={`w-full h-0.5 bg-gray-800 rounded transition-all duration-300 origin-top-left ${
            isOpen ? 'rotate-45 translate-x-1 -translate-y-0.5' : ''
          }`}
        />
        <span
          className={`w-full h-0.5 bg-gray-800 rounded transition-all duration-200 ${
```

### Features Included

* **Accessibility (a11y)**: Uses `aria-expanded` and `aria-label` attributes to inform screen readers of menu state.
* **Click Outside & ESC Key**: Automatically closes the menu when clicking elsewhere on the page or pressing Escape.
* **Smooth Transitions**: Uses Tailwind CSS transitions for smooth rotation and fade-in animations.

How do I animate this hamburger menu opening and closing using Framer Motion?

Using **Framer Motion** allows you to animate two main elements smoothly:

1. **The Hamburger Button**: Morphing the 3 lines into an "X" icon with rotation and path transitions.
2. **The Dropdown / Drawer Menu**: Animating the container scaling or sliding in while staggering each child menu item sequentially.

---

### Complete Component with Framer Motion

```jsx
import React, { useState, useRef, useEffect } from 'react';
import { motion, AnimatePresence } from 'framer-motion';
import { Home, Info, Briefcase, Mail, ChevronRight } from 'lucide-react';

const MENU_ITEMS = [
  { label: 'Home', href: '#home', icon: Home },
  { label: 'About', href: '#about', icon: Info },
  { label: 'Services', href: '#services', icon: Briefcase },
  { label: 'Contact', href: '#contact', icon: Mail },
];

// --- FRAMER MOTION VARIANTS ---
const menuVariants = {
  closed: {
    opacity: 0,
    scale: 0.95,
    y: -10,
    transition: {
      duration: 0.15,
      ease: 'easeIn',
      when: 'afterChildren', // Finish animating children before closing container
    },
  },
  open: {
    opacity: 1,
    scale: 1,
    y: 0,
    transition: {
      duration: 0.2,
      ease: 'easeOut',
      staggerChildren: 0.05, // Staggers each menu item by 50ms
      delayChildren: 0.05,
    },
  },
};

const itemVariants = {
  closed: { opacity: 0, x: -12 },
  open: { opacity: 1, x: 0 },
};

export default function AnimatedFramerMenu() {
  const [isOpen, setIsOpen] = useState(false);
  const menuRef = useRef(null);

  const toggleMenu = () => setIsOpen((prev) => !prev);
  const closeMenu = () => setIsOpen(false);

  // Close on Click Outside
  useEffect(() => {
    const handleClickOutside = (e) => {
      if (menuRef.current && !menuRef.current.contains(e.target)) {
        closeMenu();
      }
    };
    document.addEventListener('mousedown', handleClickOutside);
    return () => document.removeEventListener('mousedown', handleClickOutside);
  }, []);

  // Close on Escape Key
  useEffect(() => {
    const handleKeyDown = (e) => {
      if (e.key === 'Escape') closeMenu();
    };
    document.addEventListener('keydown', handleKeyDown);
    return () => document.removeEventListener('keydown', handleKeyDown);
  }, []);

  return (
    <nav ref={menuRef} className="relative inline-block text-left font-sans">
      
      {/* --- MORPHING HAMBURGER BUTTON --- */}
      <button
        type="button"
        onClick={toggleMenu}
        aria-expanded={isOpen}
        aria-label="Toggle navigation menu"
        className="p-3 bg-white border border-gray-200 rounded-xl shadow-sm hover:bg-gray-50 focus:outline-none focus:ring-2 focus:ring-indigo-500 transition"
      >
        <div className="w-5 h-4 flex flex-col justify-between relative">
          {/* Top Line -> Top diagonal of X */}
          <motion.span
            animate={isOpen ? { rotate: 45, y: 7 } : { rotate: 0, y: 0 }}
            transition={{ duration: 0.25, ease: 'easeInOut' }}
            className="w-full h-0.5 bg-gray-800 rounded-full block origin-center"
          />

          {/* Middle Line -> Fades out */}
          <motion.span
            animate={isOpen ? { opacity: 0, scaleX: 0 } : { opacity: 1, scaleX: 1 }}
            transition={{ duration: 0.15 }}
            className="w-full h-0.5 bg-gray-800 rounded-full block"
          />

          {/* Bottom Line -> Bottom diagonal of X */}
          <motion.span
            animate={isOpen ? { rotate: -45, y: -7 } : { rotate: 0, y: 0 }}
            transition={{ duration: 0.25, ease: 'easeInOut' }}
            className="w-full h-0.5 bg-gray-800 rounded-full block origin-center"
          />
        </div>
      </button>

      {/* --- ANIMATED DROPDOWN MENU --- */}
      <AnimatePresence>
        {isOpen && (
          <motion.div
            variants={menuVariants}
            initial="closed"
            animate="open"
            exit="closed"
            className="absolute right-0 mt-2 w-56 bg-white border border-gray-100 rounded-xl shadow-xl py-2 z-50 origin-top-right"
          >
            <ul className="space-y-1 px-1.5">
              {MENU_ITEMS.map((item) => {
                const Icon = item.icon;
                return (
                  <motion.li key={item.label} variants={itemVariants}>
                    <a
                      href={item.href}
                      onClick={closeMenu}
                      className="flex items-center justify-between px-3 py-2 text-sm text-gray-700 rounded-lg hover:bg-indigo-50 hover:text-indigo-600 font-medium transition-colors group"
                    >
                      <div className="flex items-center gap-2.5">
                        <Icon className="w-4 h-4 text-gray-400 group-hover:text-indigo-600 transition-colors" />
                        <span>{item.label}</span>
                      </div>
                      <ChevronRight className="w-3.5 h-3.5 text-gray-300 group-hover:text-indigo-400 transition-colors" />
                    </a>
                  </motion.li>
                );
              })}
            </ul>
          </motion.div>
        )}
      </AnimatePresence>
    </nav>
  );
}

```

---

### Key Animation Features Added

1. **`AnimatePresence`**: Required for exit animations. It ensures that when `isOpen` turns `false`, Framer Motion plays the `closed` variant before unmounting the element from the DOM.
2. **Morphing Lines**: The three `motion.span` elements calculate smooth rotational physics to convert seamlessly into a centered "X" without needing separate SVG icon swaps.
3. **Staggered Children (`staggerChildren`)**: Setting `staggerChildren: 0.05` on `menuVariants` causes each list item (`motion.li`) to cascade into view one by one.
