The **HTML DOM (Document Object Model)** is an object-oriented, tree-based representation of an HTML document created by the browser during parsing. The **DOM API** is the programming interface (exposed through JavaScript) that allows developers to dynamically inspect, manipulate, add, delete, and style HTML elements and handle user interactions in real time.

---

## 1. The DOM Tree Structure

When the browser loads an HTML document, it builds a tree hierarchy of **Nodes**:

```text
               window
                 │
              document (Document Node)
                 │
               <html> (Element Node: Root)
         ┌───────┴───────┐
      <head>           <body>
         │               │
      <title>        ┌───┴───────────┐
         │          <h1>           <a> (Element Node)
   "My Page"         │               │
  (Text Node)  "Welcome"       "Click Here" (Text Node)
              (Text Node)   [href="..."] (Attribute Node)

```

### Primary Node Types

* **Document Node (`Node.DOCUMENT_NODE`):** The entry point to the entire DOM tree (`document`).
* **Element Node (`Node.ELEMENT_NODE`):** HTML tags like `<div>`, `<h1>`, or `<p>`.
* **Text Node (`Node.TEXT_NODE`):** The actual text contained inside HTML tags.
* **Attribute Node (`Node.ATTRIBUTE_NODE`):** Attributes like `id`, `class`, or `src` attached to elements.
* **Comment Node (`Node.COMMENT_NODE`):** HTML comments (`<!-- comment -->`).

## 2. Core DOM API Methods & Properties

### A. Selecting Elements

```javascript
// 1. Query Selectors (Modern & Standard)
const singleEl = document.querySelector(".btn-primary"); // First matching element
const allEls   = document.querySelectorAll("div.card");  // Returns NodeList

// 2. Legacy Selectors (Fast live collections)
const byId    = document.getElementById("main-header");  // Element or null
const byClass = document.getElementsByClassName("box");  // Returns HTMLCollection
const byTag   = document.getElementsByTagName("p");      // Returns HTMLCollection

```

### B. Creating, Inserting & Removing Elements

```javascript
// 1. Create a new element
const newCard = document.createElement("div");
newCard.className = "card";
newCard.textContent = "Hello, DOM!";

// 2. Append or Insert into DOM
const container = document.querySelector("#container");
container.appendChild(newCard); // Append to bottom

// Modern placement with insertAdjacentHTML / insertAdjacentElement
container.insertAdjacentHTML("beforeend", "<p>Inserted inline</p>");

// 3. Remove an element
newCard.remove(); // Removes itself directly
// Legacy alternative: container.removeChild(newCard);

```

### C. Modifying Attributes, Classes & Styles

```javascript
const btn = document.querySelector("#submit-btn");

// 1. Classes (classList API)
btn.classList.add("active");
btn.classList.remove("disabled");
btn.classList.toggle("highlight");
console.log(btn.classList.contains("active")); // true

// 2. Attributes (getAttribute / setAttribute / dataset)
btn.setAttribute("disabled", "true");
console.log(btn.getAttribute("type")); // "button"
btn.dataset.userId = "42"; // Modifies data-user-id="42"

// 3. Inline Styles
btn.style.backgroundColor = "blue";
btn.style.fontSize = "16px";

```

### D. Tree Traversal

```javascript
const card = document.querySelector(".card");

// Parent / Children Navigation
console.log(card.parentElement);       // Direct parent Element
console.log(card.children);            // HTMLCollection of child Elements
console.log(card.firstElementChild);   // First child Element
console.log(card.lastElementChild);    // Last child Element

// Sibling Navigation
console.log(card.previousElementSibling); // Sibling before card
console.log(card.nextElementSibling);     // Sibling after card

```

## 3. DOM Events & Event Delegation

The DOM API allows listening to user events (clicks, keypresses, input changes) using `.addEventListener()`.

### Propagation Phase (Bubbling vs Capturing)

1. **Capturing Phase:** Event trickles down from `window` $\rightarrow$ `document` $\rightarrow$ target element.
2. **Target Phase:** Event reaches the targeted element.
3. **Bubbling Phase:** Event bubbles back up from target element $\rightarrow$ `document` $\rightarrow$ `window`.

```javascript
// Example: Event Delegation (Listening on a parent container)
const listContainer = document.querySelector("#todo-list");

listContainer.addEventListener("click", (event) => {
  // Check if click target matches specific child item
  if (event.target.matches("button.delete-btn")) {
    const listItem = event.target.closest("li");
    listItem.remove();
  }
});

```

## 4. `HTMLCollection` vs `NodeList`

| Feature                 | `HTMLCollection`                                  | `NodeList`                                    |
| ----------------------- | ------------------------------------------------- | --------------------------------------------- |
| **Returned By**         | `getElementsByClassName`, `getElementsByTagName`  | `querySelectorAll`, `node.childNodes`         |
| **Node Types Included** | **Element Nodes ONLY**                            | **Any Node type** (Elements, Text, Comments)  |
| **Liveness**            | **Live** (Updates automatically when DOM changes) | **Static** (Snapshot from `querySelectorAll`) |
| **Iteration Support**   | Array indexing, `for...of`                        | Built-in `.forEach()`, `for...of`             |

Here is a complete, beginner-friendly guide to selecting elements, changing HTML content, and updating CSS styles using JavaScript via the DOM API.

---

## 1. Selecting Elements

Before you can change an element, you need to select it from the web page.

| Task                   | Modern JavaScript Syntax              | Description                                               |
| ---------------------- | ------------------------------------- | --------------------------------------------------------- |
| **Select First Match** | `document.querySelector(".my-class")` | Selects the **first** element matching any CSS selector.  |
| **Select All Matches** | `document.querySelectorAll("p")`      | Selects **all** matching elements as a list (`NodeList`). |
| **Select by ID**       | `document.getElementById("my-id")`    | Selects a single element by its specific ID.              |

```javascript
// Examples:
const heading = document.querySelector("#main-title"); // Select by ID
const button  = document.querySelector(".btn-submit");  // Select by class
const paragraphs = document.querySelectorAll("p");      // Select all <p> elements

```

---

## 2. Changing HTML Content & Attributes

Once selected, you can modify an element's text, inner markup, or HTML attributes.

### A. Text and Markup

* **`textContent`**: Changes text only (safe against script injection).
* **`innerHTML`**: Changes the inner HTML structure (parses HTML tags).

```javascript
const title = document.querySelector("#main-title");
const card  = document.querySelector(".card");

// 1. Change text content
title.textContent = "Welcome to My Website!";

// 2. Change inner HTML (includes tags)
card.innerHTML = "<h3>New Card</h3><p>This is dynamic content.</p>";

```

### B. HTML Attributes

* **`setAttribute(name, value)`**: Sets or updates any HTML attribute.
* **`getAttribute(name)`**: Reads an attribute value.

```javascript
const image = document.querySelector("#profile-pic");

// Change image source and alt attribute
image.setAttribute("src", "avatar-new.jpg");
image.setAttribute("alt", "New User Profile Picture");

// Change link destination
const link = document.querySelector("a");
link.href = "https://example.com";

```

---

## 3. Changing CSS Styles

There are two primary ways to update styles: modifying **inline styles** or managing **CSS class names** (recommended).

### Option A: Using CSS Classes (`classList` - Recommended)

The cleanest approach is to toggle pre-defined CSS classes in your stylesheet.

```javascript
const box = document.querySelector(".box");

// 1. Add a CSS class
box.classList.add("active");

// 2. Remove a CSS class
box.classList.remove("hidden");

// 3. Toggle a class (adds if missing, removes if present)
box.classList.toggle("highlight");

// 4. Check if a class exists
if (box.classList.contains("active")) {
  console.log("Box is active!");
}

```

### Option B: Modifying Direct Inline Styles (`style` property)

For dynamic calculations or single inline overrides, use the `.style` property (uses `camelCase` property names).

```javascript
const banner = document.querySelector(".banner");

// Set individual inline CSS properties
banner.style.backgroundColor = "#3498db"; // CSS: background-color
banner.style.fontSize = "20px";            // CSS: font-size
banner.style.display = "none";             // Hide element
banner.style.display = "block";            // Show element

```

## 4. Complete Interactive Example

Below is a complete, working example combining element selection, HTML updates, and CSS changes triggered on a button click.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>DOM Manipulation Example</title>
  <style>
    .card {
      border: 2px solid #ccc;
      padding: 16px;
      width: 250px;
      transition: all 0.3s ease;
    }
    /* Class to be toggled by JS */
    .card-active {
      border-color: #2ecc71;
      background-color: #e8f8f5;
      box-shadow: 0 4px 8px rgba(0,0,0,0.1);
    }
  </style>
</head>
<body>

  <div id="user-card" class="card">
    <h2 id="user-name">Guest</h2>
    <p id="user-status">Status: Offline</p>
  </div>

  <button id="toggle-btn">Activate User</button>

  <script>
    // 1. SELECT ELEMENTS
    const cardElement   = document.querySelector("#user-card");
    const nameElement   = document.querySelector("#user-name");
    const statusElement = document.querySelector("#user-status");
    const buttonElement = document.querySelector("#toggle-btn");

    // 2. ADD EVENT LISTENER
    buttonElement.addEventListener("click", () => {
      // 3. CHANGE HTML CONTENT
      nameElement.textContent = "Alice Johnson";
      statusElement.innerHTML = "Status: <strong>Online</strong>";

      // 4. CHANGE CSS VIA CLASS
      cardElement.classList.toggle("card-active");

      // 5. CHANGE CSS INLINE
      statusElement.style.color = "#27ae60";
    });
  </script>
</body>
</html>

```
