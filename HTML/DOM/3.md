JavaScript form validation ensures that user input meets specific criteria (e.g., non-empty fields, valid email formats, password strength) **before** sending data to a server.

Validation should be handled at two levels:

1. **Client-Side (JavaScript):** Provides immediate user feedback and improves UI/UX.
2. **Server-Side (Backend):** Required for security (client-side validation can be bypassed).

---

## 1. Native HTML Validation vs. Custom JavaScript

HTML attributes like `required`, `type="email"`, `minlength`, `maxlength`, and `pattern` handle basic input checks natively. JavaScript is used to customize error messaging, validate dependent fields (e.g., password matching), and control form submission asynchronously.

---

## 2. Standard Pattern: Preventing Default & Custom Checks

To validate a form with JavaScript:

1. Intercept the form submission using `event.preventDefault()`.
2. Inspect input values and apply validation logic.
3. Display clear error messages next to invalid fields.
4. Submit the form (via `fetch()` or `form.submit()`) only when all checks pass.

### Complete Working Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>JS Form Validation</title>
  <style>
    .form-group { margin-bottom: 15px; }
    label { display: block; margin-bottom: 5px; font-weight: bold; }
    input { width: 100%; padding: 8px; box-sizing: border-box; }
    input.error-border { border: 2px solid #e74c3c; }
    .error-msg { color: #e74c3c; font-size: 13px; margin-top: 4px; display: none; }
  </style>
</head>
<body>

  <form id="signupForm" novalidate>
    <div class="form-group">
      <label for="username">Username</label>
      <input type="text" id="username" name="username" />
      <span class="error-msg" id="usernameError"></span>
    </div>

    <div class="form-group">
      <label for="email">Email</label>
      <input type="email" id="email" name="email" />
      <span class="error-msg" id="emailError"></span>
    </div>

    <div class="form-group">
      <label for="password">Password</label>
      <input type="password" id="password" name="password" />
      <span class="error-msg" id="passwordError"></span>
    </div>

    <button type="submit">Register</button>
  </form>

  <script>
    const form = document.querySelector("#signupForm");
    const usernameInput = document.querySelector("#username");
    const emailInput = document.querySelector("#email");
    const passwordInput = document.querySelector("#password");

    // Helper function to display errors
    function showError(input, errorElement, message) {
      input.classList.add("error-border");
      errorElement.textContent = message;
      errorElement.style.display = "block";
    }

    // Helper function to clear errors
    function clearError(input, errorElement) {
      input.classList.remove("error-border");
      errorElement.textContent = "";
      errorElement.style.display = "none";
    }

    // Email format validation via Regex
    function isValidEmail(email) {
      const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
      return emailRegex.test(email);
    }

    // Form Submit Event Handler
    form.addEventListener("submit", (event) => {
      // Prevent automatic browser submission
      event.preventDefault();

      let isValid = true;

      // 1. Validate Username
      if (usernameInput.value.trim() === "") {
        showError(usernameInput, document.querySelector("#usernameError"), "Username is required.");
        isValid = false;
      } else if (usernameInput.value.trim().length < 3) {
        showError(usernameInput, document.querySelector("#usernameError"), "Username must be at least 3 characters.");
        isValid = false;
      } else {
        clearError(usernameInput, document.querySelector("#usernameError"));
      }

      // 2. Validate Email
      if (emailInput.value.trim() === "") {
        showError(emailInput, document.querySelector("#emailError"), "Email address is required.");
        isValid = false;
      } else if (!isValidEmail(emailInput.value.trim())) {
        showError(emailInput, document.querySelector("#emailError"), "Please enter a valid email address.");
        isValid = false;
      } else {
        clearError(emailInput, document.querySelector("#emailError"));
      }

      // 3. Validate Password
      if (passwordInput.value.trim() === "") {
        showError(passwordInput, document.querySelector("#passwordError"), "Password is required.");
        isValid = false;
      } else if (passwordInput.value.length < 8) {
        showError(passwordInput, document.querySelector("#passwordError"), "Password must be at least 8 characters.");
        isValid = false;
      } else {
        clearError(passwordInput, document.querySelector("#passwordError"));
      }

      // Final Check: Submit form if all validations pass
      if (isValid) {
        console.log("Form validated successfully! Sending data...");
        // Example: Send via fetch API
        // fetch('/api/register', { method: 'POST', body: new FormData(form) });
      }
    });
  </script>
</body>
</html>

```

## 3. Real-Time (On-Blur / On-Input) Validation

Instead of waiting for form submission, validating input **on blur** (when the user leaves a field) or **on input** (as they type) provides better user feedback.

```javascript
// Validate email as soon as the user clicks away from the field
emailInput.addEventListener("blur", () => {
  if (!isValidEmail(emailInput.value.trim())) {
    showError(emailInput, document.querySelector("#emailError"), "Invalid email address format.");
  } else {
    clearError(emailInput, document.querySelector("#emailError"));
  }
});

```

## 4. The Constraints Validation API

JavaScript provides built-in methods and properties on form controls via the **Constraint Validation API**:

### Useful Properties & Methods

* **`input.validity.valid`**: Returns `true` if the element passes all validation checks.
* **`input.validity.valueMissing`**: Returns `true` if a required field is empty.
* **`input.validity.typeMismatch`**: Returns `true` if value format doesn't match `type` (e.g., email or url).
* **`input.validity.tooShort`**: Returns `true` if value length is less than `minlength`.
* **`input.setCustomValidity("message")`**: Sets a custom error message on the native popup balloon.
* **`input.checkValidity()`**: Returns `false` and fires an `invalid` event if constraints fail.

### Constraint Validation API Example

```javascript
const passwordInput = document.querySelector("#password");

passwordInput.addEventListener("input", () => {
  if (passwordInput.value.length < 8) {
    // Setting custom validity flags field as invalid natively
    passwordInput.setCustomValidity("Password must be at least 8 characters long.");
  } else {
    // Passing empty string clears the custom error state
    passwordInput.setCustomValidity("");
  }
});

```

## 5. Common Regex Validation Patterns

| Field Type          | Regex Pattern                                                            | Description                                                      |
| ------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| **Email**           | `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`                                           | Basic email address structure.                                   |
| **Phone (US)**      | `/^\(?\d{3}\)?[-.\s]?\d{3}[-.\s]?\d{4}$/`                                | Standard 10-digit formats.                                       |
| **Strong Password** | `/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$/` | Min 8 chars, 1 uppercase, 1 lowercase, 1 number, 1 special char. |
| **Numbers Only**    | `/^\d+$/`                                                                | Digits only.                                                     |

Explain how to submit HTML forms asynchronously using JavaScript Fetch API and FormData

Submitting HTML forms asynchronously using the JavaScript **Fetch API** and **`FormData`** object allows you to send data to a server in the background without causing a full browser page refresh (AJAX pattern).

---

## 1. How `FormData` Works

The **`FormData`** interface automatically compiles all named input fields (`<input name="...">`, `<textarea name="...">`, `<select name="...">`) from an HTML `<form>` element into key-value pairs.

It natively supports multi-part data, making it the standard choice when uploading **files, images, or standard text fields**.

---

## 2. Standard Implementation Step-by-Step

To handle asynchronous form submission:

1. Intercept the form's `submit` event using `event.preventDefault()`.
2. Instantiating `new FormData(formElement)`.
3. Send a `POST` request using `fetch()`.
4. Handle the asynchronous `Promise` response (JSON or text).

### Complete Working Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>Async Form Submission Demo</title>
  <style>
    .form-group { margin-bottom: 12px; }
    label { display: block; margin-bottom: 4px; }
    #status-msg { margin-top: 12px; font-weight: bold; }
    .success { color: green; }
    .error { color: red; }
  </style>
</head>
<body>

  <h2>Contact Us</h2>

  <!-- Inputs MUST have 'name' attributes for FormData to collect them -->
  <form id="contactForm">
    <div class="form-group">
      <label for="username">Name:</label>
      <input type="text" id="username" name="username" required />
    </div>

    <div class="form-group">
      <label for="email">Email:</label>
      <input type="email" id="email" name="email" required />
    </div>

    <div class="form-group">
      <label for="avatar">Profile Picture (Optional File):</label>
      <input type="file" id="avatar" name="avatar" />
    </div>

    <button type="submit" id="submitBtn">Send Message</button>
  </form>

  <div id="status-msg"></div>

  <script>
    const form = document.querySelector('#contactForm');
    const statusMsg = document.querySelector('#status-msg');
    const submitBtn = document.querySelector('#submitBtn');

    form.addEventListener('submit', async (event) => {
      // 1. Prevent default full-page reload
      event.preventDefault();

      // UI state feedback
      submitBtn.disabled = true;
      statusMsg.textContent = 'Submitting...';
      statusMsg.className = '';

      // 2. Automatically capture all form input fields
      const formData = new FormData(form);

      try {
        // 3. Send asynchronous request via Fetch API
        const response = await fetch('/api/submit-form', {
          method: 'POST',
          // Note: DO NOT manually set Content-Type header when passing FormData.
          // The browser automatically sets boundary headers for multipart/form-data.
          body: formData
        });

        // 4. Handle non-2xx HTTP error status codes
        if (!response.ok) {
          throw new Error(`Server error: ${response.status} ${response.statusText}`);
        }

        const data = await response.json();

        // 5. Success UI state
        statusMsg.textContent = 'Form submitted successfully!';
        statusMsg.className = 'success';
        form.reset(); // Clear form fields

      } catch (error) {
        // Handle network errors or server failures
        statusMsg.textContent = `Submission failed: ${error.message}`;
        statusMsg.className = 'error';
      } finally {
        submitBtn.disabled = false;
      }
    });
  </script>
</body>
</html>

```

## 3. Important Rules to Keep in Mind

### Rule 1: Always include the `name` attribute on inputs

`FormData` searches for fields based on their HTML `name` attribute—**not** their `id` or `class`. Inputs without a `name` attribute will be completely ignored.

```html
<!-- Correct -->
<input type="text" name="user_name" />

<!-- Incorrect (Will NOT be captured by FormData) -->
<input type="text" id="user_name" />

```

---

### Rule 2: DO NOT set the `Content-Type` header manually

When passing a `FormData` object into the `body` parameter of `fetch()`, **do not set `headers: { 'Content-Type': 'multipart/form-data' }**`.

Leaving `Content-Type` unset allows the browser to automatically compute and set the header along with the necessary multi-part `boundary` string parameter required for binary uploads.

```javascript
// GOOD: Let browser set multipart boundary automatically
fetch('/api', {
  method: 'POST',
  body: new FormData(form)
});

// BAD: Manually overriding breaks multi-part parsing on backend!
fetch('/api', {
  method: 'POST',
  headers: { 'Content-Type': 'multipart/form-data' }, // Avoid this!
  body: new FormData(form)
});

```

---

## 4. Converting `FormData` to JSON (Alternative Approach)

If your backend endpoint expects a standard JSON payload (`application/json`) rather than multipart form data, you can convert the `FormData` entries into a plain JavaScript Object using `Object.fromEntries()`:

```javascript
form.addEventListener('submit', async (e) => {
  e.preventDefault();

  const formData = new FormData(form);
  
  // Convert FormData key-values into a plain JS Object
  const plainDataObject = Object.fromEntries(formData.entries());

  const response = await fetch('/api/json-endpoint', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(plainDataObject)
  });

  const result = await response.json();
});

```

> **Note:** `Object.fromEntries(formData)` works best for simple forms. If your form contains multi-select fields (`<select multiple>`) or multiple file inputs under the same name, `Object.fromEntries` will overwrite duplicate keys with the last value.

---

## 5. Manually Manipulating `FormData` Keys

You can dynamically inspect or add extra fields to a `FormData` object before sending it to the server:

```javascript
const formData = new FormData(form);

// 1. Add extra custom data
formData.append('timestamp', Date.now());
formData.append('source', 'web_client');

// 2. Overwrite an existing value
formData.set('username', 'AliceUpdated');

// 3. Delete a field
formData.delete('unwanted_field');

// 4. Inspect data
console.log(formData.get('username')); // "AliceUpdated"
console.log(formData.has('email'));    // true

```

Explain how to create a file upload progress bar in JavaScript using XMLHttpRequest and Fetch API

To track file upload progress in real time, you need access to the browser's progress events during the upload stream.

Historically, **`XMLHttpRequest` (XHR)** provided native support for upload progress tracking via `xhr.upload.onprogress`. Modern **`Fetch API`** can achieve the same result using modern **`ReadableStream`** / **`WritableStream`** web streams.

---

## Method 1: Using `XMLHttpRequest` (Simplest & Most Broadly Supported)

`XMLHttpRequest` provides an `xhr.upload` object that emits continuous `progress` events as bytes are sent to the server.

### Complete Working Example (XHR)

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>XHR File Upload Progress</title>
  <style>
    .progress-container {
      width: 100%;
      background-color: #e0e0e0;
      border-radius: 4px;
      margin: 15px 0;
      display: none;
    }
    .progress-bar {
      width: 0%;
      height: 20px;
      background-color: #4caf50;
      border-radius: 4px;
      transition: width 0.1s ease;
    }
    #status { font-weight: bold; }
  </style>
</head>
<body>

  <h2>Upload File (XHR Method)</h2>
  
  <input type="file" id="fileInput" />
  <button onclick="uploadFileXHR()">Upload</button>

  <div class="progress-container" id="progressContainer">
    <div class="progress-bar" id="progressBar"></div>
  </div>

  <p id="status"></p>

  <script>
    function uploadFileXHR() {
      const fileInput = document.getElementById("fileInput");
      const file = fileInput.files[0];

      if (!file) {
        alert("Please select a file first.");
        return;
      }

      const formData = new FormData();
      formData.append("file", file);

      const xhr = new XMLHttpRequest();

      const progressContainer = document.getElementById("progressContainer");
      const progressBar = document.getElementById("progressBar");
      const statusText = document.getElementById("status");

      progressContainer.style.display = "block";
      progressBar.style.width = "0%";
      statusText.textContent = "Starting upload...";

      // --- Track Upload Progress ---
      xhr.upload.onprogress = (event) => {
        if (event.lengthComputable) {
          // Calculate percentage uploaded
          const percentComplete = Math.round((event.loaded / event.total) * 100);
          
          progressBar.style.width = percentComplete + "%";
          statusText.textContent = `Uploading: ${percentComplete}% (${(event.loaded / 1024 / 1024).toFixed(2)} MB / ${(event.total / 1024 / 1024).toFixed(2)} MB)`;
        }
      };

      // --- Handle Completion ---
      xhr.onload = () => {
        if (xhr.status >= 200 && xhr.status < 300) {
          statusText.textContent = "Upload complete!";
        } else {
          statusText.textContent = `Upload failed with status: ${xhr.status}`;
        }
      };

      // --- Handle Network Errors ---
      xhr.onerror = () => {
        statusText.textContent = "Network error occurred during upload.";
      };

      // Send POST request
      xhr.open("POST", "/upload-endpoint", true);
      xhr.send(formData);
    }
  </script>
</body>
</html>

```

## Method 2: Using the Modern `Fetch API` with `TransformStream`

Standard `fetch()` does not expose an `onprogress` callback for uploads. However, modern browsers allow passing a **`ReadableStream`** directly as the `body` parameter of a request. By reading a file chunk-by-chunk and tracking read bytes, you can monitor upload progress natively using `fetch`.

### Complete Working Example (`fetch` Streams)

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>Fetch API Upload Progress</title>
  <style>
    progress { width: 100%; height: 20px; display: none; }
  </style>
</head>
<body>

  <h2>Upload File (Fetch API Method)</h2>

  <input type="file" id="fileInputFetch" />
  <button onclick="uploadFileFetch()">Upload</button>

  <br/><br/>
  <progress id="fetchProgress" value="0" max="100"></progress>
  <p id="fetchStatus"></p>

  <script>
    async function uploadFileFetch() {
      const fileInput = document.getElementById("fileInputFetch");
      const file = fileInput.files[0];

      if (!file) {
        alert("Please select a file first.");
        return;
      }

      const progressBar = document.getElementById("fetchProgress");
      const statusText = document.getElementById("fetchStatus");

      progressBar.style.display = "block";
      progressBar.value = 0;

      let uploadedBytes = 0;
      const totalBytes = file.size;

      // 1. Create a readable stream from the file blob
      const fileStream = file.stream();

      // 2. Pass stream through a TransformStream to observe byte progress
      const progressStream = new TransformStream({
        transform(chunk, controller) {
          uploadedBytes += chunk.length;
          
          // Calculate percentage
          const percentComplete = Math.round((uploadedBytes / totalBytes) * 100);
          progressBar.value = percentComplete;
          statusText.textContent = `Uploaded ${percentComplete}%`;

          // Forward chunk to destination
          controller.enqueue(chunk);
        }
      });

      // 3. Pipe file stream into the transform stream
      const uploadBody = fileStream.pipeThrough(progressStream);

      try {
        const response = await fetch("/upload-endpoint", {
          method: "POST",
          headers: {
            "Content-Type": file.type || "application/octet-stream",
            "X-File-Name": encodeURIComponent(file.name)
          },
          body: uploadBody,
          // 'duplex: half' is required by modern browser engines when stream body is passed
          duplex: "half" 
        });

        if (response.ok) {
          statusText.textContent = "Upload successful!";
        } else {
          statusText.textContent = `Upload failed: ${response.statusText}`;
        }
      } catch (err) {
        statusText.textContent = `Error: ${err.message}`;
      }
    }
  </script>
</body>
</html>

```

## Comparison Matrix

| Feature                   | `XMLHttpRequest` (XHR)                  | `Fetch API` (with Streams)                                                            |
| ------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------- |
| **Setup Complexity**      | Very Low (Native `onprogress` callback) | Moderate (Requires Web Streams API & `duplex: 'half'`)                                |
| **Browser Compatibility** | Excellent (Legacy and modern browsers)  | Modern Browsers                                                                       |
| **Syntax Style**          | Event-based / Callbacks                 | Promise / `async-await` based                                                         |
| **Multipart `FormData**`  | Native support with upload progress     | Stream uploads require custom backend stream parsing (or manual multipart boundaries) |

> **Recommendation:** If uploading standard HTML forms with `FormData` and multiple files, **`XMLHttpRequest`** remains the cleaner and most reliable choice for tracking progress. For streaming large binary payloads in modern architectures, use the **`Fetch API`** with streams.
