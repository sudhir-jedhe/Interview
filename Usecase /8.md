You copied state using the spread operator, yet updating the copy also changed the original object. Where exactly was the reference still shared?

The reference was still shared at the **nested object or array level**.

The spread operator (`...`) creates a **shallow copy**. It copies top-level primitive values (like numbers, strings, or booleans) by value, but for nested objects, arrays, or functions, it only copies their **memory references**.

---

### Visualizing the Memory Layout

Consider this nested state object:

```javascript
const original = {
  user: "Alice",
  settings: {
    theme: "dark",
  },
};

// Shallow copy using spread operator
const copy = { ...original };
```

In memory, here is what `original` and `copy` look like:

```text
 original                             copy
┌─────────┬────────┐               ┌─────────┬────────┐
│  user   │ "Alice"│               │  user   │ "Alice"│ (Copied by value)
├─────────┼────────┤               ├─────────┼────────┤
│ settings│ 0x00A1 ├───────┐   ┌───┤ settings│ 0x00A1 │ (Shared reference!)
└─────────┴────────┘       │   │   └─────────┴────────┘
                           ▼   ▼
                     ┌───────────────┐
                     │ 0x00A1        │
                     ├───────┬───────┤
                     │ theme │"dark" │
                     └───────┴───────┘

```

When you update top-level properties on `copy`, the original object is untouched:

```javascript
copy.user = "Bob";
console.log(original.user); // "Alice" (Unchanged)
```

However, because `original.settings` and `copy.settings` both store the exact same pointer (`0x00A1`), mutating `copy.settings` mutates the underlying object that `original` points to:

```javascript
copy.settings.theme = "light";

console.log(original.settings.theme); // "light" (Mutated!)
```

---

### How to Correctly Update Nested Objects

To maintain immutability without mutating the original state, you must shallow copy **every nested level** you intend to modify.

#### 1. Nested Spread (Standard React Pattern)

Spread every nested object level down to the property you want to change:

```javascript
const updatedCopy = {
  ...original,
  settings: {
    ...original.settings,
    theme: "light", // Overrides theme on a fresh settings object
  },
};

console.log(original.settings.theme); // "dark" (Preserved)
console.log(updatedCopy.settings.theme); // "light"
```

#### 2. Deep Copying using `structuredClone()`

If you need a complete clone without sharing any nested references, use the native `structuredClone()` function:

```javascript
const deepCopy = structuredClone(original);

deepCopy.settings.theme = "light";

console.log(original.settings.theme); // "dark" (Preserved)
```

#### 3. Using Immer (Popular for Complex React State)

Libraries like `immer` allow you to write plain mutating code safely by producing an immutable update under the hood:

```javascript
import { produce } from "immer";

const nextState = produce(original, (draft) => {
  draft.settings.theme = "light";
});
```
