अगर आपको आउटपुट में **ऑब्जेक्ट्स का एरे** ही चाहिए (जैसा आपका इनपुट एरे था), तो आप `filter()` मेथड का इस्तेमाल कर सकते हैं।

इसमें `map()` लगाने की ज़रूरत नहीं है—यह हर 'key' के हिसाब से ओरिजिनल ऑब्जेक्ट्स को फिल्टर करके अलग-अलग एरे बना देगा।

### कोड उदाहरण:

```javascript
const items = [
  { key: "sample one", data: "data one" },
  { key: "sample two", data: "data two" },
  { key: "sample one", data: "data three" },
  { key: "sample three", data: "data four" },
  { key: "sample two", data: "data five" },
];

// 1. सिर्फ 'sample one' का एरे ऑफ ऑब्जेक्ट्स पाने के लिए:
const sampleOneArray = items.filter((item) => item.key === "sample one");

console.log("Sample One Result:", sampleOneArray);
/* आउटपुट (Array of Objects):
[
  { key: 'sample one', data: 'data one' },
  { key: 'sample one', data: 'data three' }
]
*/

// 2. 'sample two' के लिए:
const sampleTwoArray = items.filter((item) => item.key === "sample two");

console.log("Sample Two Result:", sampleTwoArray);
/* आउटपुट (Array of Objects):
[
  { key: 'sample two', data: 'data two' },
  { key: 'sample two', data: 'data five' }
]
*/
```

---

### अगर आपको सभी 'keys' को एक साथ ऑब्जेक्ट में ग्रुप करना हो:

अगर आप एक ही बार में सब अलग-अलग ग्रुप बनाना चाहते हैं, जिसमें वैल्यू में वही ओरिजिनल **Array of Objects** रहे:

```javascript
const grouped = items.reduce((acc, item) => {
  // अगर key पहले से एरे में नहीं है, तो नया एरे बनाएं
  if (!acc[item.key]) {
    acc[item.key] = [];
  }
  // ओरिजिनल पूरा ऑब्जेक्ट पुश करें
  acc[item.key].push(item);
  return acc;
}, {});

console.log(grouped);
/* आउटपुट:
{
  "sample one": [
    { key: "sample one", data: "data one" },
    { key: "sample one", data: "data three" }
  ],
  "sample two": [
    { key: "sample two", data: "data two" },
    { key: "sample two", data: "data five" }
  ],
  "sample three": [
    { key: "sample three", data: "data four" }
  ]
}
*/
```

अब आप `grouped['sample one']` का उपयोग करेंगे, तो आपको **Array of Objects** ही मिलेगा।
