This infographic introduces **"Master Prompt Engineering: The 4S Framework,"** designed to yield better prompts, smarter AI responses, and better code.

The framework breaks down into four core pillars:

---

### 1. Single

* **Focus:** Focus on one task at a time.
* **Key Guidelines:**
* One task.
* One objective.
* One output.

* **Example Contrast:**
* ❌ **Too many things:** *"Build my app, write tests, optimize performance and deploy it."*
* ✅ **Better:** *"Create a responsive login component using React and Tailwind CSS."*

### 2. Specific

* **Focus:** Be explicit and give details.
* **Key Guidelines:**
* Framework / Tech.
* Language.
* Requirements.
* Constraints.
* Expected output.

* **Example Contrast:**
* ❌ **Too vague:** *"Create a button."*
* ✅ **Better:** *"Create an accessible primary button in React using Tailwind CSS with hover, focus and disabled states."*

### 3. Short

* **Focus:** Keep your prompt concise and to the point.
* **Key Guidelines:**
* Avoid unnecessary words.
* Short prompts are easier for AI to understand.

* **Example Contrast:**
* ❌ **Too long:** *"I want you to create a beautiful, modern, fully responsive, and highly accessible button component with every possible feature..."*
* ✅ **Better:** *"Create an accessible primary button component in React."*

### 4. Surround

* **Focus:** Give AI the right context around your prompt.
* **Key Guidelines:**
* Open related files.
* Use descriptive filenames.
* Reference existing components.
* Let AI understand your project.

---

### Summary Mantra

> **SINGLE** (One task) + **SPECIFIC** (Be detailed) + **SHORT** (Keep it simple) + **SURROUND** (Provide context) = **BETTER PROMPTS = BETTER AI = BETTER SOFTWARE**
