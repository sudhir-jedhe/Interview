Every topic's `problems/` folder has real "implement/type X from scratch" challenges — these come up constantly in TS interviews (implement your own `Pick`, a generic `Stack<T>`, a `DeepReadonly<T>`, etc.) and are worth doing hands-on, not just reading.

See [`STUDY-PLAN.md`](./STUDY-PLAN.md) for order and [`SOURCE-MAP.md`](./SOURCE-MAP.md) for how this maps to your existing `js_polyfills/Typescript` notes.

**Prerequisite:** core JavaScript first (`js-interview-mastery`) — TypeScript interviews assume you already know the JS underneath.
