Here is a complete, working code example demonstrating a **Host App** and a **Remote MFE** (Micro Frontend) built with React and Webpack 5 Module Federation.

---

### Application Architecture

```text
┌────────────────────────────────────────────────────────┐
│ HOST APP (Port 3000)                                   │
│ ├── App.jsx                                            │
│ └── Suspense + ErrorBoundary                           │
│     └── Dynamically imports <Header /> from Remote MFE │
└───────────────────────────┬────────────────────────────┘
                            │
                            │ Fetches http://localhost:3001/remoteEntry.js
                            ▼
┌────────────────────────────────────────────────────────┐
│ REMOTE MFE (Port 3001)                                 │
│ └── Exposes Header.jsx                                 │
└────────────────────────────────────────────────────────┘

```

---

### Project 1: The Remote Micro Frontend (`remote-app`)

The Remote MFE exposes a `<Header/>` component to be consumed by the Host App.

#### 1. Remote Webpack Config (`remote-app/webpack.config.js`)

```javascript
const HtmlWebpackPlugin = require('html-webpack-plugin');
const ModuleFederationPlugin = require('webpack/lib/container/ModuleFederationPlugin');
const path = require('path');

module.exports = {
  entry: './src/index',
  mode: 'development',
  devServer: {
    port: 3001,
    headers: {
      'Access-Control-Allow-Origin': '*', // Enable CORS for host requests
    },
  },
  output: {
    publicPath: 'auto',
  },
  module: {
    rules: [
      {
        test: /\.jsx?$/,
        loader: 'babel-loader',
        exclude: /node_modules/,
        options: {
          presets: ['@babel/preset-react'],
        },
      },
    ],
  },
  plugins: [
    new ModuleFederationPlugin({
      name: 'remoteApp', // Unique name for the remote container
      filename: 'remoteEntry.js', // Manifest file generated by Webpack
      exposes: {
        './Header': './src/Header', // Component exposed to host
      },
      shared: {
        react: { singleton: true, requiredVersion: '^18.0.0', eager: false },
        'react-dom': { singleton: true, requiredVersion: '^18.0.0', eager: false },
      },
    }),
    new HtmlWebpackPlugin({
      template: './public/index.html',
    }),
  ],
  resolve: {
    extensions: ['.js', '.jsx'],
  },
};

```

#### 2. Remote Component (`remote-app/src/Header.jsx`)

```jsx
import React from 'react';

export default function Header({ user, onLogout }) {
  return (
    <header style={headerStyle}>
      <h2>🏬 E-Commerce Remote App Header</h2>
      {user ? (
        <div>
          <span>Logged in as: <strong>{user.name}</strong></span>
          <button onClick={onLogout} style={buttonStyle}>Logout</button>
        </div>
      ) : (
        <span>Guest User</span>
      )}
    </header>
  );
}

const headerStyle = {
  padding: '16px 24px',
  backgroundColor: '#1E293B',
  color: '#FFFFFF',
  display: 'flex',
  justifyContent: 'space-between',
  alignItems: 'center',
  borderRadius: '8px',
};

const buttonStyle = {
  marginLeft: '12px',
  padding: '6px 12px',
  backgroundColor: '#EF4444',
  color: '#FFF',
  border: 'none',
  borderRadius: '4px',
  cursor: 'pointer',
};

```

### Project 2: The Host Shell Application (`host-app`)

The Host App connects to the Remote MFE, fetches `remoteEntry.js` at runtime, and mounts `<Header/>`.

#### 1. Host Webpack Config (`host-app/webpack.config.js`)

```javascript
const HtmlWebpackPlugin = require('html-webpack-plugin');
const ModuleFederationPlugin = require('webpack/lib/container/ModuleFederationPlugin');
const path = require('path');

module.exports = {
  entry: './src/index',
  mode: 'development',
  devServer: {
    port: 3000,
  },
  output: {
    publicPath: 'auto',
  },
  module: {
    rules: [
      {
        test: /\.jsx?$/,
        loader: 'babel-loader',
        exclude: /node_modules/,
        options: {
          presets: ['@babel/preset-react'],
        },
      },
    ],
  },
  plugins: [
    new ModuleFederationPlugin({
      name: 'hostApp',
      remotes: {
        // Points to the remote entry of remoteApp running on port 3001
        remoteApp: 'remoteApp@http://localhost:3001/remoteEntry.js',
      },
      shared: {
        react: { singleton: true, requiredVersion: '^18.0.0', eager: false },
        'react-dom': { singleton: true, requiredVersion: '^18.0.0', eager: false },
      },
    }),
    new HtmlWebpackPlugin({
      template: './public/index.html',
    }),
  ],
  resolve: {
    extensions: ['.js', '.jsx'],
  },
};

```

#### 2. Host Bootstrap Script (`host-app/src/bootstrap.js`)

> **Crucial Pattern:** Module Federation requires an asynchronous boundary on initialization to allow shared dependencies to resolve before rendering React.

```jsx
// host-app/src/index.js
import('./bootstrap'); // Asynchronous boundary

```

```jsx
// host-app/src/bootstrap.js
import React from 'react';
import { createRoot } from 'react-dom/client';
import App from './App';

const container = document.getElementById('root');
const root = createRoot(container);
root.render(<App />);

```

#### 3. Host Main Application (`host-app/src/App.jsx`)

```jsx
import React, { useState, Suspense, lazy } from 'react';

// Lazy load remote header component
const RemoteHeader = lazy(() => import('remoteApp/Header'));

// Error boundary to catch remote failures gracefully
class RemoteErrorBoundary extends React.Component {
  state = { hasError: false };

  static getDerivedStateFromError() {
    return { hasError: true };
  }

  render() {
    if (this.state.hasError) {
      return (
        <div style={{ padding: '16px', background: '#FEE2E2', color: '#991B1B' }}>
          ⚠️ Remote Header failed to load. Displaying fallback header.
        </div>
      );
    }
    return this.props.children;
  }
}

export default function App() {
  const [user, setUser] = useState({ name: 'Sudhir' });

  const handleLogout = () => setUser(null);

  return (
    <div style={{ padding: '24px', fontFamily: 'sans-serif', maxWidth: '800px' }}>
      <h1>Host Shell Application (Port 3000)</h1>

      {/* Mount Remote Component with Suspense & Fallback */}
      <RemoteErrorBoundary>
        <Suspense fallback={<div>Loading Remote Header...</div>}>
          <RemoteHeader user={user} onLogout={handleLogout} />
        </Suspense>
      </RemoteErrorBoundary>

      <main style={{ marginTop: '24px' }}>
        <h3>Main Dashboard Area</h3>
        <p>This content belongs entirely to the Host application.</p>
      </main>
    </div>
  );
}

```

### How to Run

1. Run the **Remote App** first on Port 3001:

```bash
cd remote-app && npm start

```

1. Run the **Host App** on Port 3000:

```bash
cd host-app && npm start

```

1. Open `http://localhost:3000` in your browser. The host application will fetch and render the `<Header/>` component directly from port 3001 while sharing a single instance of React in memory.
