Here is a breakdown of every JavaScript Regular Expression flag along with the syntax and **3 concrete examples** for each flag.

---

## Flag Syntax

$$\text{/}\underbrace{\text{pattern}}_{\text{Search Criteria}}\text{/}\underbrace{\text{flags}}_{\text{Modifier Flags}}$$

* `/` **Opening delimiter**: Marks the start of the Regular Expression.
* **pattern**: The search criteria, sequence of characters, or rules to match.
* `/` **Closing delimiter**: Marks the end of the pattern.
* **flags**: One or more single-character modifiers (e.g., `g`, `i`, `m`) that alter how the search is executed.

---

## 1. Global Match Flag (`/g`)

*Performs a global search, finding all matches rather than stopping after the first match.*

```javascript
const text = "cat bat rat mat";

// Example 1: Extract all matching words into an array
console.log(text.match(/[cbm]at/g)); 
// Output: ["cat", "bat", "mat"]

// Example 2: Replace all occurrences of digits in a string
console.log("Call 123-456-7890".replace(/\d/g, "#")); 
// Output: "Call ###-###-####"

// Example 3: Count total occurrences using matchAll()
const matches = [... "test1 test2 test3".matchAll(/test\d/g)];
console.log(matches.length); 
// Output: 3

```

---

## 2. Case-Insensitive Matching Flag (`/i`)

*Makes the pattern matching case-insensitive (ignores uppercase/lowercase differences).*

```javascript
// Example 1: Basic case-insensitive test
console.log(/hello/i.test("HeLLo World")); 
// Output: true

// Example 2: Replace words regardless of capitalization
console.log("JavaScript javascript JAVASCRIPT".replace(/javascript/gi, "JS")); 
// Output: "JS JS JS"

// Example 3: Search for specific name variants
const names = ["Alice", "ALICE", "alice"];
const result = names.filter(name => /^alice$/i.test(name));
console.log(result); 
// Output: ["Alice", "ALICE", "alice"]

```

---

## 3. Multiline Matching Flag (`/m`)

*Changes the behavior of `^` (start of line) and `$` (end of line) to match the start/end of **each line** within a multiline string, rather than just the start/end of the whole string.*

```javascript
const poem = `First line\nSecond line\nThird line`;

// Example 1: Match 'line' at the end of every line
console.log(poem.match(/line$/gm)); 
// Output: ["line", "line", "line"]

// Example 2: Match words at the beginning of each line
console.log(poem.match(/^[A-Z]\w+/gm)); 
// Output: ["First", "Second", "Third"]

// Example 3: Filter markdown lines that start with a header (#)
const markdown = "# Title\nParagraph\n# Heading 2";
console.log(markdown.match(/^# .*/gm)); 
// Output: ["# Title", "# Heading 2"]

```

---

## 4. Single-line / DotAll Flag (`/s`)

*Allows the wildcard dot (`.`) character to match line terminators (`\n`, `\r`), which it normally skips.*

```javascript
const codeBlock = "function() {\n  return true;\n}";

// Example 1: Match text spanning across newline characters
console.log(/function\(\) \{.*?\}/s.test(codeBlock)); 
// Output: true (without 's', standard '.' stops at \n)

// Example 2: Extract content inside multi-line HTML tags
const html = "<div>\n  <p>Hello</p>\n</div>";
console.log(html.match(/<div>.*<\/div>/s)[0]); 
// Output: "<div>\n  <p>Hello</p>\n</div>"

// Example 3: Capture multiline comments
const code = "/* \n Multi-line \n Comment \n */";
console.log(code.match(/\/\*.*\*\//s)[0]); 
// Output: "/* \n Multi-line \n Comment \n */"

```

---

## 5. Unicode Support Flag (`/u`)

*Enables full Unicode handling, treating surrogate pairs as single characters and enabling Unicode character class escapes (`\p{...}`).*

```javascript
// Example 1: Correctly measure Unicode emoji character classes
console.log(/^.$/u.test("😊")); 
// Output: true (without 'u', "😊" takes 2 code units, causing /^.$/ to fail)

// Example 2: Use Unicode property escapes to match specific scripts
console.log(/\p{Script=Greek}/u.test("Ω")); 
// Output: true

// Example 3: Match Unicode categories like letters in non-English alphabets
console.log(/\p{L}+/gu.test("München")); 
// Output: true

```

---

## 6. Unicode Sets Flag (`/v`)

*An upgrade to the `/u` flag (introduced in ES2024). Adds set operations (difference/intersection) and multi-character properties inside character classes `[...]`.*

```javascript
// Example 1: Set subtraction - Match Greek letters EXCEPT Greek vowels
const nonVowelGreek = /[\p{Script=Greek}--\x{03B1}\x{03B5}\x{03B7}\x{03B9}]/v;
console.log(nonVowelGreek.test("β")); 
// Output: true

// Example 2: Set intersection - Match characters that are BOTH Greek AND Symbols
const greekSymbol = /[\p{Script=Greek}&&[Ω]]/v;
console.log(greekSymbol.test("Ω")); 
// Output: true

// Example 3: Match multi-character emoji properties (e.g., flags made of multiple code points)
console.log(/^\p{RGI_Emoji}$/v.test("🇺🇸")); 
// Output: true

```

---

## 7. Sticky Search Flag (`/y`)

*Matches starting strictly at the exact index indicated by the `lastIndex` property of the RegExp object, without looking ahead.*

```javascript
const str = "12 34 56";
const regex = /\d+/y;

// Example 1: Successful sticky match starting at index 0
regex.lastIndex = 0;
console.log(regex.exec(str)[0]); 
// Output: "12"

// Example 2: Failed sticky match when index points to a space instead of a digit
regex.lastIndex = 2; // Index 2 is a space ' '
console.log(regex.exec(str)); 
// Output: null

// Example 3: Advancing manual tokenizer loop with sticky flag
const tokenRegex = /\w+/y;
const code = "const x";

tokenRegex.lastIndex = 0;
console.log(tokenRegex.exec(code)[0]); // Output: "const"

tokenRegex.lastIndex = 6; // Move pointer past space directly to "x"
console.log(tokenRegex.exec(code)[0]); // Output: "x"

```

---

## 8. Substring / Indices Match Flag (`/d`)

*Generates start and end index bounds (`indices`) for matched substrings and capture groups.*

```javascript
const text = "Hello world";
const regex = /(world)/d;
const result = regex.exec(text);

// Example 1: Access start/end indices of the full match
console.log(result.indices[0]); 
// Output: [6, 11] (indicates 'world' spans index 6 to 11)

// Example 2: Access start/end indices of a specific capture group
console.log(result.indices[1]); 
// Output: [6, 11]

// Example 3: Using indices to extract sub-strings via slice
const bounds = result.indices[0];
console.log(text.slice(bounds[0], bounds[1])); 
// Output: "world"

```

## What are Character Classes?

Character Classes allow you to define a specific set or range of characters to match. When placed inside square brackets `[...]`, the regular expression engine will match **any single character** that belongs to that set (or **not** in that set if prefixed with `^`).

```javascript
// Match any single digit from 0 to 9
const pattern = /[0-9]/; 

```

---

## 1. Single Character Class: `[a]`

*Matches the exact character specified inside the brackets.*

```javascript
// Example 1: Check if a string contains the specific character 'x'
const hasX = /[x]/.test("matrix");
console.log(hasX); 
// Output: true

// Example 2: Match the letter 'a' in a sentence
const matchA = "cat".match(/[a]/g);
console.log(matchA); 
// Output: ["a"]

// Example 3: Replace occurrences of 'e' with '*'
const obscured = "hello street".replace(/[e]/g, "*");
console.log(obscured); 
// Output: "h*llo str**t"

```

---

## 2. Negated Single Character Class: `[^a]`

*Matches any character except the one specified inside the brackets.*

```javascript
// Example 1: Match all characters that are NOT 'a'
const notA = "banana".match(/[^a]/g);
console.log(notA); 
// Output: ["b", "n", "n"]

// Example 2: Remove all instances that are NOT 'x' from a string
const clean = "e-x-p-e-r-t".replace(/[^x]/g, "");
console.log(clean); 
// Output: "x"

// Example 3: Check if string contains any non-'0' character
const hasNonZero = /[^0]/.test("000100");
console.log(hasNonZero); 
// Output: true

```

---

## 3. Multiple Character Set: `[abc]`

*Matches any single character listed inside the brackets (`a`, `b`, or `c`).*

```javascript
// Example 1: Match any vowel in a set
const vowelled = "sky line".match(/[aeiou]/g);
console.log(vowelled); 
// Output: ["i", "e"]

// Example 2: Validate if input starts with a specific allowed character prefix
const validPrefix = /^[abc]/.test("cat");
console.log(validPrefix); 
// Output: true

// Example 3: Replace multiple selected punctuation marks
const text = "Hello, world! How's it going?";
const cleaned = text.replace(/[,!?]/g, "");
console.log(cleaned); 
// Output: "Hello world How's it going"

```

---

## 4. Negated Multiple Character Set: `[^abc]`

*Matches any character EXCEPT those specified inside the brackets.*

```javascript
// Example 1: Extract all consonants (excluding vowels)
const consonants = "javascript".match(/[^aeiou]/g);
console.log(consonants); 
// Output: ["j", "v", "s", "c", "r", "p", "t"]

// Example 2: Filter out specific special symbols
const sanitized = "user@name#123".match(/[^@#]/g).join("");
console.log(sanitized); 
// Output: "username123"

// Example 3: Match any character that is NOT a space or newline
const nonSpaces = "a b\nc".match(/[^ \n]/g);
console.log(nonSpaces); 
// Output: ["a", "b", "c"]

```

---

## 5. Character Range Class: `[a-z]`

*Matches any lowercase character in the alphabetical range from `a` to `z`.*

```javascript
// Example 1: Extract all lowercase English letters
const lowerChars = "Apples & Oranges 123".match(/[a-z]/g);
console.log(lowerChars); 
// Output: ["p", "p", "l", "e", "s", "r", "a", "n", "g", "e", "s"]

// Example 2: Check if a string contains any lowercase letter
const hasLowercase = /[a-z]/.test("ALLUPPERCASE");
console.log(hasLowercase); 
// Output: false

// Example 3: Match a specific pattern using custom combined ranges (e.g., lowercase and uppercase)
const lettersOnly = "Code 2026!".match(/[a-zA-Z]/g);
console.log(lettersOnly); 
// Output: ["C", "o", "d", "e"]

```

---

## 6. Negated Character Range Class: `[^a-z]`

*Matches any character that is NOT a lowercase letter in the range from `a` to `z`.*

```javascript
// Example 1: Match all uppercase letters, numbers, and symbols
const nonLower = "Hello 123!".match(/[^a-z]/g);
console.log(nonLower); 
// Output: ["H", " ", "1", "2", "3", "!"]

// Example 2: Strip away all lowercase characters
const stripped = "JavaScript".replace(/[^a-z]/g, "");
console.log(stripped); 
// Output: "avascript" (Wait, [^a-z] matches NON-lowercase, so "J" is stripped)

// Example 3: Test if a password contains non-lowercase characters (like digits or capitals)
const hasSpecialOrUpper = /[^a-z]/.test("password123");
console.log(hasSpecialOrUpper); 
// Output: true

```

---

## 7. Digit Range Class: `[0-9]`

*Matches any numeric character in the range from `0` to `9`.*

```javascript
// Example 1: Extract all individual digits from a string
const phoneDigits = "Call +1 (555) 019-2834".match(/[0-9]/g);
console.log(phoneDigits); 
// Output: ["1", "5", "5", "5", "0", "1", "9", "2", "8", "3", "4"]

// Example 2: Test if a string contains at least one digit
const hasNumber = /[0-9]/.test("User2026");
console.log(hasNumber); 
// Output: true

// Example 3: Match a specific sub-range of digits (e.g., 1 to 5)
const lowScores = "Scores: 1, 8, 4, 9, 3".match(/[1-5]/g);
console.log(lowScores); 
// Output: ["1", "4", "3"]

```

---

## 8. Negated Digit Range Class: `[^0-9]`

*Matches any character that is NOT a digit in the range from `0` to `9`.*

```javascript
// Example 1: Remove all non-digit characters to leave pure numbers
const cleanPhone = "Phone: (123) 456-7890".replace(/[^0-9]/g, "");
console.log(cleanPhone); 
// Output: "1234567890"

// Example 2: Extract non-numeric symbols and words
const wordsOnly = "Item 42 costs 100 dollars".match(/[^0-9]/g).join("");
console.log(wordsOnly); 
// Output: "Item  costs  dollars"

// Example 3: Validate that a string contains NO numbers
const isPureText = /^[^0-9]+$/.test("Hello World");
console.log(isPureText); 
// Output: true

```

## What are Metacharacters?

Metacharacters are characters with special, predefined meanings in regular expressions. Instead of matching literal text, they act as shorthand for common sets of characters—such as digits, word characters, whitespace, or specific character codes.

```javascript
// Matches any alphanumeric word character (shorthand for [a-zA-Z0-9_])
const pattern = /\w/; 

```

---

## 1. Digit Metacharacter (`\d`)

*Matches any numeric digit (equivalent to `[0-9]`).*

```javascript
// Example 1: Extract all individual digits from a string
const digits = "Order #4092 created".match(/\d/g);
console.log(digits); 
// Output: ["4", "0", "9", "2"]

// Example 2: Check if string contains at least one digit
console.log(/\d/.test("Room 101")); 
// Output: true

// Example 3: Match a 3-digit area code pattern
const areaCode = "(555) 012-3456".match(/\(\d{3}\)/);
console.log(areaCode[0]); 
// Output: "(555)"

```

---

## 2. Non-Digit Metacharacter (`\D`)

*Matches any character that is NOT a numeric digit (equivalent to `[^0-9]`).*

```javascript
// Example 1: Strip all non-digit characters to isolate a phone number
const phone = "Call: +1-800-555-0199".replace(/\D/g, "");
console.log(phone); 
// Output: "18005550199"

// Example 2: Match non-numeric characters from a string
const nonDigits = "ABC123XYZ".match(/\D+/g);
console.log(nonDigits); 
// Output: ["ABC", "XYZ"]

// Example 3: Ensure a username does not start with a digit
console.log(/^\D/.test("User1")); 
// Output: true

```

---

## 3. Word Metacharacter (`\w`)

*Matches any alphanumeric word character, including letters, digits, and underscores (equivalent to `[a-zA-Z0-9_]`).*

```javascript
// Example 1: Extract all word tokens from a sentence
const words = "Hello_World 2026!".match(/\w+/g);
console.log(words); 
// Output: ["Hello_World", "2026"]

// Example 2: Validate a basic username format (letters, digits, underscores)
const isValidUsername = /^\w+$/.test("admin_user_01");
console.log(isValidUsername); 
// Output: true

// Example 3: Match individual alphanumeric characters
console.log("A#1".match(/\w/g)); 
// Output: ["A", "1"]

```

---

## 4. Non-Word Metacharacter (`\W`)

*Matches any character that is NOT an alphanumeric character or underscore (equivalent to `[^a-zA-Z0-9_]`).*

```javascript
// Example 1: Extract all punctuation and symbols
const symbols = "Hello, world!".match(/\W/g);
console.log(symbols); 
// Output: [",", " ", "!"]

// Example 2: Replace non-word characters with dashes for URL slugs
const slug = "JavaScript & Regex!".toLowerCase().replace(/\W+/g, "-");
console.log(slug); 
// Output: "javascript-regex-"

// Example 3: Test if a password contains special characters
console.log(/\W/.test("Password123!")); 
// Output: true

```

---

## 5. Whitespace Metacharacter (`\s`)

*Matches any single whitespace character, including spaces, tabs (`\t`), newlines (`\n`), and carriage returns (`\r`).*

```javascript
// Example 1: Split a sentence into words by space boundaries
const tokens = "One\ttwo\nthree four".split(/\s+/);
console.log(tokens); 
// Output: ["One", "two", "three", "four"]

// Example 2: Remove leading/trailing spaces
const trimmed = "  hello world  ".replace(/^\s+|\s+$/g, "");
console.log(trimmed); 
// Output: "hello world"

// Example 3: Detect if string contains any spaces or line breaks
console.log(/\s/.test("NoSpacesHere")); 
// Output: false

```

---

## 6. Non-Whitespace Metacharacter (`\S`)

*Matches any character that is NOT a whitespace character.*

```javascript
// Example 1: Extract all non-whitespace character sequences
const nonSpaces = "  cat  dog  ".match(/\S+/g);
console.log(nonSpaces); 
// Output: ["cat", "dog"]

// Example 2: Validate that an input is not just empty whitespace
console.log(/\S/.test("    ")); 
// Output: false

// Example 3: Count total non-whitespace characters in text
const count = "a b c d".match(/\S/g).length;
console.log(count); 
// Output: 4

```

---

## 7. Octal Number Metacharacter (`\ddd`)

*Matches a character specified by an octal number `ddd` (1 to 3 octal digits).*

```javascript
// Example 1: Match capital letter 'A' using its octal code \101 (65 in decimal)
console.log(/\101/.test("Apple")); 
// Output: true

// Example 2: Replace octal-encoded space \040 with an underscore
console.log("hello world".replace(/\040/g, "_")); 
// Output: "hello_world"

// Example 3: Extract character sequence matching octal codes \103 \101 \124 ("CAT")
const result = "CAT DOG".match(/\103\101\124/g);
console.log(result); 
// Output: ["CAT"]

```

---

## 8. Hexadecimal Number Metacharacter (`\xhh`)

*Matches a character specified by a 2-digit hexadecimal number `hh`.*

```javascript
// Example 1: Match the copyright symbol '©' using its hex code \xA9
console.log(/\xA9/.test("Copyright © 2026")); 
// Output: true

// Example 2: Replace hexadecimal newline \x0A with a space
console.log("Line 1\x0ALine 2".replace(/\x0A/g, " ")); 
// Output: "Line 1 Line 2"

// Example 3: Match the dollar sign '$' using hex \x24
console.log(/\x24\d+/.test("$100")); 
// Output: true

```

---

## 9. Unicode Metacharacter (`\uhhhh`)

*Matches a Unicode character specified by a 4-digit hexadecimal number `hhhh`.*

```javascript
// Example 1: Match the Euro currency symbol '€' using \u20AC
console.log(/\u20AC/.test("Price: 50€")); 
// Output: true

// Example 2: Match a non-English script character (e.g., Japanese Hiragana 'あ' \u3042)
console.log(/\u3042/.test("あかね")); 
// Output: true

// Example 3: Match white star symbol '☆' (\u2606) in rating strings
const star = "Rating: ☆☆☆".match(/\u2606/g);
console.log(star.length); 
// Output: 3

```

---

## What are Assertions?

Assertions do not match actual characters themselves. Instead, they test conditions about the string—such as checking if a match occurs at a boundary or checking what characters come immediately before or after a target pattern (Lookarounds).

---

## 1. Beginning of String Boundary (`^`)

*Asserts that the match must occur at the very start of the string (or start of a line with the `/m` multiline flag).*

```javascript
// Example 1: Check if a string starts with "Hello"
console.log(/^Hello/.test("Hello world")); 
// Output: true

// Example 2: Extract protocol from the beginning of a URL
const url = "https://example.com";
console.log(url.match(/^https?/)[0]); 
// Output: "https"

// Example 3: Enforce strict input validation (must start with digits)
console.log(/^\d+/.test("123abc")); 
// Output: true

```

---

## 2. End of String Boundary (`$`)

*Asserts that the match must occur at the very end of the string (or end of a line with the `/m` multiline flag).*

```javascript
// Example 1: Validate file extension ending in .pdf
console.log(/\.pdf$/.test("document.pdf")); 
// Output: true

// Example 2: Match trailing punctuation
const sentence = "Where are you going?";
console.log(/\?$/.test(sentence)); 
// Output: true

// Example 3: Strict exact match combining ^ and $ (must contain ONLY digits)
console.log(/^\d+$/.test("12345")); 
// Output: true

```

---

## 3. Word Boundary (`\b`)

*Asserts a position where one side is a word character (`\w`) and the other side is NOT a word character (e.g., space, punctuation, or string edge).*

```javascript
// Example 1: Match whole word "cat" (ignores "caterpillar" or "bobcat")
const text = "The cat in the caterpillar";
console.log(text.match(/\bcat\b/g)); 
// Output: ["cat"]

// Example 2: Find words starting with "pre"
console.log("preview preparation prevent".match(/\bpre\w+/g)); 
// Output: ["preview", "preparation", "prevent"]

// Example 3: Find words ending with "ing"
console.log("playing sing coding".match(/\w+ing\b/g)); 
// Output: ["playing", "coding"]

```

---

## 4. Non-Word Boundary (`\B`)

*Asserts a position that is NOT a word boundary (i.e., inside a word or between two non-word characters).*

```javascript
// Example 1: Match "cat" only when embedded inside another word
console.log("caterpillar".match(/\Bcat/)); 
// Output: null (starts with boundary), but match inside word works:
console.log("bobcat".match(/cat\B/)); // Output: null (ends with boundary)
console.log("scattered".match(/\Bcat\B/)[0]); 
// Output: "cat"

// Example 2: Find instances of "in" NOT at the beginning of a word
console.log("inside painting spin".match(/\Bin\w*/g)); 
// Output: ["ing", "in"]

// Example 3: Match digits embedded inside letters (e.g., "A123B")
console.log("A123B".match(/\B\d+\B/)[0]); 
// Output: "123"

```

---

## 5. Positive Lookahead (`(?=...)`)

*Asserts that the main pattern MUST be followed by the condition inside `(?=...)`, without including it in the match result.*

```javascript
// Example 1: Match price digits ONLY if followed by a USD symbol
const text = "100USD and 200EUR";
console.log(text.match(/\d+(?=USD)/g)); 
// Output: ["100"]

// Example 2: Password validation (asserts input contains at least one digit)
const hasDigit = /^(?=.*\d)\w{6,}$/.test("secret123");
console.log(hasDigit); 
// Output: true

// Example 3: Match a word only if followed by a specific punctuation
console.log("Hello! World.".match(/\w+(?=\!)/)[0]); 
// Output: "Hello"

```

---

## 6. Negative Lookahead (`(?!...)`)

*Asserts that the main pattern MUST NOT be followed by the condition inside `(?!...)`.*

```javascript
// Example 1: Match numbers NOT followed by "px"
const css = "10px 20em 30px 40rem";
console.log(css.match(/\d+(?!px)/g)); 
// Output: ["20", "40"]

// Example 2: Match "Java" only when NOT followed by "Script"
console.log("Java, JavaScript, Java8".match(/Java(?!Script)/g)); 
// Output: ["Java", "Java"]

// Example 3: Match words that do NOT start with 'un'
console.log("happy unhappy certain".match(/\b(?!un)\w+/g)); 
// Output: ["happy", "certain"]

```

---

## 7. Positive Lookbehind (`(?<=...)`)

*Asserts that the main pattern MUST be preceded by the condition inside `(?<=...)`, without including it in the match result.*

```javascript
// Example 1: Match monetary amounts preceded by a dollar sign
const prices = "Cost: $50 and €40";
console.log(prices.match(/(?<=\$)\d+/g)); 
// Output: ["50"]

// Example 2: Extract domain names preceded by "@"
console.log("user@gmail.com".match(/(?<=@)\w+/)[0]); 
// Output: "gmail"

// Example 3: Match word directly preceded by "super"
console.log("superman superhero Batman".match(/(?<=super)\w+/g)); 
// Output: ["man", "hero"]

```

---

## 8. Negative Lookbehind (`(?<!...)`)

*Asserts that the main pattern MUST NOT be preceded by the condition inside `(?<!...)`.*

```javascript
// Example 1: Match numbers NOT preceded by a dollar sign
const invoice = "$100 and 200";
console.log(invoice.match(/(?<!\$)\b\d+/g)); 
// Output: ["200"]

// Example 2: Match "cat" NOT preceded by "wild"
console.log("wildcat housecat".match(/(?<!wild)cat/g)); 
// Output: ["cat"] (matches 'cat' inside 'housecat')

// Example 3: Match digits NOT preceded by a minus sign (positive numbers only)
console.log("-50 and 50".match(/(?<!-)\b\d+/g)); 
// Output: ["50"]

```

Here is a complete guide to **JavaScript Regex Groups**, covering Capturing Groups, Named Capturing Groups, Non-Capturing Groups, Lookarounds, and Inline Flag Groups with 3 concrete code examples for each type.

---

## What are Groups?

Groups allow you to group multiple characters together using parentheses `(...)` so they can be treated as a single unit, extracted individually, or modified with specific options or quantifiers.

---

## 1. Capturing Group (`(x)`)

*Matches `x` and remembers the matched text in numbered indices (`$1`, `$2`, etc., or index `1`, `2` in match arrays).*

```javascript
// Example 1: Extract date components (year, month, day)
const dateStr = "2026-08-07";
const match = dateStr.match(/(\d{4})-(\d{2})-(\d{2})/);
console.log(match[1], match[2], match[3]); 
// Output: "2026" "08" "07"

// Example 2: Swap two words using backreferences in replace
const name = "Doe, John";
const formatted = name.replace(/(\w+),\s*(\w+)/, "$2 $1");
console.log(formatted); 
// Output: "John Doe"

// Example 3: Match repeated words using backreferences (\1)
const text = "the the cat sat";
console.log(text.match(/\b(\w+)\s+\1\b/)[1]); 
// Output: "the"

```

---

## 2. Named Capturing Group (`(?<name>x)`)

*Matches `x` and stores the matched text under a named key inside the `groups` property of the match result object.*

```javascript
// Example 1: Extract year, month, day into a named object
const dateStr = "2026-08-07";
const { groups } = dateStr.match(/(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/);
console.log(groups.year, groups.month, groups.day); 
// Output: "2026" "08" "07"

// Example 2: Reformat string using named replacement groups ($<name>)
const phone = "123-456-7890";
const regex = /(?<area>\d{3})-(?<prefix>\d{3})-(?<line>\d{4})/;
console.log(phone.replace(regex, "($<area>) $<prefix>-$<line>")); 
// Output: "(123) 456-7890"

// Example 3: Extract domain and top-level domain from an email
const email = "user@example.com";
const emailMatch = email.match(/@(?<domain>\w+)\.(?<tld>\w+)/);
console.log(emailMatch.groups); 
// Output: { domain: "example", tld: "com" }

```

---

## 3. Non-Capturing Group (`(?:x)`)

*Groups `x` together logically (e.g., to apply a quantifier like `+` or `*`) without allocating a capture index memory for it.*

```javascript
// Example 1: Apply quantifier (+) to a multi-character sequence without capturing
const text = "ha-ha-ha!";
console.log(text.match(/(?:ha-)+/)[0]); 
// Output: "ha-ha-"

// Example 2: Use alternate choices without creating unwanted capture groups
const item = "cat food";
const match = item.match(/(?:cat|dog) food/);
console.log(match[1]); 
// Output: undefined (no capture created)

// Example 3: Optimize extraction performance by capturing only target data
const log = "ERROR: Failed task";
const extracted = log.match(/(?:ERROR|WARN):\s+(\w+)/);
console.log(extracted[1]); 
// Output: "Failed" (only captures the word, ignoring "ERROR")

```

---

## 4. Lookahead Group (`(?=x)`)

*Matches a position only if the pattern is immediately followed by `x`, without including `x` in the match.*

```javascript
// Example 1: Extract monetary values followed by "USD"
const text = "50USD and 100EUR";
console.log(text.match(/\d+(?=USD)/g)); 
// Output: ["50"]

// Example 2: Password validation (asserts input contains at least one digit)
const isValid = /^(?=.*\d)[a-zA-Z0-9]{6,}$/.test("secret2026");
console.log(isValid); 
// Output: true

// Example 3: Match a word only if followed by an exclamation mark
console.log("Hello! World.".match(/\w+(?=\!)/)[0]); 
// Output: "Hello"

```

---

## 5. Lookbehind Group (`(?<=x)`)

*Matches a position only if the pattern is immediately preceded by `x`, without including `x` in the match.*

```javascript
// Example 1: Extract price values preceded by a dollar sign
const invoice = "Total: $250 and €100";
console.log(invoice.match(/(?<=\$)\d+/g)); 
// Output: ["250"]

// Example 2: Extract username preceded by "@"
const handle = "@js_coder".match(/(?<=@)\w+/)[0];
console.log(handle); 
// Output: "js_coder"

// Example 3: Match words directly preceded by "super"
console.log("superman superhero Batman".match(/(?<=super)\w+/g)); 
// Output: ["man", "hero"]

```

---

## 6. Inline Flag Group (`(?flag:x)`)

*Enables specific regex flag(s) (e.g., `i` for case-insensitivity) **only** for the sub-expression `x` within a larger expression.*

```javascript
// Example 1: Enable case-insensitivity only for "hello"
const regex = /(?i:hello) WORLD/;
console.log(regex.test("HeLLo WORLD")); 
// Output: true

// Example 2: Mixed case matching (first word case-insensitive, second word strict)
const pattern = /(?i:javascript) Code/;
console.log(pattern.test("JAVASCRIPT Code")); // Output: true
console.log(pattern.test("JAVASCRIPT code")); // Output: false

// Example 3: Localized case-insensitive keyword search inside a strict template
const userQuery = "select * FROM users";
console.log(/(?i:select)\s+\*\s+(?i:from)\s+\w+/.test(userQuery)); 
// Output: true

```

---

## 7. Disable Flag Group (`(?flag-flag:x)`)

*Disables specific flag(s) for the sub-expression `x` when the outer regex has global flags enabled.*

```javascript
// Example 1: Outer regex is case-insensitive (/i), but inner sub-expression disables it (-i)
const regex = /hello (? -i:WORLD)/i;
console.log(regex.test("HeLLo WORLD")); // Output: true
console.log(regex.test("HeLLo world")); // Output: false (WORLD must be exact uppercase)

// Example 2: Disable multiline anchor matching for a specific sub-pattern
const multilineRegex = /(?-m:^start) \nnext/m;
console.log(multilineRegex.test("start \nnext")); 
// Output: true

// Example 3: Disable case-insensitivity for a target ID code
const orderPattern = /order-(?-i:[A-Z]{3})-\d+/i;
console.log(orderPattern.test("ORDER-ABC-123")); // Output: true
console.log(orderPattern.test("ORDER-abc-123")); // Output: false ("abc" fails due to -i)

```

## What are Quantifiers?

Quantifiers specify **how many times** the preceding character, character class, or group must appear in a string for a match to occur.

```javascript
// Match one or more consecutive zeros
const pattern = /0+/; 

```

---

## 1. At Least One Quantifier (`x+`)

*Matches 1 or more consecutive occurrences of `x` (greedy by default).*

```javascript
// Example 1: Extract all sequences of digits
const numbers = "Item 1 costs 200 dollars".match(/\d+/g);
console.log(numbers); 
// Output: ["1", "200"]

// Example 2: Match words with repeated letters
console.log(/a+/.test("caaat")); 
// Output: true

// Example 3: Match contiguous non-whitespace character sequences
const words = "Hello   world!".match(/\S+/g);
console.log(words); 
// Output: ["Hello", "world!"]

```

---

## 2. Zero or More Quantifier (`x*`)

*Matches 0 or more occurrences of `x`.*

```javascript
// Example 1: Match 'go' followed by any number of 'o's (including zero)
console.log("g go goo gooo".match/go*/g); 
// Output: ["g", "go", "goo", "gooo"]

// Example 2: Match optional leading spaces
const leadingSpaces = "   hello".match(/^\s*/)[0];
console.log(leadingSpaces.length); 
// Output: 3

// Example 3: Extract digits surrounded by optional zeros
console.log("007".match(/0*7/)[0]); 
// Output: "007"

```

---

## 3. Zero or One / Optional Quantifier (`x?`)

*Matches 0 or 1 occurrence of `x` (makes the preceding token optional).*

```javascript
// Example 1: Match both American and British spellings ("color" or "colour")
const regex = /colou?r/g;
console.log("color colour".match(regex)); 
// Output: ["color", "colour"]

// Example 2: Match optional http/https protocol
const urlRegex = /https?:\/\//;
console.log(urlRegex.test("http://example.com")); // Output: true
console.log(urlRegex.test("https://example.com")); // Output: true

// Example 3: Match optional negative sign in numbers
const signedNum = /-?\d+/g;
console.log("-50 and 100".match(signedNum)); 
// Output: ["-50", "100"]

```

---

## 4. Exact Count Quantifier (`x{n}`)

*Matches exactly `n` occurrences of `x`.*

```javascript
// Example 1: Match exactly 4 digits (e.g., year format)
console.log("2026-08-07".match(/\b\d{4}\b/)[0]); 
// Output: "2026"

// Example 2: Validate a 6-digit PIN code
const isValidPin = /^\d{6}$/.test("123456");
console.log(isValidPin); 
// Output: true

// Example 3: Match repeated character patterns (e.g., "zzz")
console.log("sleep zzz now".match(/z{3}/)[0]); 
// Output: "zzz"

```

---

## 5. Range Quantifier (`x{n,m}`)

*Matches between `n` and `m` occurrences of `x` (inclusive).*

```javascript
// Example 1: Match passwords between 8 and 12 characters long
const validLength = /^[a-zA-Z0-9]{8,12}$/.test("myPass123");
console.log(validLength); 
// Output: true

// Example 2: Match numbers with 2 to 4 digits
console.log("1 12 123 1234 12345".match(/\b\d{2,4}\b/g)); 
// Output: ["12", "123", "1234"]

// Example 3: Match HTML headers <h1> through <h6>
const headerTag = /<h[1-6]>/;
console.log(headerTag.test("<h3>")); 
// Output: true

```

---

## 6. At Least `n` Quantifier (`x{n,}`)

*Matches `n` or more occurrences of `x`.*

```javascript
// Example 1: Match words with at least 5 letters
const longWords = "a cat jumped over a tall building".match(/\b\w{5,}\b/g);
console.log(longWords); 
// Output: ["jumped", "building"]

// Example 2: Ensure an input string has at least 3 consecutive digits
console.log(/\d{3,}/.test("Code 9999")); 
// Output: true

// Example 3: Match trailing spaces of at least 2 spaces
console.log("text  ".match(/\s{2,}$/)[0].length); 
// Output: 2

```

Here is the complete reference table for JavaScript Regular Expression flags, followed by related topics and guides for further learning.

## JavaScript RegExp Flag Reference

| Flag | Name             | Description                                                                                                | Year Added |
| ---- | ---------------- | ---------------------------------------------------------------------------------------------------------- | ---------- |
| `/d` | **Indices**      | Generates start and end indices (`indices` array) for matched substrings and capture groups                | 2022       |
| `/g` | **Global**       | Performs a global search, returning all matches rather than stopping after the first match                 | ES1        |
| `/i` | **Ignore Case**  | Makes pattern matching case-insensitive (`A-Z` matches `a-z`)                                              | ES1        |
| `/m` | **Multiline**    | Enables `^` and `$` to match the start and end of each line (`\n`) rather than the entire string           | ES1        |
| `/s` | **DotAll**       | Allows the wildcard dot (`.`) to match line terminators (`\n`, `\r`)                                       | 2018       |
| `/u` | **Unicode**      | Enables full Unicode support, treating surrogate pairs as single characters and enabling `\p{...}`         | 2015       |
| `/v` | **Unicode Sets** | An upgrade to `/u` adding set operations (`--`, `&&`) and multi-character property matching inside `[...]` | 2024       |
| `/y` | **Sticky**       | Matches only from the exact index indicated by the `lastIndex` property of the RegExp object               | 2015       |

## Combining Flags

Flags can be combined in any order after the closing slash `/` delimiter:

```javascript
// Global (/g) + Case-Insensitive (/i)
const regex1 = /javascript/gi;

// Multiline (/m) + DotAll (/s) + Unicode (/u)
const regex2 = /^start.*end$/msu;

```

## 1. Substring Indices Flag (`/d`)

*Generates start and end index bounds (`indices`) for matched substrings and capture groups.*

```javascript
const text = "Hello world";
const regex = /(world)/d;
const result = regex.exec(text);

// Example 1: Get start and end indices of the entire match
console.log(result.indices[0]); 
// Output: [6, 11] (indicates 'world' spans index 6 to 11)

// Example 2: Get start and end indices of capture group 1
console.log(result.indices[1]); 
// Output: [6, 11]

// Example 3: Extract the substring using slice and match indices
const [start, end] = result.indices[0];
console.log(text.slice(start, end)); 
// Output: "world"

```

## 2. Global Match Flag (`/g`)

*Finds all matches in a string rather than stopping at the first match.*

```javascript
const text = "cat bat rat mat";

// Example 1: Extract all matching words into an array
console.log(text.match(/[cbm]at/g)); 
// Output: ["cat", "bat", "mat"]

// Example 2: Replace all digits in a string
console.log("Call 123-456-7890".replace(/\d/g, "#")); 
// Output: "Call ###-###-####"

// Example 3: Count total occurrences using matchAll()
const matches = [... "test1 test2 test3".matchAll(/test\d/g)];
console.log(matches.length); 
// Output: 3

```

## 3. Case-Insensitive Matching Flag (`/i`)

*Ignores character casing (uppercase vs. lowercase).*

```javascript
// Example 1: Basic case-insensitive test
console.log(/hello/i.test("HeLLo World")); 
// Output: true

// Example 2: Replace words regardless of capitalization
console.log("JavaScript javascript JAVASCRIPT".replace(/javascript/gi, "JS")); 
// Output: "JS JS JS"

// Example 3: Filter string variants
const names = ["Alice", "ALICE", "alice"];
const result = names.filter(name => /^alice$/i.test(name));
console.log(result); 
// Output: ["Alice", "ALICE", "alice"]

```

## 4. Multiline Matching Flag (`/m`)

*Causes `^` and `$` to match the start/end of **each line** within a multiline string, rather than just the full string boundary.*

```javascript
const poem = `First line\nSecond line\nThird line`;

// Example 1: Match 'line' at the end of every individual line
console.log(poem.match(/line$/gm)); 
// Output: ["line", "line", "line"]

// Example 2: Match words at the beginning of each line
console.log(poem.match(/^[A-Z]\w+/gm)); 
// Output: ["First", "Second", "Third"]

// Example 3: Find markdown header lines starting with '#'
const markdown = "# Title\nParagraph\n# Heading 2";
console.log(markdown.match(/^# .*/gm)); 
// Output: ["# Title", "# Heading 2"]

```

## 5. DotAll / Single-line Flag (`/s`)

*Allows the wildcard dot (`.`) character to match newline characters (`\n`, `\r`).*

```javascript
const codeBlock = "function() {\n  return true;\n}";

// Example 1: Match text spanning across multiple lines
console.log(/function\(\) \{.*?\}/s.test(codeBlock)); 
// Output: true

// Example 2: Extract content inside multi-line HTML tags
const html = "<div>\n  <p>Hello</p>\n</div>";
console.log(html.match(/<div>.*<\/div>/s)[0]); 
// Output: "<div>\n  <p>Hello</p>\n</div>"

// Example 3: Capture multi-line comments
const code = "/* \n Multi-line \n Comment \n */";
console.log(code.match(/\/\*.*\*\//s)[0]); 
// Output: "/* \n Multi-line \n Comment \n */"

```

## 6. Unicode Support Flag (`/u`)

*Enables full Unicode handling, treating surrogate pairs as single characters and enabling Unicode property escapes (`\p{...}`).*

```javascript
// Example 1: Match multi-byte Unicode characters (emojis) as single items
console.log(/^.$/u.test("😊")); 
// Output: true

// Example 2: Match letters from specific scripts using Unicode properties
console.log(/\p{Script=Greek}/u.test("Ω")); 
// Output: true

// Example 3: Match letters across international alphabets
console.log(/\p{L}+/gu.test("München")); 
// Output: ["München"]

```

## 7. Unicode Sets Flag (`/v`)

*An upgrade to the `/u` flag. Adds set operations (`--` difference, `&&` intersection) and multi-character emoji properties inside character classes.*

```javascript
// Example 1: Set subtraction - Match Greek letters EXCEPT vowels
const nonVowelGreek = /[\p{Script=Greek}--\x{03B1}\x{03B5}\x{03B7}\x{03B9}]/v;
console.log(nonVowelGreek.test("β")); 
// Output: true

// Example 2: Set intersection - Match characters that are BOTH Greek AND Symbols
const greekSymbol = /[\p{Script=Greek}&&[Ω]]/v;
console.log(greekSymbol.test("Ω")); 
// Output: true

// Example 3: Match multi-character emoji properties (e.g., flag emojis)
console.log(/^\p{RGI_Emoji}$/v.test("🇺🇸")); 
// Output: true

```

## 8. Sticky Search Flag (`/y`)

*Matches strictly from the position specified by the `lastIndex` property without searching forward.*

```javascript
const str = "12 34 56";
const regex = /\d+/y;

// Example 1: Match starting at index 0
regex.lastIndex = 0;
console.log(regex.exec(str)[0]); 
// Output: "12"

// Example 2: Fails when lastIndex points to a space instead of a digit
regex.lastIndex = 2; // Index 2 is a space ' '
console.log(regex.exec(str)); 
// Output: null

// Example 3: Advance manually for a custom tokenizer loop
const tokenRegex = /\w+/y;
const code = "const x";

tokenRegex.lastIndex = 0;
console.log(tokenRegex.exec(code)[0]); // Output: "const"

tokenRegex.lastIndex = 6; // Jump directly to index 6 ('x')
console.log(tokenRegex.exec(code)[0]); // Output: "x"

```

In JavaScript, the **`RegExp` object** is a built-in object used for matching text with patterns. You can create a `RegExp` object in two ways:

1. **Literal Notation:** `/pattern/flags`
2. **Constructor Function:** `new RegExp("pattern", "flags")`

The `RegExp` object provides properties to inspect regex configuration, along with built-in methods (`test()`, `exec()`) and `String` methods (`match()`, `replace()`, `split()`, `search()`, `matchAll()`) to perform pattern matching.

---

## 1. Creating a `RegExp` Object

You can construct regular expressions either statically (literal syntax) or dynamically (constructor syntax).

```javascript
// Example 1: Literal notation (compiled at script load time)
const regexLiteral = /hello\d+/i;
console.log(regexLiteral.test("Hello123")); 
// Output: true

// Example 2: Constructor notation with a string pattern
const patternStr = "user_\\d+"; // Note: Backslashes must be escaped with \\
const regexDynamic = new RegExp(patternStr, "g");
console.log("user_1 user_2".match(regexDynamic)); 
// Output: ["user_1", "user_2"]

// Example 3: Constructor using an existing RegExp object (copying/modifying flags)
const baseRegex = /[a-z]+/
const modifiedRegex = new RegExp(baseRegex, "g");
console.log("cat dog".match(modifiedRegex)); 
// Output: ["cat", "dog"]

```

---

## 2. `RegExp.prototype.test()`

*Tests whether a string matches the regular expression pattern. Returns `true` or `false`.*

```javascript

// Output: true

// Example 2: Validating an email format prefix

// Output: true

// Example 3: Checking if a string does NOT contain forbidden characters

// Output: true

```

## 3. `RegExp.prototype.exec()`

*Executes a search for a match in a string. Returns a result array containing captured groups and match metadata, or `null` if no match is found.*

```javascript
// Example 1: Extracting matches and capture groups

console.log(matchResult[0]); // Full match: "Item 42"
console.log(matchResult[1]); // Group 1: "Item"
console.log(matchResult[2]); // Group 2: "42"

// Example 2: Iterating through matches with the global (/g) flag

}
// Output: 
// "Found four at index 0"
// "Found five at index 5"

// Example 3: Accessing named capture groups via exec()
const dateRegex = /(?<year>\d{4})-(?<month>\d{2})/;

console.log(result.groups.year); 
// Output: "2026"

```

## 4. `RegExp` Properties


```javascript
// Output: true

// Example 2: Check when /g is absent

// Output: false

  return re.global ? "Matches all" : "Matches first";
}
console.log(checkGlobal(/\d+/g)); 
// Output: "Matches all"

```

## Part 2: RegExp String Methods

### 1. `String.prototype.match(regexp)`

*Retrieves matched elements as an Array. Without `/g`, returns detailed match data; with `/g`, returns an array of all matched strings.*

```javascript
// Example 1: Non-global match (returns array with capture groups & index)
const result = "cat 123".match(/(\w+)\s(\d+)/);
console.log(result[0], result[1], result[2]); 
// Output: "cat 123" "cat" "123"

// Example 2: Global match (returns simple array of all matches)
const allNumbers = "10 apples, 20 oranges".match(/\d+/g);
console.log(allNumbers); 
// Output: ["10", "20"]

// Example 3: Return null when no match is found
console.log("hello".match(/\d+/)); 
// Output: null

```

---

### 2. `String.prototype.matchAll(regexp)`

*Returns an Iterator yielding full match arrays (including capture groups) for every match in the string. Requires the `/g` flag.*

```javascript
// Example 1: Iterate over all matches with capture groups
const str = "test1 test2";
const matches = [...str.matchAll(/test(\d)/g)];
console.log(matches[0][1], matches[1][1]); 
// Output: "1" "2"

// Example 2: Destructure named groups in a loop
const log = "USER: alice, USER: bob";
for (const match of log.matchAll(/USER:\s*(?<name>\w+)/g)) {
  console.log(match.groups.name);
}
// Output: "alice", "bob"

// Example 3: Convert iterator to array of matched values
const res = Array.from("A1 B2 C3".matchAll(/([A-Z])(\d)/g), m => m[0]);
console.log(res); 
// Output: ["A1", "B2", "C3"]

```

---

### 3. `String.prototype.replace(regexp, replacement)`

*Returns a new string where matched pattern(s) are replaced by a replacement string or function.*

```javascript
// Example 1: Replace first match or all matches (if /g is used)
console.log("cat bat rat".replace(/[cbr]at/g, "animal")); 
// Output: "animal animal animal"

// Example 2: Use replacement backreferences ($1, $2)
const formatted = "Doe, John".replace(/(\w+),\s*(\w+)/, "$2 $1");
console.log(formatted); 
// Output: "John Doe"

// Example 3: Use a replacer function
const uppercaseNum = "item1 item2".replace(/\d+/g, (n) => Number(n) * 10);
console.log(uppercaseNum); 
// Output: "item10 item20"

```

---

### 4. `String.prototype.replaceAll(regexp, replacement)`

*Returns a new string replacing ALL occurrences matching the regexp. **Note:** The regexp MUST have the `/g` flag set, or it throws a `TypeError`.*

```javascript
// Example 1: Replace all digits across string
console.log("1-800-555-0199".replaceAll(/\d/g, "#")); 
// Output: "#-###-###-####"

// Example 2: Replace all spaces with dashes
const slug = "hello world from js".replaceAll(/\s+/g, "-");
console.log(slug); 
// Output: "hello-world-from-js"

// Example 3: Use replacer function for all matches
const result = "a b c".replaceAll(/[a-z]/g, char => char.toUpperCase());
console.log(result); 
// Output: "A B C"

```


### 6. `String.prototype.split(regexp)`

*Splits a String into an Array of substrings using a regular expression as the delimiter.*

