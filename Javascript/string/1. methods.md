## 1. Character Access & Positional Lookup

| Method / Syntax          | Description                                                                    | Example              | Output   |
| ------------------------ | ------------------------------------------------------------------------------ | -------------------- | -------- |
| **`length`**             | Property returning the total code units in the string.                         | `"Hello".length`     | `5`      |
| **`charAt(index)`**      | Returns the character at the specified index. Returns `""` if out of bounds.   | `"Hello".charAt(1)`  | `"e"`    |
| **`charCodeAt(index)`**  | Returns the UTF-16 code unit integer (0–65535) at index.                       | `"A".charCodeAt(0)`  | `65`     |
| **`codePointAt(index)`** | Returns non-negative integer code point value (handles 32-bit Unicode/emojis). | `"😀".codePointAt(0)` | `128512` |
| **`at(index)`**          | Modern relative indexing; **supports negative indices** from the end.          | `"Hello".at(-1)`     | `"o"`    |
| **`string[index]`**      | Array-like bracket access. Returns `undefined` if out of bounds.               | `"Hello"[0]`         | `"H"`    |

```javascript
const str = "JavaScript";

console.log(str.length);         // 10
console.log(str.charAt(4));       // "S"
console.log(str.charCodeAt(0));   // 74
console.log(str.at(-2));         // "p"
console.log(str[0]);             // "J"

```

## 2. Extracting Substrings

| Method                      | Syntax                      | Behavior                                                                                       |
| --------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------- |
| **`slice(start, end)`**     | `str.slice(begin, end)`     | Extracts from `start` up to (not including) `end`. **Supports negative indices**.              |
| **`substring(start, end)`** | `str.substring(begin, end)` | Similar to `slice()`, but treats negative values as `0` and swaps parameters if `start > end`. |
| **`substr(start, length)`** | `str.substr(start, length)` | **Deprecated/Legacy**. Extracts a length of characters starting from an index.                 |

```javascript
const text = "Mozilla Developer";

// slice vs substring with positive indices
console.log(text.slice(0, 7));        // "Mozilla"
console.log(text.substring(0, 7));    // "Mozilla"

// Negative indices behavior
console.log(text.slice(-9));          // "Developer" (counts from right)
console.log(text.substring(-9, 7));   // "Mozilla" (treats -9 as 0)

// Legacy substr
console.log(text.substr(0, 7));       // "Mozilla" (7 characters from index 0)

```

## 3. String Combination, Case & Normalization

```javascript
// concat() - Combines two or more strings (prefer + or template literals in modern JS)
const greeting = "Hello".concat(" ", "World!"); // "Hello World!"

// Case conversion
console.log("hello".toUpperCase());             // "HELLO"
console.log("WORLD".toLowerCase());             // "world"

// Well-Formedness (Handling lone surrogates / corrupt Unicode)
const corruptStr = "Hello \uD800"; // Lone surrogate character

console.log(corruptStr.isWellFormed());         // false
console.log(corruptStr.toWellFormed());         // "Hello " (replaces corrupt code with replacement char)

```

## 4. Trimming, Padding & Repeating

```javascript
const padded = "   Hello World!   ";

// Trimming whitespace
console.log(padded.trim());       // "Hello World!"
console.log(padded.trimStart());  // "Hello World!   "
console.log(padded.trimEnd());    // "   Hello World!"

// Padding strings (useful for formatting numbers/dates)
const ID = "42";
console.log(ID.padStart(5, "0")); // "00042"
console.log(ID.padEnd(5, "*"));   // "42***"

// Repeat string
console.log("Ha".repeat(3));      // "HaHaHa"

```

## 5. Replacing Content

```javascript
const phrase = "The red fox jumps over the red fence";

// replace() - Replaces ONLY the FIRST match (string or regex)
console.log(phrase.replace("red", "blue")); 
// Output: "The blue fox jumps over the red fence"

// replaceAll() - Replaces ALL matches (requires string or global regex /g)
console.log(phrase.replaceAll("red", "blue")); 
// Output: "The blue fox jumps over the blue fence"

```

## 6. `split()` — Real-World Practical Scenarios

`split(separator, limit)` divides a string into an ordered list of substrings and puts them into an array.

### Scenario 1: Parsing CSV (Comma-Separated Values) Data

```javascript
const csvRow = "John,Doe,30,Software Engineer,New York";

// Split string into individual fields
const userData = csvRow.split(",");

console.log(userData); 
// Output: [ 'John', 'Doe', '30', 'Software Engineer', 'New York' ]

const [firstName, lastName, age, job] = userData;
console.log(`${firstName} ${lastName} is a ${age}-year-old ${job}.`);
// Output: "John Doe is a 30-year-old Software Engineer."

```

### Scenario 2: Extracting File Name and Extension

```javascript
const filename = "user_profile_avatar.v2.png";

// Split by dot
const parts = filename.split(".");

// Get the extension (last element)
const extension = parts.pop(); 
const baseName = parts.join("."); 

console.log(`Base: ${baseName}, Ext: ${extension}`);
// Output: "Base: user_profile_avatar.v2, Ext: png"

```

### Scenario 3: Sanitizing & Normalizing User Input with Regex Split

Splitting text on multiple spaces or punctuation delimiters using Regular Expressions:

```javascript
const messyInput = "JavaScript; Python, C++  Java   Go";

// Split by commas, semicolons, or any number of whitespace characters
const languages = messyInput.split(/[\s,;]+/);

console.log(languages);
// Output: [ 'JavaScript', 'Python', 'C++', 'Java', 'Go' ]

```

## 1. String Searching & Checking Methods

These methods inspect a string to locate substrings or verify conditions.

| Method              | Syntax                                  | Description                                                      | Returns   |
| ------------------- | --------------------------------------- | ---------------------------------------------------------------- | --------- |
| **`includes()`**    | `str.includes(searchStr, position)`     | Checks if `searchStr` exists inside the string.                  | `boolean` |
| **`startsWith()`**  | `str.startsWith(searchStr, position)`   | Checks if string begins with `searchStr`.                        | `boolean` |
| **`endsWith()`**    | `str.endsWith(searchStr, length)`       | Checks if string ends with `searchStr`.                          | `boolean` |
| **`indexOf()`**     | `str.indexOf(searchStr, fromIndex)`     | Returns the **first index** where `searchStr` is found, or `-1`. | `number`  |
| **`lastIndexOf()`** | `str.lastIndexOf(searchStr, fromIndex)` | Returns the **last index** where `searchStr` is found, or `-1`.  | `number`  |

### Code Example

```javascript
const sentence = "The quick brown fox jumps over the lazy dog";

// Checking existence
console.log(sentence.includes("fox"));        // true
console.log(sentence.startsWith("The"));      // true
console.log(sentence.endsWith("dog"));        // true

// Finding positions
console.log(sentence.indexOf("o"));           // 12 (first 'o' in 'brown')
console.log(sentence.lastIndexOf("o"));       // 41 (last 'o' in 'dog')
console.log(sentence.indexOf("cat"));         // -1 (not found)

```

## 2. Pattern Matching & Regular Expressions

These methods use Regular Expressions (`RegExp`) to search, extract, or iterate over matches.

| Method                | Description                                                                             |
| --------------------- | --------------------------------------------------------------------------------------- |
| **`match(regex)`**    | Matches a regular expression against the string. Returns an array of matches or `null`. |
| **`matchAll(regex)`** | Returns an iterator yielding all matching groups (requires the global `/g` flag).       |
| **`search(regex)`**   | Executes a search for a match and returns the index of the first match, or `-1`.        |

### Code Example

```javascript
const text = "Orders: #1024, #2048, and #4096";
const regex = /#(\d+)/g;

// match() - Basic extraction
console.log(text.match(/#\d+/g)); 
// Output: [ '#1024', '#2048', '#4096' ]

// matchAll() - Extraction with capture groups (Iterator)
const matches = [...text.matchAll(regex)];
for (const m of matches) {
  console.log(`Match: ${m[0]}, Group ID: ${m[1]}`);
}
// Output:
// Match: #1024, Group ID: 1024
// Match: #2048, Group ID: 2048
// Match: #4096, Group ID: 4096

// search() - Finds first position of match
console.log(text.search(/\d+/)); // 9 (index where '1024' starts)

```

## 3. Localization & Unicode Comparison

JavaScript handles internationalization and accent/language sensitivity through these methods.

| Method                | Description                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------ |
| **`localeCompare()`** | Compares two strings in the current or specified locale (useful for sorting non-English alphabets).          |
| **`normalize()`**     | Normalizes Unicode strings into standard form (e.g., combining accented characters into single code points). |

### Code Example

```javascript
// localeCompare() - Array sorting in different languages
const items = ["ä", "a", "z"];

// Standard ASCII sort (incorrect for German)
console.log([...items].sort()); // [ 'a', 'z', 'ä' ]

// Locale-aware sort for German
console.log([...items].sort((a, b) => a.localeCompare(b, "de"))); // [ 'a', 'ä', 'z' ]

// normalize() - Unicode composition
const str1 = "\u00E9";       // "é" (single code point)
const str2 = "e\u0301";      // "e" + "◌́" (combining accent mark)

console.log(str1 === str2);                     // false (different byte sequences)
console.log(str1 === str2.normalize());         // true (canonical normalization)

```
