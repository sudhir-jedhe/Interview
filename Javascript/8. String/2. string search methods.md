Here is a complete, practical guide covering all **JavaScript String Search Methods**—explaining how they work, their key differences, and when to use each.

---

## Quick Reference Summary

| Method              | Accepts Regex?        | Returns    | Primary Use Case                                                   |
| ------------------- | --------------------- | ---------- | ------------------------------------------------------------------ |
| **`includes()`**    | ❌ No                  | `boolean`  | Simple existence check (`true`/`false`).                           |
| **`startsWith()`**  | ❌ No                  | `boolean`  | Checking if a string starts with a prefix.                         |
| **`endsWith()`**    | ❌ No                  | `boolean`  | Checking if a string ends with a suffix/extension.                 |
| **`indexOf()`**     | ❌ No                  | `number`   | Finding the **first** index position of a substring.               |
| **`lastIndexOf()`** | ❌ No                  | `number`   | Finding the **last** index position of a substring.                |
| **`search()`**      | ✅ Yes                 | `number`   | Finding the **first** index using regular expressions.             |
| **`match()`**       | ✅ Yes                 | `Array`    | `null`                                                             | Extracting matched substrings or capture groups. |
| **`matchAll()`**    | ✅ Yes (must use `/g`) | `Iterator` | Iterating through all global matches with detailed capture groups. |

---

## 1. Boolean Search Methods (Existence Checks)

These methods return `true` or `false` and are ideal for standard conditional checks (`if` statements).

```javascript
const filename = "invoice_2026_final.pdf";

// includes(searchString, position)
console.log(filename.includes("2026"));      // true
console.log(filename.includes("2026", 15));  // false (starts searching from index 15)

// startsWith(searchString, position)
console.log(filename.startsWith("invoice")); // true
console.log(filename.startsWith("2026", 8)); // true (checks if index 8 starts with "2026")

// endsWith(searchString, length)
console.log(filename.endsWith(".pdf"));      // true
console.log(filename.endsWith("2026", 12));  // true (considers only first 12 chars)

```

---

## 2. Positional Search Methods (Index Finding)

These return the index position (`0` or positive integer) of a match, or **`-1`** if the target is not found.

### `indexOf()` vs `lastIndexOf()`

* **`indexOf(searchValue, fromIndex)`**: Searches **forward** from the beginning.
* **`lastIndexOf(searchValue, fromIndex)`**: Searches **backward** from the end.

```javascript
const quote = "To be, or not to be, that is the question.";

console.log(quote.indexOf("be"));        // 3  (first 'be' at index 3)
console.log(quote.lastIndexOf("be"));    // 16 (last 'be' at index 16)

console.log(quote.indexOf("hamlet"));    // -1 (not found)

```

### `search()` (Regex Index Search)

Unlike `indexOf()`, `search()` accepts a Regular Expression. It returns the index of the **first** match.

```javascript
const text = "User logged in at 09:45 AM";

// Find the index where any digit sequence starts
console.log(text.search(/\d+/)); // 18

// Case-insensitive regex search
console.log(text.search(/LOGGED/i)); // 5

```

## 3. Pattern Extraction Methods (`match` & `matchAll`)

These methods retrieve the actual matched text and capture groups.

### `match()`

Behavior depends on whether the Regular Expression has the global (`/g`) flag:

1. **Without `/g**`: Returns an array for the first match with detailed information (index, input, groups).
2. **With `/g**`: Returns an array containing **all** matching substrings (omitting capture groups).

```javascript
const str = "Price: $45 and Tax: $5";

// 1. Without /g - Returns detailed match array with capture groups
const singleMatch = str.match(/\$(\d+)/);
console.log(singleMatch[0]); // "$45" (full match)
console.log(singleMatch[1]); // "45"  (first captured group)
console.log(singleMatch.index); // 7

// 2. With /g - Returns array of all matches
const allMatches = str.match(/\$\d+/g);
console.log(allMatches); // [ '$45', '$5' ]

```

### `matchAll()`

Introduced in ES2020 to solve the limitation of `match()` with `/g`. It returns an **iterator** containing full details (including capture groups) for every global match. *(The regex must use the `/g` flag)*.

```javascript
const log = "Error at line 12, Warning at line 45, Error at line 88";
const regex = /(Error|Warning) at line (\d+)/g;

// Convert iterator to array or iterate with for...of
const results = [...log.matchAll(regex)];

for (const match of results) {
  const [fullMatch, type, lineNumber] = match;
  console.log(`${type} found on line ${lineNumber}`);
}

// Output:
// Error found on line 12
// Warning found on line 45
// Error found on line 88

```

---

## Key Differences to Remember

1. **`indexOf` vs `search**`: Use `indexOf` for simple string literals (it is faster). Use `search` when you need regular expression patterns.
2. **`match` vs `matchAll**`: Use `match(/\d+/g)` if you only care about getting an array of matching strings. Use `matchAll(/\d+/g)` if you need access to **capture groups** or **match indices** for every result.
