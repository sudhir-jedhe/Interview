Here is a massive, rapid-fire collection of exactly **100 output-based questions** designed to test your mastery of **ES6+ (ECMAScript 2015 and beyond)** features, including Scoping, Arrow Functions, Destructuring, Spread/Rest, Classes, and new Data Structures.

To fit all 100 questions, the explanations are distilled into core, one-sentence rules of ES6.

### **Part 1: Block Scoping (`let`, `const`, TDZ)**

**1.** `let x=1; { let x=2; } console.log(x);`
**Out:** `1` | **Why:** `let` is block-scoped. The inner `x` does not overwrite the outer `x`.

**2.** `const a; a=1;`
**Out:** `SyntaxError` | **Why:** `const` declarations must be initialized at the time of declaration.

**3.** `const obj = {a: 1}; obj.a = 2; console.log(obj.a);`
**Out:** `2` | **Why:** `const` prevents reassignment of the variable identifier, but does not make the object properties immutable.

**4.** `console.log(a); let a=1;`
**Out:** `ReferenceError` | **Why:** `let` is hoisted but remains in the Temporal Dead Zone (TDZ) until initialization.

**5.** `let a=1; let a=2;`
**Out:** `SyntaxError` | **Why:** `let` and `const` cannot be redeclared within the same scope.

**6.** `var a=1; let a=2;`
**Out:** `SyntaxError` | **Why:** `let` cannot shadow a `var` declaration in the exact same scope block.

**7.** `{ var x=1; } console.log(x);`
**Out:** `1` | **Why:** `var` is function-scoped, not block-scoped, so it leaks out of the `{}` block.

**8.** `{ let x=1; } console.log(x);`
**Out:** `ReferenceError` | **Why:** `x` is block-scoped and ceases to exist outside the `{}`.

**9.** `for (let i=0; i<2; i++) setTimeout(()=>console.log(i));`
**Out:** `0, 1` | **Why:** `let` creates a fresh lexical scope and a new binding for `i` in each loop iteration.

**10.** `for (var i=0; i<2; i++) setTimeout(()=>console.log(i));`
**Out:** `2, 2` | **Why:** `var` creates one shared binding. The loop finishes before the timeouts run.

**11.** `const arr = []; arr.push(1); console.log(arr);`
**Out:** `[1]` | **Why:** Mutating a `const` array via `.push()` is perfectly valid.

**12.** `const arr = [1]; arr = [2];`
**Out:** `TypeError` | **Why:** You cannot assign a new memory reference to a `const` variable.

**13.** `let x=1; function f() { console.log(x); let x=2; } f();`
**Out:** `ReferenceError` | **Why:** The inner `let x` is hoisted inside `f()`, creating a TDZ that shadows the global `x`.

**14.** `let x=1; switch(x) { case 1: let y=1; case 2: let y=2; }`
**Out:** `SyntaxError` | **Why:** A `switch` statement has a single block scope; `y` is illegally declared twice.

**15.** `function f(a=b, b=1) { console.log(a); } f();`
**Out:** `ReferenceError` | **Why:** Default parameters evaluate left-to-right. `b` is in the TDZ when `a` tries to read it.

### **Part 2: Arrow Functions & `this**`

**16.** `const f = () => arguments; f(1);`
**Out:** `ReferenceError` | **Why:** Arrow functions do not have their own `arguments` object (in a browser environment).

**17.** `const obj = { a: 1, f: () => console.log(this.a) }; obj.f();`
**Out:** `undefined` | **Why:** Arrow functions inherit `this` from their lexical scope (the global object here).

**18.** `const obj = { a: 1, f() { return () => console.log(this.a); } }; obj.f()();`
**Out:** `1` | **Why:** The arrow function inherits `this` from `f()`, which is successfully bound to `obj`.

**19.** `const f = x => x * 2; console.log(f(2));`
**Out:** `4` | **Why:** Arrow functions without `{}` have an implicit `return`.

**20.** `const f = x => { x * 2 }; console.log(f(2));`
**Out:** `undefined` | **Why:** If you use `{}` in an arrow function, you must use the `return` keyword explicitly.

**21.** `const f = () => ({ a: 1 }); console.log(f().a);`
**Out:** `1` | **Why:** To return an object literal implicitly, it must be wrapped in parentheses `({})`.

**22.** `const f = () => { a: 1 }; console.log(f());`
**Out:** `undefined` | **Why:** Without parentheses, `{ a: 1 }` is treated as a block with a label `a`, not an object literal.

**23.** `const G = () => { this.x=1; }; new G();`
**Out:** `TypeError` | **Why:** Arrow functions cannot be used as constructors and cannot be called with `new`.

**24.** `const obj = { id: 1, f() { setTimeout(() => console.log(this.id)); } }; obj.f();`
**Out:** `1` | **Why:** The arrow function prevents `setTimeout` from losing the `this` context.

**25.** `const f = (a, a) => a + a;`
**Out:** `SyntaxError` | **Why:** Arrow functions explicitly forbid duplicate parameter names.

**26.** `console.log(typeof (() => {}));`
**Out:** `"function"` | **Why:** Arrow functions evaluate to standard JavaScript function types.

**27.** `const f = (...args) => args; console.log(f(1,2).length);`
**Out:** `2` | **Why:** The rest parameter groups all arguments into a real Array.

**28.** `const f = a => b => a + b; console.log(f(1)(2));`
**Out:** `3` | **Why:** This is a concise curried function utilizing closures.

**29.** `const obj = { id: 1 }; const f = () => this.id; console.log(f.call(obj));`
**Out:** `undefined` | **Why:** You cannot override an arrow function's `this` binding using `.call()`, `.bind()`, or `.apply()`.

**30.** `const f = x => typeof x; console.log(f());`
**Out:** `"undefined"` | **Why:** Calling a single-parameter arrow function with no arguments sets the parameter to `undefined`.

### **Part 3: Default Parameters, Spread, and Rest**

**31.** `function f(a=1, b=2) { return a+b; } console.log(f(undefined, null));`
**Out:** `1` | **Why:** `undefined` triggers the default parameter (`1`), but `null` is a valid value (`1 + null = 1`).

**32.** `function f(a=1) { return a; } console.log(f(NaN));`
**Out:** `NaN` | **Why:** `NaN` is a distinct value; it does not trigger the default parameter.

**33.** `function f(a, ...b, c) {}`
**Out:** `SyntaxError` | **Why:** The rest parameter (`...b`) must be the absolute last parameter in the function definition.

**34.** `const arr = [1, ...[2,3]]; console.log(arr.length);`
**Out:** `3` | **Why:** The spread operator unpacks the inner array into the outer array.

**35.** `const o1 = {a:1}, o2 = {b:2}, o3 = {...o1, ...o2}; console.log(o3.b);`
**Out:** `2` | **Why:** Object spread merges properties into a new object.

**36.** `const arr = [...'hi']; console.log(arr);`
**Out:** `['h', 'i']` | **Why:** Strings are iterables, so the spread operator splits them into an array of characters.

**37.** `function f(x, y=x) { return x+y; } console.log(f(2));`
**Out:** `4` | **Why:** Default parameters can reference previous parameters in the signature.

**38.** `function f(x=y, y=2) { return x+y; } f();`
**Out:** `ReferenceError` | **Why:** Parameters are evaluated left-to-right. `y` hasn't been initialized when `x` attempts to read it.

**39.** `const obj = {a:1, b:2, a:3}; console.log({...obj});`
**Out:** `{a:3, b:2}` | **Why:** When spreading, later properties overwrite earlier properties with the same key.

**40.** `const a = [1,2]; const b = [...a]; b[0]=9; console.log(a[0]);`
**Out:** `1` | **Why:** The spread operator creates a shallow copy, severing the top-level reference.

**41.** `const o1 = {a:{b:1}}; const o2 = {...o1}; o2.a.b=2; console.log(o1.a.b);`
**Out:** `2` | **Why:** Spread is a shallow copy; nested objects are still copied by reference.

**42.** `console.log(Math.max(...[1,2,3]));`
**Out:** `3` | **Why:** Spread unpacks the array into individual arguments expected by `Math.max`.

**43.** `function f(...args) { return typeof args; } console.log(f());`
**Out:** `"object"` | **Why:** The rest parameter collects arguments into an Array, and `typeof Array` is `"object"`.

**44.** `const [a, ...b] = [1,2,3]; console.log(b);`
**Out:** `[2,3]` | **Why:** Rest can be used in array destructuring to grab all remaining elements.

**45.** `const [a, ...b] = [1]; console.log(b);`
**Out:** `[]` | **Why:** If there are no remaining elements, the rest operator produces an empty array.

### **Part 4: Destructuring**

**46.** `const {a} = {b:2}; console.log(a);`
**Out:** `undefined` | **Why:** Object destructuring requires the property key to match exactly.

**47.** `const {a=1} = {a:undefined}; console.log(a);`
**Out:** `1` | **Why:** `undefined` triggers the default value in destructuring assignments.

**48.** `const {a=1} = {a:null}; console.log(a);`
**Out:** `null` | **Why:** `null` is a valid value and does NOT trigger the default.

**49.** `const {a: x = 2} = {a: 1}; console.log(x);`
**Out:** `1` | **Why:** Syntax: `targetProperty: localAlias = defaultValue`.

**50.** `const {a: x = 2} = {a: 1}; console.log(a);`
**Out:** `ReferenceError` | **Why:** Because `a` was aliased to `x`, `a` itself is never declared as a variable.

**51.** `const [x, , y] = [1,2,3]; console.log(y);`
**Out:** `3` | **Why:** Empty commas skip elements in array destructuring.

**52.** `let x=1, y=2; [x,y] = [y,x]; console.log(x);`
**Out:** `2` | **Why:** Array destructuring is the cleanest ES6 way to swap variables without a temp variable.

**53.** `const {a: {b}} = {a: {b: 2}}; console.log(b);`
**Out:** `2` | **Why:** Deep destructuring extracts nested properties directly.

**54.** `const {a: {b}} = {c: 1};`
**Out:** `TypeError` | **Why:** Cannot destructure property `b` of `undefined` (since `a` does not exist).

**55.** `const [{a}] = [{a:1}]; console.log(a);`
**Out:** `1` | **Why:** You can seamlessly combine array and object destructuring.

**56.** `function f({a=1}={}) { return a; } console.log(f());`
**Out:** `1` | **Why:** Passing nothing defaults the whole parameter to `{}`, which then defaults `a` to `1`.

**57.** `function f({a} = {a:1}) { return a; } console.log(f({}));`
**Out:** `undefined` | **Why:** Passing `{}` overrides the `{a:1}` default object. Destructuring `a` from `{}` yields `undefined`.

**58.** `const {length} = "hi"; console.log(length);`
**Out:** `2` | **Why:** You can destructure standard properties (like length) directly from primitive wrappers.

**59.** `const [...arr] = "hi"; console.log(arr[0]);`
**Out:** `"h"` | **Why:** Strings are iterables and can be destructured into arrays.

**60.** `const {0: x, 1: y} = [10, 20]; console.log(x);`
**Out:** `10` | **Why:** Arrays are objects under the hood; you can destructure them using numeric keys.

### **Part 5: Enhanced Object Literals & Symbols**

**61.** `const a = 1; const obj = {a}; console.log(obj.a);`
**Out:** `1` | **Why:** Property shorthand assigns the variable name as the key and its value as the value.

**62.** `const prop = "x"; const obj = {[prop]: 1}; console.log(obj.x);`
**Out:** `1` | **Why:** Computed property names `[]` allow dynamic keys inside object literals.

**63.** `const obj = { f() { return 1; } }; console.log(obj.f());`
**Out:** `1` | **Why:** Method shorthand removes the need for the `function` keyword and colon.

**64.** `const s1 = Symbol("a"), s2 = Symbol("a"); console.log(s1 === s2);`
**Out:** `false` | **Why:** Every invocation of `Symbol()` creates a unique, guaranteed-distinct identifier.

**65.** `const s = Symbol.for("a"); console.log(s === Symbol.for("a"));`
**Out:** `true` | **Why:** `Symbol.for()` checks the global symbol registry and returns the same symbol if the key matches.

**66.** `const obj = {[Symbol("a")]: 1}; console.log(Object.keys(obj).length);`
**Out:** `0` | **Why:** Symbol keys are non-enumerable and are completely ignored by `Object.keys()`.

**67.** `const obj = { ["a"+"b"]: 1 }; console.log(obj.ab);`
**Out:** `1` | **Why:** Computed properties can evaluate full JavaScript expressions.

**68.** `const name = "x"; const obj = { [name]() { return 1; } }; console.log(obj.x());`
**Out:** `1` | **Why:** Computed properties can be combined with method shorthand.

**69.** `const sym = Symbol("key"); const obj = { [sym]: 1 }; console.log(obj[Symbol("key")]);`
**Out:** `undefined` | **Why:** A new `Symbol("key")` is passed for lookup, which is not the same memory reference as `sym`.

**70.** `console.log(typeof Symbol());`
**Out:** `"symbol"` | **Why:** ES6 introduced `symbol` as a brand new primitive data type.

### **Part 6: Template Literals**

**71.** `const a = 1; console.log(\`${a} + 1 = ${a+1}`);`**Out:**`"1 + 1 = 2"` | **Why:** Template literals (` `) support string interpolation and expression evaluation inside `${}`.

**72.** `function tag(strings, ...vals) { return strings[0] + vals[0]; } console.log(tag\`hi ${1}`);`**Out:**`"hi 1"` | **Why:** Tagged template literals pass the raw string chunks as the first array argument, and evaluated expressions as the rest.

**73.** `console.log(\`a\nb`.length);`**Out:**`3`| **Why:** The newline character`\n` is evaluated as a single character.

**74.** `const f = () => "x"; console.log(\`${f}`);`**Out:**`"() => "x""`| **Why:** Interpolating a function implicitly calls`.toString()` on the function object.

**75.** `console.log(String.raw\`a\nb`.length);`**Out:**`4`| **Why:**`String.raw`ignores escape sequences, treating``, `n`, `a`, and `b` as literal individual characters.

### **Part 7: Classes & OOP**

**76.** `class A {}; console.log(typeof A);`
**Out:** `"function"` | **Why:** Classes in ES6 are syntactical sugar over JavaScript's existing prototype-based constructor functions.

**77.** `class A {}; const a = A();`
**Out:** `TypeError` | **Why:** Unlike standard constructor functions, ES6 Classes **must** be instantiated using the `new` keyword.

**78.** `class A { constructor() { this.x=1; } }; class B extends A {}; console.log(new B().x);`
**Out:** `1` | **Why:** If no constructor is defined in a derived class, a default constructor automatically calls `super()`.

**79.** `class A { constructor(){this.x=1;} }; class B extends A { constructor(){ super(); this.y=2; } }; console.log(new B().x);`
**Out:** `1` | **Why:** The derived constructor explicitly calls `super()`, running the parent's setup logic.

**80.** `class A {}; class B extends A { constructor(){ this.x=1; super(); } }`
**Out:** `ReferenceError` | **Why:** In a child class, you cannot access `this` until _after_ `super()` has been called.

**81.** `class A { static f(){ return 1; } }; console.log(new A().f());`
**Out:** `TypeError` | **Why:** Static methods live on the class constructor itself, not on the instances (`new A()`).

**82.** `class A { static x = 1; }; class B extends A {}; console.log(B.x);`
**Out:** `1` | **Why:** Static properties and methods are successfully inherited by subclass constructors.

**83.** `class A { f(){ return 1; } }; console.log(A.prototype.f());`
**Out:** `1` | **Why:** Standard class methods are bound to the class's `prototype` object.

**84.** `const A = class { f(){ return 1;} }; console.log(new A().f());`
**Out:** `1` | **Why:** Classes can be assigned to variables via Class Expressions, just like Function Expressions.

**85.** `class A { #x=1; }; console.log(new A().#x);`
**Out:** `SyntaxError` | **Why:** Properties prefixed with `#` are strictly private and cannot be read from outside the class.

### **Part 8: Map, Set, Promises, and Iterables**

**86.** `const s = new Set([1, 1, 2]); console.log(s.size);`
**Out:** `2` | **Why:** Sets automatically filter out duplicate values.

**87.** `const m = new Map(); m.set({}, 1); m.set({}, 2); console.log(m.size);`
**Out:** `2` | **Why:** Maps compare object keys by memory reference. `{}` and `{}` point to different memory addresses.

**88.** `const m = new Map(); const obj = {}; m.set(obj, 1); m.set(obj, 2); console.log(m.size);`
**Out:** `1` | **Why:** Because the exact same object reference (`obj`) is used, the Map overwrites the first entry.

**89.** `Promise.resolve(1).then(x => x+1).then(console.log);`
**Out:** `2` | **Why:** Returning a value inside a `.then()` automatically wraps it in a resolved Promise for the next block.

**90.** `Promise.reject(1).catch(x => x).then(console.log);`
**Out:** `1` | **Why:** Returning a value from `.catch()` successfully recovers the chain, passing it to the next `.then()`.

**91.** `const s = new Set("hello"); console.log(s.size);`
**Out:** `4` | **Why:** Strings are iterables; the Set removes the duplicate `"l"`.

**92.** `const arr = Array.from(new Set([1, 2, 2])); console.log(arr.length);`
**Out:** `2` | **Why:** `Array.from()` easily converts a deduped Set back into a standard Array.

**93.** `function* g() { yield 1; yield 2; } console.log(g().next().value);`
**Out:** `1` | **Why:** The generator pauses at the first `yield` and returns its value.

**94.** `function* g() { return 1; } console.log(g().next());`
**Out:** `{value: 1, done: true}` | **Why:** A `return` statement immediately sets `done: true` on the iterator result.

**95.** `const obj = { *f() { yield 1; } }; console.log(obj.f().next().value);`
**Out:** `1` | **Why:** The `*` prefix is the concise ES6 syntax to declare a generator method inside an object.

**96.** `const m = new Map([['a', 1]]); console.log([...m.keys()][0]);`
**Out:** `"a"` | **Why:** `.keys()` returns an iterable of map keys, which can be spread into an array.

**97.** `const m = new Map([['a', 1]]); console.log([...m][0][1]);`
**Out:** `1` | **Why:** Spreading a Map yields an array of arrays `[['a', 1]]`. Index `[0][1]` grabs the value `1`.

**98.** `Promise.resolve(1).finally(() => 2).then(console.log);`
**Out:** `1` | **Why:** `.finally()` does not mutate the promise chain's value. The `2` is ignored, and `1` passes through.

**99.** `Promise.all([Promise.resolve(1), Promise.reject(2)]).catch(console.log);`
**Out:** `2` | **Why:** `Promise.all` is fail-fast. A single rejection immediately rejects the entire group.

**100.** `const it = "hi"[Symbol.iterator](); console.log(it.next().value);`
**Out:** `"h"` | **Why:** ES6 strings have a built-in Symbol.iterator protocol, allowing them to be iterated character by character.
