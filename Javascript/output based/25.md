```javascript
const a = { id: 1, tags: ['x'] };
const list = [a];

const copy = list.map(o => ({ ...o }));
copy[0].tags.push('y');
copy[0].id = 99;

console.log(a);

```

This prints:

```javascript
{ id: 1, tags: ['x', 'y'] }

```

### Why?

1. **Shallow Copy (`...o`):**
The `list.map(o => ({ ...o }))` statement creates a **shallow copy** of each object in the array. This means a new object wrapper is created for the copy, and primitive properties (like `id: 1`) are copied by value.
2. **Mutating the Primitive Property (`copy[0].id = 99`):**
Because `id` is a primitive, changing `copy[0].id` only affects the copied object. The original object `a` retains its original value (`id: 1`).
3. **Shared Reference for Nested Objects (`tags`):**
Spread syntax (`...`) only performs a *shallow* copy. It does **not** clone nested objects or arrays; it merely copies their references. Therefore, `copy[0].tags` and `a.tags` both point to the **exact same array in memory**. When `copy[0].tags.push('y')` is executed, it mutates the shared array, affecting both `copy` and the original object `a`.
