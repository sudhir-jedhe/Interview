```javascript
let x = 0;
let y = "0";
let z = false;

console.log(x == y); // true
console.log(x == z); // true

```

* **`console.log(x == y)` outputs: `true**`
* **Reason:** The loose equality operator (`==`) triggers implicit type coercion. When comparing a **Number** and a **String**, JavaScript converts the string into a number. Here, `"0"` is converted to `0`, resulting in `0 == 0`.

* **`console.log(x == z)` outputs: `true**`
* **Reason:** When comparing a **Number** and a **Boolean**, JavaScript converts the boolean into a number. In JavaScript, `false` converts to `0` (and `true` to `1`). This also results in `0 == 0`.
