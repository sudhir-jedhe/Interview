**ECMAScript 2024 (ES15)** brought powerful new utilities for grouping array data, managing asynchronous promises, working with regular expressions, manipulating ArrayBuffers, and handling Unicode strings.

Supported across all major browsers since mid-2024.

---

## Key Features Overview

| Feature                              | Syntax / Method                           | Description                                                                         |
| ------------------------------------ | ----------------------------------------- | ----------------------------------------------------------------------------------- |
| **Object / Map Data Grouping**       | `Object.groupBy()`, `Map.groupBy()`       | Groups iterable elements into an object or Map based on a callback criteria.        |
| **Promise Capability Control**       | `Promise.withResolvers()`                 | Exposes a Promise alongside its outer `resolve` and `reject` triggers.              |
| **RegExp Set Notation & Properties** | `/pattern/v`                              | Advanced set operations (difference, intersection) and Unicode properties in regex. |
| **Resizable ArrayBuffers**           | `new ArrayBuffer(len, { maxByteLength })` | Allows growing and shrinking ArrayBuffers without re-allocating memory.             |
| **Well-Formed String Inspection**    | `.isWellFormed()`, `.toWellFormed()`      | Validates and sanitizes UTF-16 surrogate pairs in strings.                          |
| **ArrayBuffer Transfer**             | `.transfer()`, `.transferToFixedLength()` | Transfers ownership and memory of an ArrayBuffer efficiently.                       |

---

## Code Examples & Use Cases

### 1. Data Grouping (`Object.groupBy` & `Map.groupBy`)

Replaces custom `reduce()` boilerplate or external libraries like Lodash by providing native methods to group array data by keys.

#### `Object.groupBy()`

Groups items into a plain JavaScript object where keys are converted to strings.

```javascript
const inventory = [
  { name: 'Laptop', category: 'Tech', price: 999 },
  { name: 'Shirt', category: 'Apparel', price: 29 },
  { name: 'Mouse', category: 'Tech', price: 49 },
  { name: 'Pants', category: 'Apparel', price: 59 }
];

const groupedByCategory = Object.groupBy(inventory, item => item.category);

console.log(groupedByCategory);
/* Output:
{
  Tech: [
    { name: 'Laptop', category: 'Tech', price: 999 },
    { name: 'Mouse', category: 'Tech', price: 49 }
  ],
  Apparel: [
    { name: 'Shirt', category: 'Apparel', price: 29 },
    { name: 'Pants', category: 'Apparel', price: 59 }
  ]
}
*/

```

#### `Map.groupBy()`

Useful when you want to group by non-string keys (such as objects, numbers, or booleans).

```javascript
const products = [
  { name: 'Monitor', stock: 15 },
  { name: 'Keyboard', stock: 0 },
  { name: 'Headphones', stock: 5 }
];

// Group by boolean key (In Stock vs Out of Stock)
const groupedByStock = Map.groupBy(products, item => item.stock > 0);

console.log(groupedByStock.get(true));  // Array of items in stock
console.log(groupedByStock.get(false)); // Array of items out of stock

```

### 2. `Promise.withResolvers()`

Simplifies promise management by returning an object containing a new `Promise` alongside its `resolve` and `reject` functions directly extracted. This eliminates the need to expose resolver callbacks outside of Promise constructors manually.

```javascript
// Before ES2024:
let resolveFn, rejectFn;
const legacyPromise = new Promise((resolve, reject) => {
  resolveFn = resolve;
  rejectFn = reject;
});

// ES2024 Promise.withResolvers():
const { promise, resolve, reject } = Promise.withResolvers();

// Resolve or reject from anywhere in your codebase
setTimeout(() => {
  resolve('Async task completed!');
}, 1000);

promise.then(result => console.log(result)); // "Async task completed!"

```

### 3. RegExp Set Notation & Unicode Properties (`/v` Flag)

The `/v` flag is an upgrade to the `/u` flag for Regular Expressions, introducing set operations (intersection `&&`, difference `--`) inside character classes.

```javascript
// Match Greek characters THAT ARE ALSO numbers (Intersection &&)
const greekDigits = /[\p{Script=Greek}&&[\0-\9]]/v;

// Match ASCII characters EXCEPT vowels (Difference --)
const nonVowelAscii = /[\x00-\x7F--[aeiouAEIOU]]/v;

console.log(nonVowelAscii.test('b')); // true
console.log(nonVowelAscii.test('a')); // false

```

### 4. Well-Formed Unicode Strings (`isWellFormed` & `toWellFormed`)

JavaScript strings use UTF-16 encoding. Unpaired surrogate code units cause broken or malformed strings when converted to UTF-8 (e.g., when sending JSON over network sockets).

* **`isWellFormed()`:** Checks whether a string contains lone surrogates.
* **`toWellFormed()`:** Returns a new string with any lone surrogates replaced by the Unicode replacement character `` (`U+FFFD`).

```javascript
const badString = 'Hello \uD800 World'; // Contains unpaired high-surrogate

console.log(badString.isWellFormed()); // false

const safeString = badString.toWellFormed();
console.log(safeString);                // "Hello  World"
console.log(safeString.isWellFormed()); // true

```

### 5. Resizable & Transferable `ArrayBuffer`s

Provides better performance and memory efficiency for low-level binary data handling (WebAssembly, WebGL, Canvas API) by allowing buffers to resize dynamically.

```javascript
// Allocate buffer with initial length 8 bytes, expandable up to 16 bytes
const buffer = new ArrayBuffer(8, { maxByteLength: 16 });

console.log(buffer.byteLength); // 8
console.log(buffer.resizable);  // true

// Grow memory buffer on demand without creating a new allocation
buffer.resize(12);
console.log(buffer.byteLength); // 12

// Transfer buffer memory ownership safely
const newBuffer = buffer.transfer();
console.log(buffer.detached);   // true (Original buffer is detached/freed)
console.log(newBuffer.byteLength); // 12

```
