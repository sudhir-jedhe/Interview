**ECMAScript 2020 (ES11)** introduced significant features to JavaScript, including long-requested language syntax like optional chaining, nullish coalescing, and BigInt for large integers.

Supported in all modern browsers since mid-2020.

---

## Key Features Overview

| Feature                           | Syntax / Method        | Description                                                                        |
| --------------------------------- | ---------------------- | ---------------------------------------------------------------------------------- |
| **Optional Chaining**             | `?.`                   | Safely accesses deeply nested object properties without throwing `TypeError`.      |
| **Nullish Coalescing Operator**   | `??`                   | Returns right-hand operand only if left side is `null` or `undefined` (unlike `    |  | `). |
| **BigInt**                        | `123n` / `BigInt()`    | Represents integers of arbitrary size beyond `Number.MAX_SAFE_INTEGER`.            |
| **`Promise.allSettled()`**        | `Promise.allSettled()` | Resolves when all Promises finish (fulfilled or rejected), returning their status. |
| **Dynamic Import**                | `import()`             | Dynamically loads ES modules on demand, returning a Promise.                       |
| **`globalThis`**                  | `globalThis`           | Standardized global object across environments (`window`, `global`, `self`).       |
| **`String.prototype.matchAll()`** | `.matchAll()`          | Returns an iterator of all regex matches, including capture groups.                |
| **`import.meta`**                 | `import.meta`          | Exposes module-specific metadata (such as module URL).                             |

---

## Code Examples & Use Cases

### 1. Optional Chaining (`?.`)

Prevents runtime errors like `TypeError: Cannot read properties of undefined` when navigating nested objects or calling optional methods.

```javascript
const user = {
  name: 'Sudhir',
  address: {
    city: 'Pune'
  }
};

// Safe property access
console.log(user?.address?.city);    // 'Pune'
console.log(user?.contact?.phone);   // undefined (Doesn't throw error!)

// Safe method invocation
console.log(user.getDetails?.());    // undefined (Doesn't throw error!)

// Safe array element access
const usersList = null;
console.log(usersList?.[0]);          // undefined

```

---

### 2. Nullish Coalescing Operator (`??`)

A logical operator that provides a default value **only** when the left operand is `null` or `undefined`. Unlike the logical OR (`||`) operator, it treats falsy values like `0`, `""`, and `false` as valid values.

```javascript
const config = {
  timeout: 0,
  title: ''
};

// Using || (Logical OR) treats 0 and "" as falsy -> overwrites valid values
console.log(config.timeout || 5000); // 5000 ❌ (Unexpected!)
console.log(config.title || 'Default'); // 'Default' ❌ (Unexpected!)

// Using ?? (Nullish Coalescing) respects 0 and ""
console.log(config.timeout ?? 5000); // 0 ✅
console.log(config.title ?? 'Default'); // '' ✅
console.log(config.port ?? 8080);    // 8080 ✅ (Triggers default because config.port is undefined)

```

---

### 3. BigInt

Represents whole numbers larger than $2^{53} - 1$ (`9,007,199,254,740,991`), which is the maximum safe integer for standard JavaScript numbers.

```javascript
const maxSafe = Number.MAX_SAFE_INTEGER; // 9007199254740991

console.log(maxSafe + 1); // 9007199254740992
console.log(maxSafe + 2); // 9007199254740992 ❌ (Precision lost!)

// BigInt declaration (append 'n' to the integer)
const bigNum1 = 9007199254740991n;
const bigNum2 = BigInt('9007199254740991');

console.log(bigNum1 + 2n); // 9007199254740993n ✅ (Exact precision!)

```

---

### 4. `Promise.allSettled()`

Unlike `Promise.all()` (which fails fast if *any* Promise rejects), `Promise.allSettled()` waits for all Promises to complete regardless of whether they fulfill or reject.

```javascript
const p1 = Promise.resolve('Success 1');
const p2 = Promise.reject('Error occurred');
const p3 = Promise.resolve('Success 2');

Promise.allSettled([p1, p2, p3]).then(results => console.log(results));

/* Output:
[
  { status: 'fulfilled', value: 'Success 1' },
  { status: 'rejected', reason: 'Error occurred' },
  { status: 'fulfilled', value: 'Success 2' }
]
*/

```

---

### 5. Dynamic Import (`import()`)

Allows loading modules dynamically on demand as promises, enabling code-splitting and conditional loading.

```javascript
async function loadChartModule() {
  if (userNeedsChart) {
    // Dynamically import module only when needed
    const { renderChart } = await import('./chart.js');
    renderChart();
  }
}

```

---

### 6. `globalThis`

Provides a single, standardized global object across any JavaScript environment (Browser `window`, Node.js `global`, Web Workers `self`).

```javascript
// Works everywhere consistently:
globalThis.setTimeout(() => {
  console.log('Running on standard global context!');
}, 100);

```

---

### 7. `String.prototype.matchAll()`

Returns an iterator of all regex matches against a string, providing access to full capture groups for each match (requires the global `/g` flag).

```javascript
const text = 'IDs: #101, #202, #303';
const regex = /#(?<id>\d+)/g;

const matches = text.matchAll(regex);

for (const match of matches) {
  console.log(`Matched: ${match[0]}, Group ID: ${match.groups.id}`);
}
// Output:
// Matched: #101, Group ID: 101
// Matched: #202, Group ID: 202
// Matched: #303, Group ID: 303

```
