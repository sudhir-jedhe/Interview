JavaScript Generators

In JavaScript, a **Generator** is a special type of function that can be **paused and resumed** during its execution.

Unlike normal functions that execute completely from start to finish, a generator function can `yield` multiple values over time, preserving its internal state (variables, execution position) between consecutive calls.

---

## 1. Syntax & Mechanics

A generator function is declared using the `function*` syntax (with an asterisk). Calling a generator function **does not run its code immediately**—instead, it returns a **Generator Object**, which implements both the **Iterable** and **Iterator** protocols.

* **`function*`**: Declares a generator function.
* **`yield`**: Pauses execution and returns a value to the caller.
* **`.next()`**: Resumes execution from where it was paused until it reaches the next `yield` or `return`.

```javascript
// Example 1: Basic Generator declaration and step-by-step execution
function* simpleGenerator() {
  console.log("Start");
  yield "First Pause";
  console.log("Middle");
  yield "Second Pause";
  return "End";
}

const gen = simpleGenerator(); // Returns generator object; body hasn't executed yet

console.log(gen.next()); 
// Logs: "Start"
// Output: { value: "First Pause", done: false }

console.log(gen.next()); 
// Logs: "Middle"
// Output: { value: "Second Pause", done: false }

console.log(gen.next()); 
// Output: { value: "End", done: true }

```

---

## 2. Bidirectional Communication (Passing Values Into Generators)

The `yield` keyword not only sends values out, but it can also **receive values back** when you pass an argument to `.next(value)`.

```javascript
function* conversation() {
  const name = yield "What is your name?";
  console.log(`Hello, ${name}!`);
  
  const age = yield "How old are you?";
  console.log(`You are ${age} years old.`);
}

const chat = conversation();

// 1. Start execution up to the first yield
console.log(chat.next().value); 
// Output: "What is your name?"

// 2. Pass "Alice" as the result of the first yield expression
console.log(chat.next("Alice").value); 
// Logs: "Hello, Alice!"
// Output: "How old are you?"

// 3. Pass 30 as the result of the second yield expression
chat.next(30); 
// Logs: "You are 30 years old."

```

---

## 3. Delegating Generators with `yield*`

The `yield*` syntax allows a generator to delegate execution to another generator or iterable object (such as an Array or Set).

```javascript
function* numbers() {
  yield 1;
  yield 2;
}

function* letters() {
  yield "A";
  yield "B";
}

function* combined() {
  yield* numbers(); // Delegates to numbers()
  yield* letters(); // Delegates to letters()
  yield* [10, 20];  // Delegates to an Array
}

console.log([...combined()]); 
// Output: [1, 2, "A", "B", 10, 20]

```

## 4. Common Use Cases

### A. Infinite Data Streams

Generators pause execution between `.next()` calls, allowing you to handle infinite sequences without freezing memory or throwing stack overflow errors.

```javascript
function* idGenerator() {
  let id = 1;
  while (true) {
    yield `user_${id++}`;
  }
}

const genId = idGenerator();
console.log(genId.next().value); // Output: "user_1"
console.log(genId.next().value); // Output: "user_2"
console.log(genId.next().value); // Output: "user_3"

```

### B. Making Custom Objects Iterable

Generators simplify making plain objects iterable with `for...of` loops by implementing `[Symbol.iterator]`.

```javascript
const team = {
  members: ["Alice", "Bob", "Charlie"],
  *[Symbol.iterator]() {
    for (const member of this.members) {
      yield member;
    }
  }
};

for (const name of team) {
  console.log(name);
}
// Output: "Alice", "Bob", "Charlie"

```

### C. Memory-Efficient Batching / Pagination

Yielding chunks of data on demand allows applications to process large datasets without loading everything into memory upfront.

```javascript
function* paginate(items, pageSize) {
  for (let i = 0; i < items.length; i += pageSize) {
    yield items.slice(i, i + pageSize);
  }
}

const data = [1, 2, 3, 4, 5, 6, 7, 8, 9];
const pager = paginate(data, 3);

console.log(pager.next().value); // Output: [1, 2, 3]
console.log(pager.next().value); // Output: [4, 5, 6]
console.log(pager.next().value); // Output: [7, 8, 9]

```

## 5. Generator Object Interface Summary

| Method                  | Description                                                                                              |
| ----------------------- | -------------------------------------------------------------------------------------------------------- |
| **`gen.next(value)`**   | Resumes execution, optionally passing `value` into the `yield` expression.                               |
| **`gen.return(value)`** | Ends generator execution immediately, returning `{ value: value, done: true }`.                          |
| **`gen.throw(error)`**  | Throws an error into the generator at the current `yield` point so it can be handled by a `try...catch`. |

Explain JavaScript Async Generators (async function*) and for await...of loops with examples

**Async Generators** (`async function*`) combine the power of **Async/Await** and **Generators**.

While a standard synchronous generator yields values immediately, an async generator **yields Promises for values**. This allows you to pause execution, await asynchronous operations (like network requests or file reads), and `yield` results sequentially as they become available.

To consume the stream of promises emitted by an async generator, JavaScript provides the **`for await...of`** loop.

---

## 1. Syntax & Core Mechanics

An async generator is declared using `async function*`. Inside its body, you can use both `await` and `yield`.

* **`async function*`**: Declares an async generator function.
* **`await`**: Pauses internal execution until a Promise resolves.
* **`yield`**: Returns a Promise that resolves to `{ value, done }` when `.next()` is called.
* **`for await...of`**: A specialized loop that automatically awaits each Promise emitted by an async iterable.

```javascript
// Example 1: Basic Async Generator
async function* asyncNumberGenerator() {
  for (let i = 1; i <= 3; i++) {
    // Wait 500ms between each value
    await new Promise(resolve => setTimeout(resolve, 500));
    yield i;
  }
}

// Consuming with for await...of
(async () => {
  for await (const num of asyncNumberGenerator()) {
    console.log(num);
  }
})();
// Output (with 500ms delay between each line):
// 1
// 2
// 3

```

---

## 2. Manual Iteration using `.next()`

Calling `.next()` on an async generator returns a **Promise** resolving to an object with shape `{ value, done }`.

```javascript
async function* simpleStream() {
  yield "Data Chunk 1";
  yield "Data Chunk 2";
}

const stream = simpleStream();

// .next() returns a Promise, so we must await it
async function readStreamManually() {
  const first = await stream.next();
  console.log(first); // Output: { value: 'Data Chunk 1', done: false }

  const second = await stream.next();
  console.log(second); // Output: { value: 'Data Chunk 2', done: false }

  const third = await stream.next();
  console.log(third); // Output: { value: undefined, done: true }
}

readStreamManually();

```

## 3. Real-World Use Cases

### A. Paginated API Fetching (Auto-Fetching Pages on Demand)

Fetch records page-by-page from an API, requesting the next page only when the consumer demands more items.

```javascript
// Simulated API client
async function fetchPageFromAPI(page) {
  // Simulate network latency
  await new Promise(resolve => setTimeout(resolve, 300));
  
  const totalPages = 3;
  if (page > totalPages) return null;

  return {
    items: [`Item A (Page ${page})`, `Item B (Page ${page})`],
    nextPage: page < totalPages ? page + 1 : null
  };
}

// Async Generator handles pagination
async function* fetchAllItems() {
  let page = 1;

  while (page !== null) {
    console.log(`Fetching page ${page}...`);
    const response = await fetchPageFromAPI(page);

    if (!response) break;

    // Yield items one at a time
    for (const item of response.items) {
      yield item;
    }

    page = response.nextPage;
  }
}

// Consumer processes items without worrying about pagination logic
async function processData() {
  for await (const item of fetchAllItems()) {
    console.log("Received:", item);
  }
}

processData();
/* Output:
Fetching page 1...
Received: Item A (Page 1)
Received: Item B (Page 1)
Fetching page 2...
Received: Item A (Page 2)
Received: Item B (Page 2)
Fetching page 3...
Received: Item A (Page 3)
Received: Item B (Page 3)
*/

```

---

### B. Streaming Large Files or WebSockets Line-by-Line

Async generators prevent high memory usage by yielding chunks of streaming data as they arrive over a network or file stream.

```javascript
// Simulating an incoming data stream (e.g., WebSocket or Node.js ReadableStream)
async function* streamDataChunks(chunks) {
  for (const chunk of chunks) {
    // Wait for the next chunk to arrive
    await new Promise(resolve => setTimeout(resolve, 400));
    yield chunk;
  }
}

async function runStreamReader() {
  const incomingData = ["Headers OK\n", "Row 1: User A\n", "Row 2: User B\n"];
  
  const stream = streamDataChunks(incomingData);

  for await (const chunk of stream) {
    console.log("Chunk Processed:", chunk.trim());
  }
}

runStreamReader();

```

## 4. Sync vs. Async Generators Comparison

| Feature              | Sync Generator (`function*`) | Async Generator (`async function*`)      |
| -------------------- | ---------------------------- | ---------------------------------------- |
| **`yield` Value**    | Returns values directly      | Returns Promises for values              |
| **`await` Support**  | ❌ Not allowed inside body    | ✅ Allowed inside body                    |
| **Iteration Method** | `for...of` loop or `.next()` | `for await...of` loop or `await .next()` |
| **Protocol**         | `Symbol.iterator`            | `Symbol.asyncIterator`                   |
| **`.next()` Result** | `{ value, done }`            | `Promise<{ value, done }>`               |

---

## 5. Error Handling with `try...catch`

Errors thrown inside an async generator or network failures inside `await` can be caught using standard `try...catch` blocks within `for await...of` loops.

```javascript
async function* faultyStream() {
  yield "Step 1";
  await new Promise(resolve => setTimeout(resolve, 200));
  throw new Error("Network connection dropped!");
}

async function consumeWithErrorHandling() {
  try {
    for await (const val of faultyStream()) {
      console.log(val);
    }
  } catch (err) {
    console.error("Caught error during stream consumption:", err.message);
  }
}

consumeWithErrorHandling();
// Output:
// Step 1
// Caught error during stream consumption: Network connection dropped!

```
