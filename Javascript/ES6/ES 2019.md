**ECMAScript 2019 (ES10)** brought very practical utilities for array flattening, string trimming, object transformations, error handling, and symbol descriptions.

Supported in all modern browsers since mid-2019.

---

## Key Features Overview

| Feature                                          | Syntax / Method                    | Description                                                                          |
| ------------------------------------------------ | ---------------------------------- | ------------------------------------------------------------------------------------ |
| **`Array.prototype.flat()`**                     | `.flat(depth)`                     | Flattens nested arrays up to a specified depth.                                      |
| **`Array.prototype.flatMap()`**                  | `.flatMap(fn)`                     | Maps each element using a mapping function, then flattens the result by depth 1.     |
| **`Object.fromEntries()`**                       | `Object.fromEntries()`             | Transforms a list of key-value pairs (e.g., `[[key, val]]` or `Map`) into an object. |
| **`String.prototype.trimStart()` / `trimEnd()**` | `.trimStart()`, `.trimEnd()`       | Trims whitespace from only the beginning or only the end of a string.                |
| **Optional `catch` Binding**                     | `try { ... } catch { ... }`        | Allows omitting the error parameter in `catch` blocks if it isn't used.              |
| **`Symbol.prototype.description`**               | `sym.description`                  | Provides direct read-only access to a Symbol's description.                          |
| **`Function.prototype.toString()` Revision**     | `fn.toString()`                    | Returns exact source code slice, including whitespace and comments.                  |
| **JSON Improvements**                            | `JSON.stringify()` / `well-formed` | Correctly encodes un-paired UTF-16 surrogate code units.                             |

## Code Examples & Use Cases

### 1. `Array.prototype.flat()`

Recursively flattens multi-dimensional arrays up to the specified depth (default is `1`). Pass `Infinity` to completely flatten an array of any depth.

```javascript
const nestedArray = [1, 2, [3, 4, [5, 6]]];

// Flatten 1 level deep (default)
console.log(nestedArray.flat()); 
// [1, 2, 3, 4, [5, 6]]

// Flatten 2 levels deep
console.log(nestedArray.flat(2)); 
// [1, 2, 3, 4, 5, 6]

// Completely flatten regardless of depth
const deeplyNested = [1, [2, [3, [4]]]];
console.log(deeplyNested.flat(Infinity)); 
// [1, 2, 3, 4]

```

---

### 2. `Array.prototype.flatMap()`

Combines `.map()` and `.flat(1)` into a single, more efficient operation. Great for adding or removing items during mapping.

```javascript
const sentences = ['Hello world', 'JavaScript ES10'];

// Using map + flat separately
const words1 = sentences.map(s => s.split(' ')).flat();

// Using flatMap directly (more performant)
const words2 = sentences.flatMap(s => s.split(' '));

console.log(words2); 
// ['Hello', 'world', 'JavaScript', 'ES10']

// Filtering and transforming at the same time:
const numbers = [1, 2, 3, 4];
const doubledEvensOnly = numbers.flatMap(num => (num % 2 === 0 ? [num * 2] : []));

console.log(doubledEvensOnly); 
// [4, 8]

```

---

### 3. `Object.fromEntries()`

The inverse of `Object.entries()`. It turns a list of key-value pairs (like an array of pairs or a `Map`) back into a plain object.

```javascript
// 1. Transforming an Object's values cleanly
const prices = { apple: 2, banana: 1, cherry: 3 };

const doublePrices = Object.fromEntries(
  Object.entries(prices).map(([fruit, price]) => [fruit, price * 2])
);

console.log(doublePrices); 
// { apple: 4, banana: 2, cherry: 6 }

// 2. Converting a Map directly into an Object
const map = new Map([['name', 'Sudhir'], ['role', 'Developer']]);
const obj = Object.fromEntries(map);

console.log(obj); 
// { name: 'Sudhir', role: 'Developer' }

```

---

### 4. `String.prototype.trimStart()` and `trimEnd()`

Targeted alternatives to `trim()`, replacing the non-standard `trimLeft()` and `trimRight()`.

```javascript
const text = '   Hello World!   ';

console.log(text.trimStart()); // "Hello World!   "
console.log(text.trimEnd());   // "   Hello World!"
console.log(text.trim());      // "Hello World!"

```

---

### 5. Optional `catch` Binding

If you don't need to use the error object inside a `try...catch` block, you can omit the `(error)` parameter completely.

```javascript
// Before ES2019:
try {
  JSON.parse(invalidJson);
} catch (unusedError) {
  console.log('Invalid JSON payload received');
}

// ES2019 (Clean & parameterless):
try {
  JSON.parse(invalidJson);
} catch {
  console.log('Invalid JSON payload received');
}

```

---

### 6. `Symbol.prototype.description`

Access a Symbol's optional description property directly without having to call `.toString()`.

```javascript
const mySymbol = Symbol('user_id_key');

// Before ES2019:
console.log(mySymbol.toString()); // "Symbol(user_id_key)"

// ES2019:
console.log(mySymbol.description); // "user_id_key"

```

---

### 7. `Function.prototype.toString()` Revision

`toString()` now returns the precise, unaltered slice of source code, including comments, whitespaces, and exact formatting.

```javascript
function calculateTax(amount) {
  // 18% standard tax rate
  return amount * 0.18;
}

console.log(calculateTax.toString());
// Output includes the exact inline comment and indentation!

```
