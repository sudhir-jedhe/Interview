**ECMAScript 2018 (ES9)** brought major enhancements to asynchronous processing, regular expressions, and object manipulation.

Supported in all modern browsers since late 2018.

---

## Key Features Overview

| Feature                             | Syntax / Method                 | Description                                                                      |
| ----------------------------------- | ------------------------------- | -------------------------------------------------------------------------------- |
| **Async Iteration**                 | `for await...of`                | Iterates over asynchronous data sources or streams of Promises sequentially.     |
| **Promise.prototype.finally()**     | `.finally()`                    | Runs a cleanup callback after a Promise settles (whether fulfilled or rejected). |
| **Object Rest & Spread**            | `{ ...obj }` / `{ a, ...rest }` | Spreads and collects properties in objects (extending ES6 array rest/spread).    |
| **RegExp Named Capture Groups**     | `(?<name>...)`                  | Assigns names to regex capture groups instead of relying on numeric indexes.     |
| **RegExp Lookbehind Assertions**    | `(?<=...)` & `(?<!...)`         | Matches a pattern based on what precedes it (positive and negative lookbehind).  |
| **RegExp Unicode Property Escapes** | `\p{...}`                       | Matches characters based on Unicode properties (e.g., emojis, scripts).          |
| **RegExp `s` (dotAll) Flag**        | `/pattern/s`                    | Allows the dot (`.`) to match newline characters (`\n`, `\r`).                   |

---

## Code Examples & Use Cases

### 1. Asynchronous Iteration (`for await...of`)

Allows you to loop through an array of Promises—or an async generator stream—executing each iteration sequentially as each Promise resolves.

```javascript
const fetchUser = (id) => new Promise(resolve => setTimeout(() => resolve(`User ${id}`), 500));

async function loadUsers() {
  const userPromises = [fetchUser(1), fetchUser(2), fetchUser(3)];

  // Waits for each Promise to resolve in order
  for await (const user of userPromises) {
    console.log(user);
  }
}

loadUsers();
// Output:
// User 1
// User 2
// User 3

```

---

### 2. `Promise.prototype.finally()`

Specifies a function that executes regardless of whether the Promise was resolved or rejected. Perfect for stopping loading spinners, closing database connections, or freeing up resources.

```javascript
function loadData() {
  showLoadingSpinner();

  fetchDataFromApi()
    .then(data => renderData(data))
    .catch(err => showError(err))
    .finally(() => {
      hideLoadingSpinner(); // Runs in both success and failure cases!
    });
}

```

---

### 3. Object Rest and Spread Properties

Brings the rest (`...`) and spread (`...`) operators from ES6 arrays into plain JavaScript objects.

```javascript
// 1. Object Rest (Destructuring)
const user = { name: 'Sudhir', role: 'Developer', city: 'Pune', country: 'India' };
const { name, role, ...address } = user;

console.log(name);    // 'Sudhir'
console.log(address); // { city: 'Pune', country: 'India' }

// 2. Object Spread (Merging & Shallow Copying)
const defaults = { theme: 'light', font: 'Arial' };
const custom = { theme: 'dark' };

const settings = { ...defaults, ...custom, language: 'en' };
console.log(settings); // { theme: 'dark', font: 'Arial', language: 'en' }

```

### 4. RegExp Named Capture Groups

Instead of accessing matched regex groups by index numbers (`match[1]`), ES2018 lets you assign explicit names using `(?<name>...)`.

```javascript
const dateString = '2026-08-07';
const regex = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;

const match = regex.exec(dateString);

console.log(match.groups.year);  // '2026'
console.log(match.groups.month); // '08'
console.log(match.groups.day);   // '07'

```

---

### 5. RegExp Lookbehind Assertions

Lookbehinds allow you to match a pattern **only if it is preceded** by another pattern.

* **Positive Lookbehind (`(?<=...)`):** Matches if preceded by the specified string.
* **Negative Lookbehind (`(?<!...)`):** Matches if NOT preceded by the specified string.

```javascript
// Positive Lookbehind: Match price only if preceded by '$'
const priceString = 'Item cost: $100';
const priceRegex = /(?<=\$)\d+/;
console.log(priceString.match(priceRegex)[0]); // '100'

// Negative Lookbehind: Match price only if NOT preceded by '$'
const euroString = 'Item cost: €100';
const nonDollarRegex = /(?<!\$)\d+/;
console.log(euroString.match(nonDollarRegex)[0]); // '100'

```

---

### 6. RegExp Unicode Property Escapes (`\p{...}`)

Matches characters based on their Unicode properties, such as specific alphabets, punctuation, or emojis. Requires the `u` flag.

```javascript
const text = 'Hello! 👋 123';

// Match any emoji
const emojiRegex = /\p{Extended_Pictographic}/u;
console.log(emojiRegex.test(text)); // true

// Match Greek letters
const greekRegex = /\p{Script=Greek}/u;
console.log(greekRegex.test('Ω')); // true

```

---

### 7. RegExp `s` (dotAll) Flag

By default, the wildcard dot (`.`) matches any character **except** line terminators (`\n`, `\r`). The `/s` flag enables "dotAll" mode so that `.` matches newlines as well.

```javascript
const multilineText = 'Hello\nWorld';

// Without 's' flag:
console.log(/Hello.World/.test(multilineText)); // false

// With 's' flag:
console.log(/Hello.World/s.test(multilineText)); // true

```
