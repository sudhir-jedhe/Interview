Here is the completed table with the correct feature names and operators introduced in **ECMAScript 2016 (ES7)**:

| Feature                                | Syntax / Operator | Description                                                                                                |
| -------------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------- |
| **Exponentiation Operator**            | `**`              | Raises the first operand to the power of the second operand (e.g., `2 ** 3 = 8`).                          |
| **Exponentiation Assignment Operator** | `**=`             | Raises the value of a variable to the power of the right operand and assigns the result (e.g., `x **= 2`). |
| **`Array.prototype.includes()`**       | `.includes()`     | Checks if an array contains a specific element, returning `true` or `false`.                               |

---

### Code Examples

#### 1. Exponentiation Operator (`**` & `**=`)

Replaces the older `Math.pow()` method with cleaner syntax.

```javascript
// Before ES2016:
console.log(Math.pow(2, 3)); // 8

// ES2016 Exponentiation Operator:
console.log(2 ** 3); // 8

// Exponentiation Assignment:
let x = 3;
x **= 2; // Equivalent to x = x ** 2
console.log(x); // 9

```

#### 2. `Array.prototype.includes()`

Improves readability when searching for an item in an array, and correctly handles `NaN` values (unlike `indexOf`).

```javascript
const fruits = ['apple', 'banana', 'mango'];

// Before ES2016:
console.log(fruits.indexOf('banana') !== -1); // true

// ES2016 includes():
console.log(fruits.includes('banana')); // true
console.log(fruits.includes('grape'));  // false

// Special edge case: handling NaN
const numbers = [1, 2, NaN];
console.log(numbers.indexOf(NaN));   // -1 (indexOf cannot find NaN)
console.log(numbers.includes(NaN));  // true (includes correctly handles NaN)

```
