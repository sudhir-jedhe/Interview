**ECMAScript 2022 (ES13)** introduced major improvements to JavaScript classes, top-level asynchronous processing, array indexing, and error handling.

Supported across all modern browsers since mid-2022.

---

## Key Features Overview

| Feature                            | Syntax / Method                     | Description                                                              |
| ---------------------------------- | ----------------------------------- | ------------------------------------------------------------------------ |
| **Class Fields & Private Members** | `#privateField`, `#privateMethod()` | Adds native private properties/methods and static class elements.        |
| **Top-Level `await**`              | `await fetch(...)`                  | Allows `await` directly at the module root outside of `async` functions. |
| **`Array.prototype.at()`**         | `.at(index)`                        | Relative indexing supporting negative numbers for arrays and strings.    |
| **`Object.hasOwn()`**              | `Object.hasOwn(obj, prop)`          | Safer replacement for `Object.prototype.hasOwnProperty()`.               |
| **Error Cause**                    | `new Error('msg', { cause: err })`  | Chains errors together to preserve root diagnostics.                     |
| **RegExp Match Indices**           | `/pattern/d`                        | Returns exact start and end position indices for matched groups.         |

---

## Code Examples & Use Cases

### 1. Class Fields & Private Members (`#`)

Brings true native encapsulation to JavaScript classes using the `#` prefix for private fields, methods, and getters/setters, along with static class fields and static private methods.

```javascript
class BankAccount {
  // Public field
  owner;
  
  // Private field (cannot be accessed outside class)
  #balance = 0;

  // Static private field
  static #totalAccounts = 0;

  constructor(owner, initialDeposit) {
    this.owner = owner;
    this.#balance = initialDeposit;
    BankAccount.#totalAccounts++;
  }

  // Private method
  #logTransaction(type, amount) {
    console.log(`[LOG]: ${type} of $${amount}`);
  }

  deposit(amount) {
    this.#balance += amount;
    this.#logTransaction('Deposit', amount);
  }

  getBalance() {
    return this.#balance;
  }
}

const account = new BankAccount('Sudhir', 500);
account.deposit(200);

console.log(account.getBalance()); // 700
console.log(account.owner);        // 'Sudhir'

// Accessing private fields throws SyntaxError/TypeError:
// console.log(account.#balance);  // ❌ Uncaught SyntaxError

```

### 2. Top-Level `await`

Modules can now use `await` at the root level without needing to wrap execution inside an `async` function or an Immediately Invoked Function Expression (IIFE).

```javascript
// dbConnection.js (ES Module)
import { connect } from './database.js';

// Top-level await blocks module loading until promise resolves cleanly
export const db = await connect('mongodb://localhost:27017');

console.log('Database connected successfully!');

```

---

### 3. Relative Indexing with `.at()`

Simplifies accessing elements from the end of arrays, strings, or typed arrays using negative indices (unlike square bracket `[]` notation, which treats negative values as string keys).

```javascript
const colors = ['red', 'green', 'blue', 'yellow'];

// Old way to get last item:
console.log(colors[colors.length - 1]); // 'yellow'

// ES2022 .at() method:
console.log(colors.at(-1)); // 'yellow'
console.log(colors.at(-2)); // 'blue'

// Works on strings too:
const message = 'JavaScript';
console.log(message.at(-1)); // 't'

```

---

### 4. `Object.hasOwn()`

Provides a robust and safe way to check if an object has a property as its own (non-inherited), replacing `Object.prototype.hasOwnProperty`.

```javascript
const person = Object.create(null); // Object without prototype
person.name = 'Sudhir';

// Old approach throws an error because person has no prototype:
// person.hasOwnProperty('name'); // ❌ TypeError: person.hasOwnProperty is not a function

// ES2022 Object.hasOwn works safely on ALL objects:
console.log(Object.hasOwn(person, 'name')); // true
console.log(Object.hasOwn(person, 'age'));  // false

```

### 5. Error Cause (`Error.prototype.cause`)

Allows chaining errors by attaching an underlying `cause` property to a newly thrown `Error`. This preserves deep error traces across architecture layers.

```javascript
async function fetchData() {
  try {
    await fetch('https://invalid-api-domain.test');
  } catch (networkError) {
    // Wrap low-level network error with domain-specific context
    throw new Error('Failed to load user profile', { cause: networkError });
  }
}

try {
  await fetchData();
} catch (err) {
  console.error(err.message); // "Failed to load user profile"
  console.error(err.cause);   // Contains original TypeError: Failed to fetch
}

```

### 6. RegExp Match Indices (`/d` flag)

Adding the `/d` flag generates a `.indices` array on match results, providing start and end position offsets for matches and their capture groups.

```javascript
const text = 'User: Sudhir';
const regex = /User: (?<name>\w+)/d;

const match = regex.exec(text);

console.log(match.indices[0]); // [0, 12] (Entire match span)
console.log(match.indices.groups.name); // [6, 12] (Span for 'Sudhir')

```
