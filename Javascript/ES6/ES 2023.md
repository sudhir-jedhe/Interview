**ECMAScript 2023 (ES14)** focused on immutable array operations, enhanced search capabilities for arrays, symbols as weak map keys, and expanding the command-line shell interface standard.

Supported across all major modern browsers since mid-2023.

---

## Key Features Overview

| Feature                     | Syntax / Method                                           | Description                                                                                        |
| --------------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Change Array by Copy**    | `.toReversed()`, `.toSorted()`, `.toSpliced()`, `.with()` | Non-mutating methods that return a new modified array copy instead of mutating the original array. |
| **Array Search from Last**  | `.findLast()`, `.findLastIndex()`                         | Searches an array starting from the end towards the beginning.                                     |
| **Symbols as WeakMap Keys** | `WeakMap` with `Symbol` keys                              | Allows unique `Symbol` primitives to be used as keys in `WeakMap` collections.                     |
| **Hashbang Grammar**        | `#!/usr/bin/env node`                                     | Standardizes executable script headers directly in JS syntax.                                      |

---

## Code Examples & Use Cases

### 1. Change Array by Copy (Non-Mutating Array Methods)

Historically, methods like `.reverse()`, `.sort()`, and `.splice()` modified arrays in place, forcing developers to manually clone arrays (`[...arr]`) before operating on them. ES14 introduced non-mutating alternatives that return a fresh array copy.

#### `.toReversed()`

```javascript
const original = [1, 2, 3, 4];
const reversed = original.toReversed();

console.log(reversed); // [4, 3, 2, 1]
console.log(original); // [1, 2, 3, 4] (Original array remains untouched!)

```

#### `.toSorted()`

```javascript
const numbers = [30, 10, 40, 20];
const sorted = numbers.toSorted((a, b) => a - b);

console.log(sorted);  // [10, 20, 30, 40]
console.log(numbers); // [30, 10, 40, 20] (Unchanged)

```

#### `.toSpliced()`

```javascript
const items = ['a', 'b', 'c', 'd'];
// Removes 1 item at index 1 and inserts 'x', 'y'
const spliced = items.toSpliced(1, 1, 'x', 'y');

console.log(spliced); // ['a', 'x', 'y', 'c', 'd']
console.log(items);   // ['a', 'b', 'c', 'd'] (Unchanged)

```

#### `.with(index, value)`

A clean non-mutating way to replace a value at a specific index without using index assignment (`arr[i] = val`).

```javascript
const fruits = ['Apple', 'Banana', 'Cherry'];
const updatedFruits = fruits.with(1, 'Mango');

console.log(updatedFruits); // ['Apple', 'Mango', 'Cherry']
console.log(fruits);        // ['Apple', 'Banana', 'Cherry'] (Unchanged)

```

### 2. Array Search from Last (`findLast` & `findLastIndex`)

Iterates through an array in reverse order (right-to-left) to find elements that match a predicate condition.

```javascript
const numbers = [5, 12, 50, 130, 44, 20];

// Finds the LAST element greater than 45
const lastLargeNumber = numbers.findLast(n => n > 45);
console.log(lastLargeNumber); // 44

// Finds the INDEX of the last element greater than 45
const lastLargeIndex = numbers.findLastIndex(n => n > 45);
console.log(lastLargeIndex); // 4 (index of 44)

```

### 3. Symbols as WeakMap Keys

Previously, `WeakMap` keys were strictly limited to Objects. ES14 allows non-registered `Symbol` primitives to be used as `WeakMap` keys because symbols can be uniquely identified and garbage-collected.

```javascript
const map = new WeakMap();

// Create a unique symbol
const secretKey = Symbol('session_token');
const sessionData = { userId: 101, role: 'Admin' };

// Store data in WeakMap using a Symbol key
map.set(secretKey, sessionData);

console.log(map.get(secretKey)); // { userId: 101, role: 'Admin' }

```

### 4. Hashbang Grammar (`#!`)

Standardizes the Hashbang/Shebang directives at the beginning of JavaScript files, allowing Node.js and other JS runtimes to execute scripts directly from command-line shells without needing preprocessing tools.

```javascript
#!/usr/bin/env node

// App CLI entry point script
console.log('Script executing directly via system CLI environment!');

```
