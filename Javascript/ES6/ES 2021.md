**ECMAScript 2021 (ES12)** introduced useful logical assignment operators, string replacement methods, weak references, and numeric separators for better code readability.

Supported across all modern browsers since mid-2021.

---

## Key Features Overview

| Feature                                | Syntax / Method | Description                                                                          |
| -------------------------------------- | --------------- | ------------------------------------------------------------------------------------ |
| **`String.prototype.replaceAll()`**    | `.replaceAll()` | Replaces all occurrences of a substring without needing a global regex.              |
| **Logical Assignment Operators**       | `&&=`, `        |                                                                                      | =`,`??=` | Combines logical operators (`&&`, ` |  | `,`??`) with variable assignment (`=`). |
| **`Promise.any()`**                    | `Promise.any()` | Resolves as soon as any one Promise fulfills. Fails if all Promises reject.          |
| **Numeric Separators**                 | `1_000_000`     | Uses underscores (`_`) as visual separators to improve readability of large numbers. |
| **`WeakRef` & `FinalizationRegistry**` | `new WeakRef()` | Creates weak references to objects, allowing garbage collection when needed.         |

## Code Examples & Use Cases

### 1. `String.prototype.replaceAll()`

Previously, replacing all instances of a string required a global regular expression (`/pattern/g`). `replaceAll()` provides a direct string-based method.

```javascript
const str = 'Apples are red. Apples are tasty.';

// Before ES2021 (using global regex):
console.log(str.replace(/Apples/g, 'Bananas'));

// ES2021 replaceAll():
console.log(str.replaceAll('Apples', 'Bananas'));
// Output: "Bananas are red. Bananas are tasty."

```

### 2. Logical Assignment Operators (`&&=`, `||=`, `??=`)

Short-circuit assignment operators that evaluate the right-hand side and assign the result only if the condition holds.

```javascript
// 1. Logical OR Assignment (||=) -> Assigns if left side is FALSY
let title = '';
title ||= 'Default Title';
console.log(title); // "Default Title"

// 2. Nullish Coalescing Assignment (??=) -> Assigns ONLY if left side is null or undefined
let count = 0;
count ??= 100;
console.log(count); // 0 (Does NOT overwrite 0 because 0 is not nullish!)

let speed;
speed ??= 60;
console.log(speed); // 60 (Assigns because speed was undefined)

// 3. Logical AND Assignment (&&=) -> Assigns ONLY if left side is TRUTHY
let user = { name: 'Sudhir' };
user.name &&= 'Sudhir Jedhe';
console.log(user.name); // "Sudhir Jedhe"

```

---

### 3. `Promise.any()`

Takes an iterable of Promises and returns a single Promise that resolves as soon as **any** of the input promises fulfills (succeeds). If all input promises reject, it rejects with an `AggregateError`.

```javascript
const p1 = new Promise((_, reject) => setTimeout(() => reject('Error 1'), 100));
const p2 = new Promise((resolve) => setTimeout(() => resolve('Fastest Success'), 200));
const p3 = new Promise((resolve) => setTimeout(() => resolve('Slow Success'), 500));

Promise.any([p1, p2, p3])
  .then((value) => console.log(value)) // "Fastest Success"
  .catch((err) => console.error(err));

```

> **Promise Methods Quick Reference:**
>
> * `Promise.all()` $\rightarrow$ Resolves when **ALL** resolve (fails fast if 1 fails).
> * `Promise.allSettled()` $\rightarrow$ Waits for **ALL** to finish (returns status array).
> * `Promise.race()` $\rightarrow$ Resolves/rejects as soon as **FIRST** settles (success or failure).
> * `Promise.any()` $\rightarrow$ Resolves as soon as **FIRST SUCCESS** fulfills.
>
>

### 4. Numeric Separators (`_`)

Improves code readability by allowing numeric literals to use underscores as visual delimiters without affecting mathematical operations.

```javascript
// Large numbers
const salary = 1_000_000_000; // 1 billion
console.log(salary === 1000000000); // true

// Byte codes and binary
const bytes = 0b1010_0001_1000_0101;

// Financial / Cents
const price = 19_99; // 1999

```

### 5. `WeakRef` and `FinalizationRegistry`

Advanced memory management features for holding weak references to objects so they can still be garbage collected.

* **`WeakRef`:** Lets you hold a reference to an object without preventing that object from being garbage collected.
* **`FinalizationRegistry`:** Lets you register a cleanup callback to run after an object has been garbage collected.

```javascript
// Register a cleanup handler
const registry = new FinalizationRegistry((heldValue) => {
  console.log(`Object with value "${heldValue}" was garbage collected!`);
});

let obj = { data: 'Cache Item' };
registry.register(obj, 'Cache Item Descriptor');

// Create a weak reference
const weakObj = new WeakRef(obj);

console.log(weakObj.deref()?.data); // "Cache Item"

// When obj is set to null, the engine can free memory during the next GC cycle
obj = null;

```
