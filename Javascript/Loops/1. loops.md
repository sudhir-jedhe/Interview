Here is a complete guide to all **JavaScript Loops and Iteration Methods**, matching your table reference, complete with 3 concrete code examples for each loop type.

---

## 1. `for` Loop

*Iterates over a block of code a set number of times using an initialization, condition, and increment expression.*

```javascript
// Example 1: Basic count from 1 to 3
for (let i = 1; i <= 3; i++) {
  console.log(i);
}
// Output: 1, 2, 3

// Example 2: Iterating backwards through an array
const items = ["A", "B", "C"];
for (let i = items.length - 1; i >= 0; i--) {
  console.log(items[i]);
}
// Output: "C", "B", "A"

// Example 3: Skipping steps (counting by 2s)
for (let i = 0; i <= 6; i += 2) {
  console.log(i);
}
// Output: 0, 2, 4, 6

```

---

## 2. `while` Loop

*Repeatedly executes a block of code as long as a specified condition evaluates to `true`.*

```javascript
// Example 1: Basic counter loop
let count = 0;
while (count < 3) {
  console.log(count);
  count++;
}
// Output: 0, 1, 2

// Example 2: Loop until a target condition is met
let balance = 100;
while (balance > 0) {
  balance -= 40;
}
console.log(balance); 
// Output: -20

// Example 3: Processing an array by popping items
const queue = ["task1", "task2"];
while (queue.length > 0) {
  console.log(queue.shift());
}
// Output: "task1", "task2"

```

---

## 3. `do...while` Loop

*Executes the code block **once before checking** if the condition is true, then continues looping as long as the condition remains true.*

```javascript
// Example 1: Executes at least once even if the condition is initially false
let i = 10;
do {
  console.log(i);
  i++;
} while (i < 5);
// Output: 10

// Example 2: Standard counter execution
let step = 1;
do {
  console.log(`Step ${step}`);
  step++;
} while (step <= 2);
// Output: "Step 1", "Step 2"

// Example 3: Generating random numbers until a condition is met
let num;
do {
  num = Math.floor(Math.random() * 5);
} while (num === 0);
console.log(num > 0); 
// Output: true

```

---

## 4. `for...in` Loop

*Iterates over all **enumerable property keys** (names/indices) of an Object or Array.*

```javascript
// Example 1: Iterating over key-value pairs of a plain object
const user = { name: "Alice", age: 25, role: "Admin" };
for (let key in user) {
  console.log(`${key}: ${user[key]}`);
}
// Output: "name: Alice", "age: 25", "role: Admin"

// Example 2: Accessing array indices (keys in arrays are strings "0", "1", ...)
const colors = ["red", "green"];
for (let index in colors) {
  console.log(index, colors[index]);
}
// Output: "0 red", "1 green"

// Example 3: Inherited property check
const parent = { family: "Smith" };
const child = Object.create(parent);
child.name = "John";

for (let key in child) {
  console.log(key); // Iterates over own and inherited properties
}
// Output: "name", "family"

```

---

## 5. `for...of` Loop

*Iterates over the **values** of iterable objects (Arrays, Strings, Maps, Sets, NodeLists, argument objects, etc.).*

```javascript
// Example 1: Iterating over Array values directly
const fruits = ["apple", "banana", "cherry"];
for (let fruit of fruits) {
  console.log(fruit);
}
// Output: "apple", "banana", "cherry"

// Example 2: Iterating over characters in a String
for (let char of "JS") {
  console.log(char);
}
// Output: "J", "S"

// Example 3: Iterating over a Set collection
const uniqueNumbers = new Set([10, 20, 20, 30]);
for (let val of uniqueNumbers) {
  console.log(val);
}
// Output: 10, 20, 30

```

---

## 6. `forEach()` Method

*Executes a provided callback function once for each element in an Array.*

```javascript
// Example 1: Accessing element values
const nums = [1, 2, 3];
nums.forEach(num => console.log(num * 2));
// Output: 2, 4, 6

// Example 2: Accessing both element and index
const animals = ["cat", "dog"];
animals.forEach((animal, idx) => {
  console.log(`${idx}: ${animal}`);
});
// Output: "0: cat", "1: dog"

// Example 3: Modifying an external variable within callback scope
let total = 0;
[10, 20, 30].forEach(val => { total += val; });
console.log(total); 
// Output: 60

```

Here is a direct comparison of all 6 JavaScript iteration mechanisms, highlighting their primary target, what they actually iterate over, break/continue support, and common use cases.

## Direct Feature Comparison Matrix

| Loop Mechanism   | Primary Target                    | What it Iterates Over              | Supports `break` / `continue`? | Supports `async/await`?   | Key Advantage                                           |
| ---------------- | --------------------------------- | ---------------------------------- | ------------------------------ | ------------------------- | ------------------------------------------------------- |
| **`for`**        | General purpose / Arrays          | Explicit numeric index / counter   | **Yes**                        | **Yes**                   | Maximum control over start, end, and step size.         |
| **`while`**      | Conditional loops                 | Evaluates condition on each turn   | **Yes**                        | **Yes**                   | Ideal when the total number of iterations is unknown.   |
| **`do...while`** | Conditional loops                 | Evaluates condition after running  | **Yes**                        | **Yes**                   | Guarantees the code block runs at least once.           |
| **`for...in`**   | Objects                           | Object **property keys** (strings) | **Yes**                        | **Yes**                   | Designed specifically for inspecting plain Object keys. |
| **`for...of`**   | Iterables (Arrays, Maps, Strings) | Collection **values** directly     | **Yes**                        | **Yes**                   | Cleanest syntax for array/iterable values.              |
| **`forEach()`**  | Arrays                            | Array elements via callback        | **No**                         | **No** *(does not await)* | Functional approach with direct access to index/array.  |

## Detailed Comparison Highlights

### 1. `for...in` vs `for...of` (Key Distinction)

* **`for...in`** loops over **keys / property names** (including inherited prototype keys).
* **`for...of`** loops over **values** of iterable objects (Arrays, Sets, Maps, Strings).

```javascript
const list = ["a", "b", "c"];

// for...in extracts INDICES (as strings)
for (let key in list) {
  console.log(key); // Output: "0", "1", "2"
}

// for...of extracts VALUES
for (let val of list) {
  console.log(val); // Output: "a", "b", "c"
}

```

---

### 2. `for...of` vs `forEach()`

* **Control Flow:** You can stop a `for...of` loop early using `break`, `continue`, or `return`. You **cannot** `break` out of a `.forEach()` loop (it executes for every element regardless).
* **Asynchronous Code:** `for...of` properly pauses execution when used with `await`. `.forEach()` ignores `async/await` callbacks and continues executing immediately.

```javascript
const items = [1, 2, 3, 4, 5];

// 1. Stopping early with break (Works in for...of, fails in forEach)
for (const num of items) {
  if (num === 3) break; // Stops loop when num is 3
  console.log(num); // Output: 1, 2
}

// 2. Handling Async/Await
async function processItems(array) {
  // Works as expected: waits 1 sec per item sequentially
  for (const item of array) {
    await new Promise(r => setTimeout(r, 1000));
    console.log(item);
  }
}

```

---

### 3. `while` vs `do...while`

* **`while`** checks the condition **before** entering the loop body. If the condition is false initially, the block never executes.
* **`do...while`** executes the block **first**, then checks the condition at the end.

```javascript
let count = 10;

// while check fails immediately -> 0 executions
while (count < 5) {
  console.log("while loop");
  count++;
}

// do...while runs body first -> 1 execution guaranteed
do {
  console.log("do...while loop"); // Output: "do...while loop"
  count++;
} while (count < 5);

```

---

## When to Use Which?

1. **Use `for...of**` as your default choice for iterating through Array items, Strings, Sets, or Maps.
2. **Use `for...in**` when you need to inspect key names on a plain JavaScript Object `{}`.
3. **Use `forEach()**` when writing functional code where you need both the `element` and its `index`, and do not need to break early.
4. **Use standard `for**` when you need custom index logic (e.g., step by 2, loop backwards, or skip elements).
5. **Use `while` or `do...while**` when looping based on a changing condition rather than a fixed collection size.
