Implementing a dark mode theme system using **CSS variables (tokens)** along with either **React Context** or **Redux Toolkit** and **system preferences (`prefers-color-scheme`)** is the standard approach for frontend development.

Using CSS variables ensures that changing themes happens instantly in the browser without re-rendering every React component.

Here is a complete guide to building this architecture.

---

## 1. Define Design Tokens using CSS Variables

Define design tokens at the `:root` level using CSS variables, and override them under a `.dark` class (or `data-theme="dark"` attribute).

```css
/* src/styles/theme.css */
:root {
  /* Light Mode Design Tokens */
  --bg-primary: #ffffff;
  --bg-secondary: #f3f4f6;
  --text-primary: #111827;
  --text-secondary: #4b5563;
  --accent-color: #2563eb;
  --border-color: #e5e7eb;
}

/* Dark Mode Tokens */
.dark {
  --bg-primary: #0f172a;
  --bg-secondary: #1e293b;
  --text-primary: #f8fafc;
  --text-secondary: #94a3b8;
  --accent-color: #3b82f6;
  --border-color: #334155;
}

/* Global resets using CSS tokens */
body {
  background-color: var(--bg-primary);
  color: var(--text-primary);
  transition:
    background-color 0.2s ease,
    color 0.2s ease;
}
```

## 2. Approach A: Implementation with React Context (Recommended)

React Context is ideal for theme management because theme changes affect global presentation rather than complex business state.

### `ThemeContext.tsx`

```tsx
import React, { createContext, useContext, useEffect, useState } from "react";

type ThemeMode = "light" | "dark" | "system";

interface ThemeContextType {
  theme: ThemeMode; // 'light' | 'dark' | 'system'
  resolvedTheme: "light" | "dark"; // Actual theme applied ('light' or 'dark')
  setTheme: (theme: ThemeMode) => void;
}

const ThemeContext = createContext<ThemeContextType | undefined>(undefined);

export const ThemeProvider: React.FC<{ children: React.ReactNode }> = ({
  children,
}) => {
  // Initialize theme state from localStorage, fallback to 'system'
  const [theme, setThemeState] = useState<ThemeMode>(() => {
    return (localStorage.getItem("app-theme") as ThemeMode) || "system";
  });

  const [resolvedTheme, setResolvedTheme] = useState<"light" | "dark">("light");

  useEffect(() => {
    const root = document.documentElement;
    const mediaQuery = window.matchMedia("(prefers-color-scheme: dark)");

    const applyTheme = () => {
      let activeTheme: "light" | "dark";

      if (theme === "system") {
        activeTheme = mediaQuery.matches ? "dark" : "light";
      } else {
        activeTheme = theme;
      }

      setResolvedTheme(activeTheme);

      // Toggle .dark class on <html> element
      if (activeTheme === "dark") {
        root.classList.add("dark");
      } else {
        root.classList.remove("dark");
      }
    };

    applyTheme();

    // Listener for System Preference Changes (when set to 'system')
    const handleSystemChange = () => {
      if (theme === "system") {
        applyTheme();
      }
    };

    mediaQuery.addEventListener("change", handleSystemChange);
    return () => mediaQuery.removeEventListener("change", handleSystemChange);
  }, [theme]);

  const setTheme = (newTheme: ThemeMode) => {
    setThemeState(newTheme);
    localStorage.setItem("app-theme", newTheme);
  };

  return (
    <ThemeContext.Provider value={{ theme, resolvedTheme, setTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

export const useTheme = () => {
  const context = useContext(ThemeContext);
  if (!context) throw new Error("useTheme must be used within a ThemeProvider");
  return context;
};
```

## 3. Approach B: Implementation with Redux Toolkit

If your application strictly manages all state in Redux, you can encapsulate theme management in a slice.

### `themeSlice.ts`

```typescript
import { createSlice, PayloadAction } from "@reduxjs/toolkit";

export type ThemeMode = "light" | "dark" | "system";

interface ThemeState {
  mode: ThemeMode;
}

const initialMode =
  (localStorage.getItem("app-theme") as ThemeMode) || "system";

const initialState: ThemeState = {
  mode: initialMode,
};

export const themeSlice = createSlice({
  name: "theme",
  initialState,
  reducers: {
    setThemeMode: (state, action: PayloadAction<ThemeMode>) => {
      state.mode = action.payload;
      localStorage.setItem("app-theme", action.payload);
    },
  },
});

export const { setThemeMode } = themeSlice.actions;
export default themeSlice.reducer;
```

### `useThemeSync.ts` (Custom Hook to Sync DOM with Redux)

```typescript
import { useEffect } from "react";
import { useAppSelector } from "./hooks"; // Redux Typed Hooks

export function useThemeSync() {
  const mode = useAppSelector((state) => state.theme.mode);

  useEffect(() => {
    const root = document.documentElement;
    const mediaQuery = window.matchMedia("(prefers-color-scheme: dark)");

    const updateDOM = () => {
      const isDark =
        mode === "dark" || (mode === "system" && mediaQuery.matches);

      if (isDark) {
        root.classList.add("dark");
      } else {
        root.classList.remove("dark");
      }
    };

    updateDOM();

    mediaQuery.addEventListener("change", updateDOM);
    return () => mediaQuery.removeEventListener("change", updateDOM);
  }, [mode]);
}
```

## 4. Theme Selector Component (UI Switcher)

Render a toggle that allows users to pick **Light**, **Dark**, or match their **System Preference**.

```tsx
// src/components/ThemeToggle.tsx
import React from "react";
import { useTheme } from "../context/ThemeContext"; // Or Redux actions

export function ThemeToggle() {
  const { theme, setTheme } = useTheme();

  return (
    <div className="theme-toggle flex gap-2">
      <button
        onClick={() => setTheme("light")}
        className={theme === "light" ? "active-btn" : ""}
      >
        ☀️ Light
      </button>

      <button
        onClick={() => setTheme("dark")}
        className={theme === "dark" ? "active-btn" : ""}
      >
        🌙 Dark
      </button>

      <button
        onClick={() => setTheme("system")}
        className={theme === "system" ? "active-btn" : ""}
      >
        💻 System
      </button>
    </div>
  );
}
```

## 5. Preventing "Flash of Unstyled Text/Theme" (FOUT)

When reading `localStorage` in React client code, users might experience a brief white flash before dark mode loads. To prevent this, inject a small script into the `<head>` of your HTML document:

```html
<!-- index.html or _document.tsx -->
<head>
  <script>
    (function () {
      const savedTheme = localStorage.getItem("app-theme") || "system";
      const systemDark = window.matchMedia(
        "(prefers-color-scheme: dark)",
      ).matches;

      if (savedTheme === "dark" || (savedTheme === "system" && systemDark)) {
        document.documentElement.classList.add("dark");
      } else {
        document.documentElement.classList.remove("dark");
      }
    })();
  </script>
</head>
```

### Summary Checklist for Dark Mode Systems

| Strategy              | Best Practice                                                                                        |
| --------------------- | ---------------------------------------------------------------------------------------------------- |
| **Design Tokens**     | Use CSS variables (`--bg-primary`, `--text-primary`) mapped under `:root` and `.dark`.               |
| **System Preference** | Listen for OS changes via `window.matchMedia('(prefers-color-scheme: dark)')`.                       |
| **Flash Prevention**  | Apply the `.dark` class using an inline script in `<head>` before React renders.                     |
| **Context vs Redux**  | Use **Context** for pure UI/theme needs; use **Redux** only if required by strict state constraints. |
