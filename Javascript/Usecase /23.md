Handling online and offline states in React using a **Service Worker** provides a true Progressive Web App (PWA) experience: users can continue viewing cached assets and data offline, and automatically sync or notify the user when the connection is restored.

Here is a complete, modern guide to implementing offline support using **Workbox** (the modern standard for Service Workers) and **React Custom Hooks**.

---

## 1. Create an Offline Status Custom Hook (`useOnlineStatus`)

First, create a custom React hook that tracks the browser's `navigator.onLine` state and listens for connection status changes.

```typescript
// src/hooks/useOnlineStatus.ts
import { useState, useEffect } from "react";

export function useOnlineStatus(): boolean {
  const [isOnline, setIsOnline] = useState<boolean>(() =>
    typeof navigator !== "undefined" ? navigator.onLine : true,
  );

  useEffect(() => {
    const handleOnline = () => setIsOnline(true);
    const handleOffline = () => setIsOnline(false);

    window.addEventListener("online", handleOnline);
    window.addEventListener("offline", handleOffline);

    return () => {
      window.removeEventListener("online", handleOnline);
      window.removeEventListener("offline", handleOffline);
    };
  }, []);

  return isOnline;
}
```

## 2. Set Up the Service Worker (using Workbox)

Workbox handles caching static assets (HTML, CSS, JS) and caching API responses with smart caching strategies.

### `src/sw.js` (Service Worker Script)

```javascript
import { precacheAndRoute } from "workbox-precaching";
import { registerRoute } from "workbox-routing";
import {
  StaleWhileRevalidate,
  NetworkFirst,
  CacheFirst,
} from "workbox-strategies";
import { ExpirationPlugin } from "workbox-expiration";

// 1. Precache static React build assets (injected automatically during build)
precacheAndRoute(self.__WB_MANIFEST || []);

// 2. Cache API Requests: Network First (fall back to cache when offline)
registerRoute(
  ({ url }) => url.pathname.startsWith("/api/"),
  new NetworkFirst({
    cacheName: "api-cache",
    plugins: [
      new ExpirationPlugin({
        maxEntries: 50,
        maxAgeSeconds: 24 * 60 * 60, // 24 hours
      }),
    ],
  }),
);

// 3. Cache Images: Cache First (load instantly from cache)
registerRoute(
  ({ request }) => request.destination === "image",
  new CacheFirst({
    cacheName: "images-cache",
    plugins: [
      new ExpirationPlugin({
        maxEntries: 60,
        maxAgeSeconds: 30 * 24 * 60 * 60, // 30 Days
      }),
    ],
  }),
);

// Skip waiting to immediately activate updated service worker
self.addEventListener("message", (event) => {
  if (event.data && event.data.type === "SKIP_WAITING") {
    self.skipWaiting();
  }
});
```

## 3. Register the Service Worker in React

Register the Service Worker in your React application entry point (`index.js` or `main.tsx`).

```typescript
// src/serviceWorkerRegistration.ts
export function registerServiceWorker() {
  if ("serviceWorker" in navigator && process.env.NODE_ENV === "production") {
    window.addEventListener("load", () => {
      navigator.serviceWorker
        .register("/sw.js")
        .then((registration) => {
          console.log("ServiceWorker registered:", registration.scope);
        })
        .catch((error) => {
          console.error("ServiceWorker registration failed:", error);
        });
    });
  }
}
```

## 4. Render Offline UI Banner & Sync Manager in React

Now, consume the `useOnlineStatus` hook to render an **Offline Banner** and synchronize pending operations when back online.

```tsx
// src/components/OfflineNotifier.tsx
import React, { useEffect } from "react";
import { useOnlineStatus } from "../hooks/useOnlineStatus";

export function OfflineNotifier() {
  const isOnline = useOnlineStatus();

  useEffect(() => {
    if (isOnline) {
      // Trigger background sync or refetch stale data when connection returns
      console.log("Back online! Syncing data...");
      syncOfflineQueue();
    }
  }, [isOnline]);

  if (isOnline) return null;

  return (
    <div className="fixed bottom-4 right-4 bg-yellow-500 text-black px-4 py-3 rounded-lg shadow-lg flex items-center gap-2 z-50">
      <svg className="w-5 h-5 fill-current" viewBox="0 0 20 20">
        <path d="M3.707 2.293a1 1 0 00-1.414 1.414l14 14a1 1 0 001.414-1.414l-14-14zM10 5a7.5 7.5 0 017.5 7.5c0 .883-.15 1.731-.428 2.52l-1.528-1.528A5.474 5.474 0 0015.5 12.5 5.5 5.5 0 0010 7c-.89 0-1.724.212-2.462.589L6.009 6.06A7.464 7.464 0 0110 5z" />
      </svg>
      <span>You are currently offline. Showing cached data.</span>
    </div>
  );
}

// Optional helper to sync queued offline requests
async function syncOfflineQueue() {
  const pendingRequests = JSON.parse(
    localStorage.getItem("offline_queue") || "[]",
  );
  if (pendingRequests.length === 0) return;

  for (const req of pendingRequests) {
    try {
      await fetch(req.url, {
        method: req.method,
        body: JSON.stringify(req.body),
      });
    } catch (err) {
      console.error("Sync failed:", err);
    }
  }

  localStorage.removeItem("offline_queue");
}
```

## 5. Offline Data Handling with React Query / TanStack Query

If you use **TanStack Query**, offline mutation queuing and cache management work seamlessly out of the box:

```tsx
import { useQueryClient } from "@tanstack/react-query";
import { useOnlineStatus } from "./useOnlineStatus";

export function AppContent() {
  const isOnline = useOnlineStatus();
  const queryClient = useQueryClient();

  useEffect(() => {
    if (isOnline) {
      // Automatically refetch stale queries when back online
      queryClient.invalidateQueries();
    }
  }, [isOnline, queryClient]);

  return <div>{/* Your App */}</div>;
}
```

### Summary Checklist for React Service Worker Setup

| Feature                 | Strategy                                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------- |
| **Detect Connection**   | Use `window.addEventListener('online' / 'offline')` in a custom hook.                              |
| **App Assets (JS/CSS)** | Precache static assets using Workbox `precacheAndRoute`.                                           |
| **API Requests**        | Use `NetworkFirst` strategy so cached API responses serve when offline.                            |
| **POST/PUT Data**       | Store user actions in IndexedDB or `localStorage` when offline, then flush the queue on reconnect. |
