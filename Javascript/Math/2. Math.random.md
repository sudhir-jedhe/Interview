Here is a complete breakdown of how `Math.random()` works in JavaScript, including table explanations, breakdown of standard random expressions, and proper random functions for both **min-inclusive/max-exclusive** and **min-inclusive/max-inclusive** ranges.

---

## 1. `Math.random()` Expression Reference Table

| Expression                           | Range From       | Range To             | Result Type    | Description                                                                 |
| ------------------------------------ | ---------------- | -------------------- | -------------- | --------------------------------------------------------------------------- |
| `Math.random()`                      | `0` *(included)* | `< 1` *(excluded)*   | Floating-point | Returns a random decimal number starting at 0 up to (but never reaching) 1. |
| `Math.random() * 10`                 | `0` *(included)* | `< 10` *(excluded)*  | Floating-point | Scales the random float range from 0 up to 9.999...                         |
| `Math.random() * 100`                | `0` *(included)* | `< 100` *(excluded)* | Floating-point | Scales the random float range from 0 up to 99.999...                        |
| `Math.floor(Math.random() * 10)`     | `0`              | `9`                  | Integer        | Rounds down to the nearest whole integer, producing integers from 0 to 9.   |
| `Math.floor(Math.random() * 100)`    | `0`              | `99`                 | Integer        | Rounds down to produce integers from 0 to 99.                               |
| `Math.floor(Math.random() * 10) + 1` | `1`              | `10`                 | Integer        | Shifts range up by 1 to produce integers from 1 to 10.                      |

---

## 2. Examples of Standard Random Formulas

### Example 1: Random Decimal Between 0 and 1

```javascript
// Generates a random float value like 0.7348123...
const randomFloat = Math.random();
console.log(randomFloat);

```

### Example 2: Random Integer Between 0 and 9

```javascript
// Generates an integer from 0, 1, 2, ..., 9
const randomDigit = Math.floor(Math.random() * 10);
console.log(randomDigit);

```

### Example 3: Random Integer Between 1 and 10 (Dice Roll Style)

```javascript
// Generates an integer from 1, 2, 3, ..., 10
const randomOneToTen = Math.floor(Math.random() * 10) + 1;
console.log(randomOneToTen);

```

## 3. Proper Random Functions

Creating helper functions helps manage integer bounds cleanly across your code.

### Variant A: Min Included, Max Excluded (`min` to `max - 1`)

*Returns an integer starting at `min` up to, but not including, `max`.*

```javascript
function getRndInteger(min, max) {
  return Math.floor(Math.random() * (max - min)) + min;
}

// Example 1: Generate integer between 1 and 4 (Outputs 1, 2, or 3)
console.log(getRndInteger(1, 4));

// Example 2: Generate integer between 10 and 20 (Outputs 10 to 19)
console.log(getRndInteger(10, 20));

// Example 3: Select a random element index from an array length
const colors = ["red", "green", "blue"];
const randomIndex = getRndInteger(0, colors.length); // 0 to 2
console.log(colors[randomIndex]);

```

---

### Variant B: Min Included, Max Included (`min` to `max`)

*Returns an integer starting at `min` up to and **including** `max`.*

```javascript
function getRndIntegerInclusive(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

// Example 1: Simulate a 6-sided dice roll (Outputs 1, 2, 3, 4, 5, or 6)
console.log(getRndIntegerInclusive(1, 6));

// Example 2: Generate a percentage integer between 1 and 100
console.log(getRndIntegerInclusive(1, 100));

// Example 3: Random year between 2020 and 2026 (inclusive)
console.log(getRndIntegerInclusive(2020, 2026));

```
