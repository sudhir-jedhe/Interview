In JavaScript, the expression **`[] + {}`** evaluates to:

```javascript
"[object Object]"

```

### Why This Happens (Step-by-Step Coercion)

1. **Binary Addition Operator (`+`):**
Because both operands are objects, the JavaScript engine calls the abstract operation `ToPrimitive()` on each side with a default hint of `"default"` (which resolves to number/string preference).
2. **Primitive Coercion of `[]`:**

* The array calls its default `.toString()` method.
* An empty array's `.toString()` returns an empty string: `""`.

1. **Primitive Coercion of `{}`:**

* The plain object calls its default `.toString()` method (`Object.prototype.toString.call({})`).
* This returns `"[object Object]"`.

1. **String Concatenation:**

* Since one of the primitive operands is now a string, the `+` operator performs string concatenation:

```javascript
"" + "[object Object]" // "[object Object]"

```

---

### Comparison Note: `[] + {}` vs. `{} + []`

Unlike `[] + {}`, the reverse expression **`{} + []`** produces different results depending on the context:

* **`[] + {}`**: Always evaluates to `"[object Object]"` in all contexts.
* **`{} + []`** *(as a standalone statement or in the browser console)*: Evaluates to **`0`**, because the leading `{}` is parsed as an empty code block, leaving `+[]` which coerces to `0`.
