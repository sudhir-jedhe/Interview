```js
  let obj = { num: 2 };
  const fun = (x = { ...obj }) => {
    console.log((x.num /= 2));
  };
  fun();
  fun();
  fun(obj);
  fun(obj);
```

Here is the output of the code:

```text

1
1
0.5

```

### Explanation

1. **First `fun()` call:**
No argument is passed, triggering the default parameter `x = { ...obj }`. This creates a **new copy** of `obj` (`{ num: 2 }`). `x.num /= 2` divides its `num` property by 2 and logs **`1`**. The original `obj` is untouched.
2. **Second `fun()` call:**
The default parameter evaluates again, creating **another fresh copy** of `obj` (`{ num: 2 }`). Modifying `x.num` logs **`1`** and leaves the original `obj` untouched.
3. **Third `fun(obj)` call:**
`obj` is passed explicitly by reference, bypassing the default parameter. `x` now points to the original `obj` (`{ num: 2 }`). `x.num /= 2` mutates `obj.num` to `1` and logs **`1`**.
4. **Fourth `fun(obj)` call:**
`obj` is passed by reference again, but its `num` property is now `1`. `x.num /= 2` divides `1` by 2, mutating `obj.num` to `0.5` and logging **`0.5`**.
