Here is a breakdown of the foundational building blocks of JavaScript, complete with examples.

## 1. Basic Syntax

JavaScript syntax is the set of rules that defines a correctly structured program. It is **case-sensitive** (so `myVariable` and `myvariable` are different) and executes instructions top-to-bottom.

```javascript
// This is a single-line comment

/* 
   This is a 
   multi-line comment 
*/

// Statements are instructions telling the computer what to do.
// They typically end with a semicolon (though JS can often insert them automatically).
console.log("Hello, World!"); 

// Case sensitivity matters
let City = "London";
let city = "Paris"; // This is a completely separate variable

```

---

## 2. Variables

Variables are containers for storing data values. Modern JavaScript uses two main keywords to declare them:

* **`const`**: Short for "constant." Use this by default. Once you assign a value to a `const` variable, you cannot reassign it to something else.
* **`let`**: Use this when you expect the value to change later (like a counter in a game or a user's input).
* **`var`**: The old way of declaring variables before 2015. You will see it in older codebases, but it is generally avoided today due to confusing scoping rules.

```javascript
const birthYear = 1990;
// birthYear = 1991;  <-- This would throw an error!

let currentAge = 35;
currentAge = 36;      // This is perfectly fine.

var legacyName = "Bob"; // Works, but best to avoid in new code

```

## 3. Data Types

JavaScript variables can hold different types of data. These are divided into two main categories: **Primitives** (simple, single values) and **Reference Types** (complex collections).

### Primitive Data Types

Primitives are the most basic data types. There are seven of them:

```javascript
// 1. String: Text wrapped in quotes (single, double, or backticks).
const greeting = 'Hello';
const name = "Alice";
const template = `Welcome, ${name}!`; // Backticks allow embedding variables

// 2. Number: Both integers and decimals (floating point).
const score = 100;
const price = 19.99;

// 3. Boolean: Represents a logical entity and can only be true or false.
const isGameOver = false;
const hasAdminRights = true;

// 4. Undefined: A variable that has been declared but has no assigned value yet.
let userLocation;
console.log(userLocation); // Outputs: undefined

// 5. Null: The intentional absence of any value. You explicitly set it.
const activeSession = null;

// 6. Symbol: A unique and immutable identifier (mostly used for advanced object properties).
const uniqueId = Symbol('id');

// 7. BigInt: Used for mathematically massive numbers beyond the safe limit of standard Numbers.
const massiveNumber = 9007199254740991n; 

```

### Reference Types (Objects)

Reference types allow you to group related data and functions together.

```javascript
// 1. Object: A collection of key-value pairs inside curly braces {}.
const person = {
  firstName: "Alice",
  age: 30,
  isEmployed: true
};

// You access object properties using dot notation:
console.log(person.firstName); // Outputs: "Alice"


// 2. Array: An ordered list of values inside square brackets []. 
// (Technically, arrays are a specific type of Object in JavaScript).
const colors = ["red", "green", "blue"];

// You access array elements using their index position (starting at 0):
console.log(colors[0]); // Outputs: "red"
console.log(colors[2]); // Outputs: "blue"

```
