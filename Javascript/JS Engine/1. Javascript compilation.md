The JavaScript compilation process is executed inside the JavaScript engine (like V8 in Chrome/Node.js, SpiderMonkey in Firefox, or JavaScriptCore in Safari). Modern JS engines use **Just-In-Time (JIT) Compilation**, combining compilation and execution to run code at native speed.

---

```
Source Code
    │
    ▼
[ 1. Tokenization / Lexing ]
    │
    ▼
[ 2. Parsing (AST Generation) ]
    │
    ▼
[ 3. Bytecode / Code Generation ]  ──► Execution (JIT Compiler / Interpreter)

```

---

## Step 1: Tokenization / Lexing

Before reading logic, the engine breaks raw text into individual, meaningful chunks called **tokens**.

* **Tokenization:** Breaks the stream of characters into recognized lexical elements (keywords, operators, identifiers, literals).
* **Lexing:** Identifies tokens and attaches **contextual meaning** based on stateful grammar rules.

### Example

For the source code:

```javascript
const age = 25;

```

The lexer breaks it down into tokens:

```javascript
[
  { type: 'Keyword',    value: 'const' },
  { type: 'Identifier', value: 'age' },
  { type: 'Punctuator', value: '=' },
  { type: 'Numeric',    value: '25' },
  { type: 'Punctuator', value: ';' }
]

```

---

## Step 2: Parsing (Building the AST)

The parser takes the flat list of tokens and converts it into a nested, hierarchical tree called an **Abstract Syntax Tree (AST)**. The AST represents the grammatical structure of the program.

### Syntax Analysis

During this step, the engine checks for syntax errors (e.g., missing parentheses or invalid keywords). If syntax is invalid, parsing halts and throws a `SyntaxError` **before any code executes**.

### Abstract Syntax Tree (AST) Example

For `const age = 25;`, the resulting AST node looks like this:

```
VariableDeclaration (const)
  └── VariableDeclarator
        ├── Identifier (age)
        └── NumericLiteral (25)

```

---

## Step 3: Code Generation & Execution (JIT Compilation)

Once the AST is ready, modern JavaScript engines pass it to an **Interpreter** and a **JIT Compiler** to generate executable instructions.

```
                  ┌────────────────┐
                  │      AST       │
                  └───────┬────────┘
                          │
                          ▼
                 Interpreter (e.g., Ignition)
                          │
                  Generates Bytecode
                          │
           ┌──────────────┴──────────────┐
           ▼                             ▼
       Execution                Optimization Pipeline
  (Runs immediately)             (e.g., TurboFan JIT)
                                         │
                                Generates Optimized
                                    Machine Code

```

### 1. Bytecode Generation (Interpreter)

An interpreter (like V8’s **Ignition**) takes the AST and translates it into lightweight **Bytecode**. Bytecode starts executing immediately, keeping the initial startup time low.

### 2. Just-In-Time (JIT) Optimization

While bytecode executes, the engine monitors ("profiles") hot code—functions or loops run repeatedly:

* **Hot Functions:** Passed to an optimizing compiler (like V8’s **TurboFan**).
* **Machine Code:** Recompiled into highly optimized native machine code (CPU instructions) for fast execution.
* **Deoptimization:** If assumptions change dynamically at runtime (e.g., passing a string into a function that previously only handled numbers), the engine discards the optimized machine code and falls back to bytecode.

---

## Summary of Stages

| Stage                     | Input              | Output                     | Main Role                                        |
| ------------------------- | ------------------ | -------------------------- | ------------------------------------------------ |
| **Tokenization / Lexing** | Source Code String | Array of Tokens            | Converts characters into vocabulary units        |
| **Parsing**               | Array of Tokens    | Abstract Syntax Tree (AST) | Validates syntax and builds structural tree      |
| **Code Generation / JIT** | AST                | Bytecode / Machine Code    | Translates tree into executable CPU instructions |
