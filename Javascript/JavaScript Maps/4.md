Here is the complete JavaScript **`Map`** reference formatted directly for clear navigation and quick lookups.

---

## JavaScript `Map` Reference Summary

| Method / Property     | Type          | Description                                                                 |
| --------------------- | ------------- | --------------------------------------------------------------------------- |
| **`new Map()`**       | Constructor   | Creates a new `Map` object                                                  |
| **`clear()`**         | Method        | Removes all elements from a `Map`                                           |
| **`delete(key)`**     | Method        | Removes a `Map` element specified by a key                                  |
| **`entries()`**       | Method        | Returns an iterator object with the `[key, value]` pairs in a `Map`         |
| **`forEach()`**       | Method        | Invokes a callback function for each key-value pair in a `Map`              |
| **`get(key)`**        | Method        | Gets the value associated with a key in a `Map`                             |
| **`Map.groupBy()`**   | Static Method | Groups iterable elements into a `Map` according to returned callback values |
| **`has(key)`**        | Method        | Returns `true` if a key exists in a `Map`                                   |
| **`keys()`**          | Method        | Returns an iterator object containing all keys in a `Map`                   |
| **`set(key, value)`** | Method        | Sets or updates the value for a key in a `Map`                              |
| **`size`**            | Property      | Returns the total number of elements in a `Map`                             |
| **`values()`**        | Method        | Returns an iterator object containing all values in a `Map`                 |

---

## Method Code Examples

### 1. `new Map()`, `set()`, and `size`

```javascript
// Create a new Map instance
const userRoles = new Map();

// Add key-value pairs
userRoles.set("alice", "Admin");
userRoles.set("bob", "Editor");

console.log(userRoles.size); // Output: 2

```

### 2. `get()`, `has()`, and `delete()`

```javascript
const map = new Map([["theme", "dark"], ["notifications", true]]);

// Check key existence and get values
console.log(map.has("theme")); // Output: true
console.log(map.get("theme")); // Output: "dark"

// Delete an element
map.delete("notifications");
console.log(map.has("notifications")); // Output: false

```

### 3. Iteration: `keys()`, `values()`, `entries()`, and `forEach()`

```javascript
const fruitMap = new Map([["apple", 5], ["banana", 2]]);

// Get iterators
console.log([...fruitMap.keys()]);   // Output: ["apple", "banana"]
console.log([...fruitMap.values()]); // Output: [5, 2]
console.log([...fruitMap.entries()]); // Output: [["apple", 5], ["banana", 2]]

// Loop through elements
fruitMap.forEach((value, key) => {
  console.log(`${key}: ${value}`);
});

```

### 4. `Map.groupBy()` (Static Method)

```javascript
const inventory = [
  { name: "Asparagus", type: "vegetable" },
  { name: "Bananas", type: "fruit" },
  { name: "Cherries", type: "fruit" }
];

// Group items by 'type' into a Map
const groupedMap = Map.groupBy(inventory, item => item.type);

console.log(groupedMap.get("fruit"));
// Output: [{ name: "Bananas", type: "fruit" }, { name: "Cherries", type: "fruit" }]

```

### 5. `clear()`

```javascript
const cache = new Map([["a", 100], ["b", 200]]);

cache.clear();
console.log(cache.size); // Output: 0

```
