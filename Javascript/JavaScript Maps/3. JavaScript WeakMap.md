A **`WeakMap`** is a built-in collection of key-value pairs in JavaScript where **keys must be objects (or non-registered Symbols)** and are held as **weak references**.

If a key object no longer has any other references in your application, it becomes eligible for automatic **garbage collection**, and its corresponding key-value entry is safely cleaned up from memory.

---

## 1. How Weak References Work

To understand `WeakMap`, contrast how standard `Map` handles memory versus `WeakMap`:

---

### Standard `Map` (Strong Reference)

```javascript
let user = { name: "Alice" };
const map = new Map();

map.set(user, "User Profile Data");

// Remove the primary variable reference
user = null;

// The { name: "Alice" } object CANNOT be garbage collected
// because map retains a strong reference to it!
console.log(map.size); // Output: 1

```

---

### `WeakMap` (Weak Reference)

```javascript
let user = { name: "Alice" };
const weakMap = new WeakMap();

weakMap.set(user, "User Profile Data");

// Remove the primary variable reference
user = null;

// The { name: "Alice" } object is now eligible for Garbage Collection.
// Once garbage collected, its entry in weakMap automatically vanishes!

```

---

## 2. API & Method Overview

Because entries are garbage-collected non-deterministically in the background, `WeakMap` **does not support iteration** or size inspection. It only exposes 4 primary methods:

| Method                | Description                                              | Example               |
| --------------------- | -------------------------------------------------------- | --------------------- |
| **`set(key, value)`** | Adds/updates a key-value pair (`key` must be an Object). | `wm.set(obj, "data")` |
| **`get(key)`**        | Retrieves value associated with `key` (or `undefined`).  | `wm.get(obj)`         |
| **`has(key)`**        | Returns boolean if `key` exists in the WeakMap.          | `wm.has(obj)`         |
| **`delete(key)`**     | Removes entry associated with `key`.                     | `wm.delete(obj)`      |

### What `WeakMap` Cannot Do

* ❌ **No primitive keys:** `wm.set("stringKey", 123)` throws a `TypeError`.
* ❌ **No `.size` property:** You cannot check how many items are inside.
* ❌ **No `.clear()` method:** Entries cannot be cleared all at once.
* ❌ **No iteration:** Methods like `.keys()`, `.values()`, `.entries()`, or `for...of` loops do not exist.

---

## 3. Practical Use Cases

### A. Associated Metadata & DOM Node Tracking

Attach metadata to third-party objects or DOM elements without modifying them or risking memory leaks when elements are removed from the DOM.

```javascript
const clickCounts = new WeakMap();

function registerClick(buttonElement) {
  const count = clickCounts.get(buttonElement) || 0;
  clickCounts.set(buttonElement, count + 1);
}

let btn = document.createElement("button");
registerClick(btn); // Count: 1
registerClick(btn); // Count: 2

// When the DOM node is removed and dereferenced:
btn.remove();
btn = null; 
// Button node and its click count in clickCounts are garbage-collected together!

```

---

### B. Object Memoization & Caching

Cache calculation results derived from objects without holding onto the objects past their natural lifecycle.

```javascript
const resultCache = new WeakMap();

function processData(dataObj) {
  if (resultCache.has(dataObj)) {
    return resultCache.get(dataObj);
  }

  const computedResult = { total: dataObj.values.reduce((a, b) => a + b, 0) };
  resultCache.set(dataObj, computedResult);
  return computedResult;
}

let payload = { values: [10, 20, 30] };
processData(payload); // Computes and caches

// When payload is no longer needed:
payload = null; // Cache automatically cleared from memory!

```

---

### C. Private Data Encapsulation

Store private class instance variables that cannot be accessed directly from the outside object reference.

```javascript
const privateMembers = new WeakMap();

class BankAccount {
  constructor(initialBalance) {
    privateMembers.set(this, { balance: initialBalance });
  }

  getBalance() {
    return privateMembers.get(this).balance;
  }
}

const account = new BankAccount(500);
console.log(account.getBalance()); // Output: 500
console.log(account.balance);    // Output: undefined (Private!)

```
