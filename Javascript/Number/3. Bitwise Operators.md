JavaScript treats numbers as 64-bit floating-point numbers internally, but when performing **bitwise operations**, it temporarily converts operands into **32-bit signed integers** (or 32-bit unsigned for `>>>`), performs the bit-level math, and converts the result back to a standard JavaScript number.

Here is a complete breakdown of all 7 JavaScript bitwise operators, complete with binary visual representations and practical real-world use cases.

---

## Quick Reference Summary

| Operator  | Name                      | Description                                                      | Example ($A=5, B=1$)                           | Result       |
| --------- | ------------------------- | ---------------------------------------------------------------- | ---------------------------------------------- | ------------ |
| **`&`**   | **Bitwise AND**           | Sets each bit to `1` if **both** bits are `1`.                   | `5 & 1`                                        | `1`          |
| **`       | `**                       | **Bitwise OR**                                                   | Sets each bit to `1` if **either** bit is `1`. | `5           | 1` | `5` |
| **`^`**   | **Bitwise XOR**           | Sets each bit to `1` if **only one** bit is `1`.                 | `5 ^ 1`                                        | `4`          |
| **`~`**   | **Bitwise NOT**           | Inverts all bits (flips `0` to `1` and `1` to `0`).              | `~5`                                           | `-6`         |
| **`<<`**  | **Zero-fill Left Shift**  | Shifts bits left, filling `0`s from the right.                   | `5 << 1`                                       | `10`         |
| **`>>`**  | **Signed Right Shift**    | Shifts bits right, preserving the sign bit (leftmost).           | `-5 >> 1`                                      | `-3`         |
| **`>>>`** | **Zero-fill Right Shift** | Shifts bits right, pushing `0`s from the left (always positive). | `-5 >>> 1`                                     | `2147483645` |

---

## 1. Bitwise Logical Operators (`&`, `|`, `^`, `~`)

For these examples, let's look at `5` (`0101` in binary) and `3` (`0011` in binary):

### Bitwise AND (`&`)

Compares corresponding bits; returns `1` only if both bits are `1`.

```
  0101  (5)
& 0011  (3)
------
  0001  (1 in decimal)

```

```javascript
console.log(5 & 3); // 1

```

### Bitwise OR (`|`)

Compares corresponding bits; returns `1` if at least one bit is `1`.

```
  0101  (5)
| 0011  (3)
------
  0111  (7 in decimal)

```

```javascript
console.log(5 | 3); // 7

```

### Bitwise XOR (`^`)

Compares corresponding bits; returns `1` if the bits are **different**.

```
  0101  (5)
^ 0011  (3)
------
  0110  (6 in decimal)

```

```javascript
console.log(5 ^ 3); // 6

```

### Bitwise NOT (`~`)

Inverts all bits. In 32-bit signed Two's Complement representation, `~x` is always equal to **`-(x + 1)`**.

```javascript
// ~5 becomes -(5 + 1) = -6
console.log(~5);  // -6
console.log(~-1); // 0

```

---

## 2. Shift Operators (`<<`, `>>`, `>>>`)

### Zero-fill Left Shift (`<<`)

Shifts bits to the left by $n$ positions, discarding overflow bits on the left and filling with `0`s on the right.

> **Math rule:** `x << n` is equivalent to $x \times 2^n$.

```javascript
// 5 in binary: 00000000000000000000000000000101
// 5 << 1 becomes: 00000000000000000000000000001010 (10)
console.log(5 << 1); // 10
console.log(5 << 2); // 20 (5 * 2^2)

```

### Signed Right Shift (`>>`)

Shifts bits to the right by $n$ positions. Discards bits on the right and **copies the sign bit** (0 for positive, 1 for negative) into the left positions.

> **Math rule:** `x >> n` is equivalent to $\lfloor x / 2^n \rfloor$.

```javascript
console.log(20 >> 1);  // 10
console.log(-10 >> 1); // -5

```

### Zero-fill Right Shift (`>>>`)

Shifts bits to the right by $n$ positions, pushing `0`s in from the left **regardless of whether the number is positive or negative**. For negative numbers, this turns them into very large positive 32-bit unsigned integers.

```javascript
console.log(20 >>> 1);  // 10
console.log(-10 >>> 1); // 2147483643 (converts negative sign bit to positive 0)

```

## 3. Practical Real-World Scenarios

While uncommon in daily web app UI code, bitwise operators are essential for high-performance computing, graphics, and flags.

### Scenario A: Odd / Even Check (Fast Modulo)

Instead of `num % 2 === 0`, checking the lowest bit (`num & 1`) is slightly faster:

```javascript
const isEven = (num) => (num & 1) === 0;

console.log(isEven(4)); // true
console.log(isEven(7)); // false

```

### Scenario B: Fast Floor / Truncating Decimals

Using double NOT (`~~`) or bitwise OR with 0 (`| 0`) strips decimals faster than `Math.floor()` for positive numbers:

```javascript
console.log(~~4.9);    // 4
console.log(12.8 | 0);  // 12

```

### Scenario C: Permission Bitmasks (Flags)

Combining multiple permissions into a single integer saves memory and enables ultra-fast capability checks:

```javascript
// Define permissions as bit flags
const READ    = 1 << 0; // 1 (0001)
const WRITE   = 1 << 1; // 2 (0010)
const EXECUTE = 1 << 2; // 4 (0100)

// Assign READ and EXECUTE permissions to a user using OR (|)
let userPermissions = READ | EXECUTE; // 5 (0101)

// Check if user has WRITE permission using AND (&)
const canWrite = (userPermissions & WRITE) !== 0; // false
console.log("Can write?", canWrite);

// Check if user has READ permission
const canRead = (userPermissions & READ) !== 0;   // true
console.log("Can read?", canRead);

```

### Scenario D: Swapping Two Variables Without a Temp Variable

```javascript
let a = 5;
let b = 10;

a = a ^ b;
b = a ^ b;
a = a ^ b;

console.log(a, b); // 10, 5

```
