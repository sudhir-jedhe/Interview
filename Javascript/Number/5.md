All numbers in JavaScript are stored as 64-bit double-precision floating-point numbers (IEEE 754). Here is the complete reference for instance methods, static methods, and properties of the `Number` object.

---

## 1. Basic Instance Methods

Instance methods are called directly on a number variable or literal (e.g., `num.toFixed()`).

| Method                      | Description                                                                | Return Type | Code Example                             |
| --------------------------- | -------------------------------------------------------------------------- | ----------- | ---------------------------------------- |
| **`toString([radix])`**     | Converts a number to a string. Optional `radix` specifies base (2 to 36).  | `string`    | `(255).toString(16); // "ff"`            |
| **`toFixed(digits)`**       | Formats a number using fixed-point notation with specified decimal places. | `string`    | `(9.656).toFixed(2); // "9.66"`          |
| **`toPrecision(digits)`**   | Formats a number to a specified total length (total significant digits).   | `string`    | `(9.656).toPrecision(2); // "9.7"`       |
| **`toExponential(digits)`** | Converts a number into exponential (scientific) notation.                  | `string`    | `(9.656).toExponential(2); // "9.66e+0"` |
| **`valueOf()`**             | Returns the primitive value of a `Number` object.                          | `number`    | `(123).valueOf(); // 123`                |

```javascript
const num = 123.4567;

console.log(num.toString());       // "123.4567"
console.log(num.toFixed(2));        // "123.46" (rounds up)
console.log(num.toPrecision(4));    // "123.5"
console.log(num.toExponential(1)); // "1.2e+2"

```

---

## 2. Static Methods

Static methods must be called on the global `Number` object itself (e.g., `Number.isInteger()`), rather than on instance variables.

| Method                            | Description                                                                   | Return Type | Code Example                               |
| --------------------------------- | ----------------------------------------------------------------------------- | ----------- | ------------------------------------------ |
| **`Number.isFinite(val)`**        | Checks if a value is a finite number (returns `false` for `NaN`, `Infinity`). | `boolean`   | `Number.isFinite(100); // true`            |
| **`Number.isInteger(val)`**       | Checks if a value is an integer without decimal parts.                        | `boolean`   | `Number.isInteger(4.2); // false`          |
| **`Number.isNaN(val)`**           | Checks if a value is strictly `NaN` without type coercion.                    | `boolean`   | `Number.isNaN(NaN); // true`               |
| **`Number.isSafeInteger(val)`**   | Checks if a number falls within safe double-precision integer bounds.         | `boolean`   | `Number.isSafeInteger(2**53 - 1); // true` |
| **`Number.parseInt(str, radix)`** | Parses a string argument and returns an integer of the specified radix.       | `number`    | `Number.parseInt("100px", 10); // 100`     |
| **`Number.parseFloat(str)`**      | Parses a string argument and returns a floating-point number.                 | `number`    | `Number.parseFloat("3.14 text"); // 3.14`  |

```javascript
// Difference between global isNaN and Number.isNaN:
console.log(isNaN("hello"));        // true (coerces string to NaN)
console.log(Number.isNaN("hello")); // false (no coercion; string is not NaN)

// Parsing strings
console.log(Number.parseInt("10.99"));   // 10
console.log(Number.parseFloat("10.99")); // 10.99

```

## 3. Static Number Properties

Properties stored directly on `Number` representing boundary limits and special mathematical constants.

| Property                       | Value                                 | Description                                                      |
| ------------------------------ | ------------------------------------- | ---------------------------------------------------------------- |
| **`Number.EPSILON`**           | $\approx 2.22 \times 10^{-16}$        | Smallest difference between 1 and the next representable number. |
| **`Number.MAX_VALUE`**         | $\approx 1.79 \times 10^{308}$        | Largest positive representable number in JavaScript.             |
| **`Number.MIN_VALUE`**         | $\approx 5.00 \times 10^{-324}$       | Smallest positive representable number closest to zero.          |
| **`Number.MAX_SAFE_INTEGER`**  | $2^{53} - 1$ (`9007199254740991`)     | Maximum integer that can be safely compared and represented.     |
| **`Number.MIN_SAFE_INTEGER`**  | $-(2^{53} - 1)$ (`-9007199254740991`) | Minimum integer that can be safely compared and represented.     |
| **`Number.POSITIVE_INFINITY`** | `Infinity`                            | Value representing infinity on overflow.                         |
| **`Number.NEGATIVE_INFINITY`** | `-Infinity`                           | Value representing negative infinity on overflow.                |
| **`Number.NaN`**               | `NaN`                                 | Special "Not-a-Number" value indicating invalid calculation.     |

```javascript
// Using EPSILON for float comparison safety
const isEqual = Math.abs((0.1 + 0.2) - 0.3) < Number.EPSILON;
console.log(isEqual); // true

// Unsafe integer overflow example
console.log(Number.MAX_SAFE_INTEGER + 1); // 9007199254740992
console.log(Number.MAX_SAFE_INTEGER + 2); // 9007199254740992 (Precision loss!)

```
