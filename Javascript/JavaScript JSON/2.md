**JSON (JavaScript Object Notation)** is a lightweight, text-based data interchange format. While based on JavaScript object syntax, JSON is plain text and language-independent, making it the standard format for exchanging data between web browsers, servers, and APIs.

---

## 1. Syntax Rules: JSON vs JavaScript Objects

Although they look similar, JSON enforces strict formatting rules that differ from standard JavaScript objects:

| Feature                  | JSON Standard                                       | JavaScript Object Literal                             |
| ------------------------ | --------------------------------------------------- | ----------------------------------------------------- |
| **Keys**                 | Must be wrapped in **double quotes** (`"key"`)      | Quotes optional (`key` or `'key'`)                    |
| **String Values**        | Must use **double quotes** (`"value"`)              | Single or double quotes (`'value'` or `"value"`)      |
| **Trailing Commas**      | ❌ **Forbidden** (`{"a": 1,}`)                       | ✅ Allowed                                             |
| **Supported Data Types** | Strings, Numbers, Booleans, `null`, Arrays, Objects | All types + `undefined`, Functions, Symbols, `BigInt` |
| **Functions/Methods**    | ❌ **Forbidden**                                     | ✅ Allowed                                             |

```json
/* Valid JSON Example */
{
  "name": "Alice",
  "age": 30,
  "isEmployed": true,
  "skills": ["JavaScript", "JSON"],
  "address": {
    "city": "New York",
    "zip": "10001"
  },
  "spouse": null
}

```

## 2. Core Methods: `JSON.parse()` & `JSON.stringify()`

JavaScript provides a global **`JSON`** object with two primary methods for converting between strings and in-memory data structures.

### A. `JSON.parse(text [, reviver])`

Converts a valid JSON-formatted string into a native JavaScript object, array, or primitive value.

```javascript
const jsonString = '{"name": "Alice", "age": 30}';

// Parse string to JS Object
const user = JSON.parse(jsonString);

console.log(user.name); // "Alice"
console.log(user.age);  // 30

```

#### Using the `reviver` Function

The optional `reviver` function lets you transform properties during parsing (e.g., converting ISO date strings back into native `Date` objects):

```javascript
const jsonWithDate = '{"title": "Event", "date": "2026-08-07T12:00:00.000Z"}';

const eventObj = JSON.parse(jsonWithDate, (key, value) => {
  if (key === "date") {
    return new Date(value); // Transform date string to Date object
  }
  return value;
});

console.log(eventObj.date.getFullYear()); // 2026

```

---

### B. `JSON.stringify(value [, replacer [, space]])`

Converts a JavaScript object or value into a JSON-formatted string.

```javascript
const user = {
  name: "Bob",
  role: "Admin",
  active: true
};

const jsonString = JSON.stringify(user);
console.log(jsonString); 
// Output: '{"name":"Bob","role":"Admin","active":true}'

```

#### Formatting Output with `space` (Pretty Printing)

Pass a number or string as the third parameter to format output with indentation for readable logging:

```javascript
// Indent with 2 spaces
console.log(JSON.stringify(user, null, 2));
/* Output:
{
  "name": "Bob",
  "role": "Admin",
  "active": true
}
*/

```

#### Filtering with the `replacer` Parameter

Pass an array of property names or a filtering function as the second parameter:

```javascript
const user = { name: "Alice", age: 30, secretKey: "12345" };

// Only include "name" and "age" in output
const filteredJson = JSON.stringify(user, ["name", "age"]);
console.log(filteredJson); // '{"name":"Alice","age":30}'

```

## 3. Important Edge Cases & Behaviors

1. **`undefined`, Functions, and Symbols:** When passed through `JSON.stringify()`, properties with these values are **omitted** from objects, or converted to `null` inside arrays.

```javascript
const obj = {
  fn: () => {},
  val: undefined,
  name: "Test"
};
console.log(JSON.stringify(obj)); // '{"name":"Test"}'

```

1. **Circular References:** Passing an object that references itself into `JSON.stringify()` throws a `TypeError: Converting circular structure to JSON`.

```javascript
const a = {};
a.self = a;
// JSON.stringify(a); // ❌ Throws TypeError

```

1. **Parsing Errors:** If `JSON.parse()` receives invalid JSON, it throws a `SyntaxError`. Always wrap parsing calls in `try...catch` blocks when handling user or API input:

```javascript
try {
  const data = JSON.parse("invalid json string");
} catch (error) {
  console.error("Invalid JSON format:", error.message);
}

```

## 4. Deep Cloning with `structuredClone()` vs `JSON`

Developers historically used `JSON.parse(JSON.stringify(obj))` to create deep copies of objects. Modern JavaScript natively provides **`structuredClone()`**, which is significantly faster and handles types like `Date`, `RegExp`, `Map`, `Set`, and `ArrayBuffer` that `JSON.stringify()` cannot serialize cleanly.

```javascript
const original = {
  name: "Data",
  date: new Date(),
  items: [1, 2, 3]
};

// Modern Deep Clone (Recommended)
const clone = structuredClone(original);

console.log(clone.date instanceof Date); // true

```

Explain how to handle circular references in JSON.stringify with custom replacer function code examples

A **circular reference** occurs when an object references itself directly or indirectly through a chain of references (e.g., Object A references Object B, and Object B references Object A).

When you pass a circular structure to `JSON.stringify()`, JavaScript throws an error:
`TypeError: Converting circular structure to JSON`

To safely stringify circular objects, you can use a custom **replacer function** paired with a `WeakSet` (or `Set`) to keep track of every object that has already been visited during serialization.

---

## 1. Handling Circular References with a Replacer Function

The `replacer` argument in `JSON.stringify(value, replacer)` is a callback function that evaluates every `(key, value)` pair before it is converted into a string.

By checking whether `value` is an object that was previously recorded in a tracking set, you can replace recurring references with a placeholder string (like `"[Circular]"`) or omit them by returning `undefined`.

### Implementation Code

```javascript
function getCircularReplacer() {
  // Use a WeakSet to track objects encountered during stringification
  const seen = new WeakSet();

  return (key, value) => {
    // Check if value is a non-null object/array
    if (typeof value === "object" && value !== null) {
      if (seen.has(value)) {
        // Return placeholder string or return undefined to omit the key entirely
        return "[Circular]";
      }
      // Add unvisited object to the set
      seen.add(value);
    }
    return value;
  };
}

// ==========================================
// EXAMPLE USAGE
// ==========================================

// Create a circular structure
const user = {
  name: "Alice",
  role: "Admin"
};

const company = {
  title: "TechCorp",
  owner: user
};

// Create the circular link
user.company = company; // user -> company -> user

// 1. Standard stringify fails:
try {
  JSON.stringify(user);
} catch (error) {
  console.error("Standard call failed:", error.message);
  // Output: "TypeError: Converting circular structure to JSON"
}

// 2. Safe stringify using our custom replacer:
const safeJson = JSON.stringify(user, getCircularReplacer(), 2);
console.log(safeJson);

```

### Output Result

```json
{
  "name": "Alice",
  "role": "Admin",
  "company": {
    "title": "TechCorp",
    "owner": "[Circular]"
  }
}

```

## 2. Reusable Utility Function (`safeStringify`)

Here is a ready-to-use helper function that wraps `JSON.stringify` with safe circular reference handling, formatting support (`space`), and custom fallback values.

```javascript
/**
 * Safely converts a JavaScript value to a JSON string, handling circular references.
 * 
 * @param {any} value - The value to stringify.
 * @param {string|number} [space=null] - Indentation/spacing for formatting.
 * @param {string} [circularFallback="[Circular]"] - Value to replace circular references.
 * @returns {string} The JSON string output.
 */
function safeStringify(value, space = null, circularFallback = "[Circular]") {
  const seen = new WeakSet();

  return JSON.stringify(
    value,
    (key, val) => {
      if (typeof val === "object" && val !== null) {
        if (seen.has(val)) {
          return circularFallback;
        }
        seen.add(val);
      }
      return val;
    },
    space
  );
}

// Test with nested array circular references
const itemA = { id: 1 };
const itemB = { id: 2 };
itemA.sibling = itemB;
itemB.sibling = itemA;

console.log(safeStringify({ items: [itemA, itemB] }, 2));

```

## 3. Alternative: Native `structuredClone()` Limitation

While native `structuredClone()` handles circular structures without throwing errors when cloning objects in memory, **it cannot serialize them into text strings**.

If your goal is sending data over an HTTP API, logging to disk, or saving to `localStorage`, custom replacer logic or utility libraries (like `flatted` or `json-stringify-safe`) remain mandatory.

Explain how to parse and stringify circular JSON data using the Flatted library with code examples

The native `JSON.parse()` and `JSON.stringify()` methods are designed for tree-structured data and cannot handle circular references.

While custom `replacer` functions can prevent errors by replacing circular references with static placeholder strings like `"[Circular]"`, they **destroy the relationship data**, making it impossible to reconstruct the original object structure later using `JSON.parse()`.

The **[Flatted](https://github.com/WebReflection/flatted)** library solves this by using a super-lightweight, circular-safe JSON format. It replaces duplicate and circular object references with index pointers, allowing full two-way serialization (`stringify` and `parse`) without data loss.

---

## 1. How Flatted Works Under the Hood

Instead of writing objects inline, `flatted.stringify()` flattens the object structure into a single array where the first item is the root object, and subsequent items are indexed references.

```javascript
// Native JSON cannot handle this:
const parent = {};
const child = { parent };
parent.child = child;

// Flatted turns it into a flat, indexed array structure:
// flatted.stringify(parent) -> '[{"child":"1"},{"parent":"0"}]'

```

When `flatted.parse()` reads this string, it resolves the numeric index pointers back into exact object references in memory.

## 3. Code Example: Full Two-Way Circular Serialization

Here is a complete example creating a circular object graph, stringifying it, parsing it back, and verifying that reference equality is preserved.

```javascript
import { parse, stringify } from 'flatted';

// 1. Create a circular data graph
const user = { name: "Alice", role: "Developer" };
const department = { name: "Engineering", lead: user };

// Create circular references
user.department = department; // user -> department -> user
user.self = user;             // self-reference

// 2. Stringify the circular structure safely
const flattedString = stringify(user);

console.log("Flatted JSON Output:");
console.log(flattedString);
// Output: '[{"name":"0","role":"1","department":"2","self":"0"},"Alice","Developer",{"name":"3","lead":"0"},"Engineering"]'

// 3. Parse the string back into a JavaScript object
const restoredUser = parse(flattedString);

// 4. Verify object references and values
console.log("\nRestored Object Values:");
console.log("User Name:", restoredUser.name);                     // "Alice"
console.log("Department Name:", restoredUser.department.name);    // "Engineering"

console.log("\nPreserved Reference Checks:");
console.log(restoredUser.department.lead === restoredUser);      // true (Circular link intact!)
console.log(restoredUser.self === restoredUser);                 // true

```

## 4. Using Custom Replacers and Formatting with Flatted

`flatted.stringify()` and `flatted.parse()` share the same signature as native `JSON.stringify()` and `JSON.parse()`. You can pass `replacer`, `reviver`, and `space` parameters for pretty-printing or data transformation.

```javascript
import { parse, stringify } from 'flatted';

const a = {};
a.self = a;
a.timestamp = new Date();

// Stringify with 2-space indentation (pretty print)
const prettyFlatted = stringify(a, null, 2);
console.log(prettyFlatted);

// Parse with a custom reviver function
const restored = parse(prettyFlatted, (key, value) => {
  if (key === 'timestamp') return new Date(value);
  return value;
});

console.log(restored.timestamp instanceof Date); // true

```

Explain how to store and retrieve circular JavaScript objects in browser LocalStorage using Flatted with code examples

Browser `localStorage` can only store text strings. Because standard `JSON.stringify()` throws a `TypeError: Converting circular structure to JSON` when given a self-referencing object, storing circular data in `localStorage` requires converting the object graph into a flat, stringified array using **Flatted** before saving it.

---

## 1. Helper Storage Wrapper

To make working with circular objects in `localStorage` clean and reusable, wrap `localStorage.setItem` and `localStorage.getItem` with Flatted's `stringify` and `parse` methods.

```javascript
import { parse, stringify } from 'flatted';

export const circularStorage = {
  /**
   * Stores a circular object in LocalStorage
   * @param {string} key 
   * @param {any} value 
   */
  setItem(key, value) {
    try {
      const serializableString = stringify(value);
      localStorage.setItem(key, serializableString);
    } catch (error) {
      console.error(`Error saving key "${key}" to localStorage:`, error);
    }
  },

  /**
   * Retrieves and reconstructs a circular object from LocalStorage
   * @param {string} key 
   * @returns {any | null}
   */
  getItem(key) {
    try {
      const storedString = localStorage.getItem(key);
      if (!storedString) return null;
      return parse(storedString);
    } catch (error) {
      console.error(`Error reading/parsing key "${key}" from localStorage:`, error);
      return null;
    }
  },

  /**
   * Removes an item from LocalStorage
   * @param {string} key 
   */
  removeItem(key) {
    localStorage.removeItem(key);
  }
};

```

## 2. Complete Code Example

Here is how to create a circular data structure (e.g., node trees, parent-child relationships, or graph state), save it to `localStorage`, and retrieve it later while maintaining all internal memory references intact.

```javascript
import { circularStorage } from './circularStorage.js';

// 1. Create a circular object structure (e.g., UI Node Tree)
const parentNode = {
  id: "node-1",
  title: "Root Folder",
  children: []
};

const childNode = {
  id: "node-2",
  title: "Document.pdf",
  parent: parentNode // Circular link: child -> parent -> child
};

parentNode.children.push(childNode);

// Add a direct self-reference
parentNode.self = parentNode;

// 2. Save circular object to localStorage
circularStorage.setItem("file_system_state", parentNode);
console.log("Saved circular state to LocalStorage successfully.");

// ==========================================
// RETRIEVAL & VERIFICATION
// ==========================================

// 3. Retrieve and reconstruct object graph from localStorage
const restoredNode = circularStorage.getItem("file_system_state");

if (restoredNode) {
  console.log("Restored Node Title:", restoredNode.title);
  console.log("Restored Child Title:", restoredNode.children[0].title);

  // 4. Verify that circular references are preserved
  console.log("\n--- Reference Verification ---");
  console.log("Child's parent points to root:", restoredNode.children[0].parent === restoredNode); // true
  console.log("Root's self points to root:", restoredNode.self === restoredNode);                   // true
}

```

## Key Best Practices

1. **Storage Limits:** Browser `localStorage` has a strict quota (typically **5 MB** per origin). Large object graphs can exceed this limit.
2. **Error Handling:** Always wrap `localStorage` access in `try...catch` blocks to gracefully handle `QuotaExceededError` or private browsing restrictions.
3. **Complex Objects (Dates/Regex):** If your circular object contains custom types like `Date` objects, pass a custom reviver function to `parse()` inside your wrapper to reconstitute those types.

Explain how to deep clone circular objects in JavaScript using structuredClone vs MessageChannel with code examples

Deep cloning an object containing **circular references** requires an algorithm that tracks object identity across the cloned graph. In modern JavaScript, two built-in browser APIs handle circular deep copies natively in memory without requiring third-party libraries: **`structuredClone()`** and **`MessageChannel`**.

---

## 1. Native Approach: `structuredClone()` (Modern Standard)

`structuredClone()` is a globally available function built into browsers and Node.js (v17+). It uses the HTML Structured Clone Algorithm under the hood to handle circular references automatically.

### Code Example

```javascript
// 1. Create a circular object structure
const parent = { name: "Parent Node", role: "Admin" };
const child = { name: "Child Node", parent: parent };

// Establish circular link: parent -> child -> parent
parent.child = child;

// 2. Perform deep clone using structuredClone
const clonedParent = structuredClone(parent);

// 3. Verify deep copy & reference independence
console.log(clonedParent.name); // "Parent Node"
console.log(clonedParent.child.name); // "Child Node"

// Reference Integrity: Circular relationship is preserved inside the clone
console.log(clonedParent.child.parent === clonedParent); // true

// Memory Isolation: The clone is completely decoupled from the original object
console.log(clonedParent === parent); // false
clonedParent.name = "Modified Parent";
console.log(parent.name); // "Parent Node" (Unchanged)

```

---

## 2. Channel Messaging Approach: `MessageChannel`

Before `structuredClone()` was universally supported, developers leveraged the browser's **Channel Messaging API** (`MessageChannel`). Passing data through a `MessageChannel` port invokes the browser's native structured clone algorithm asynchronously during message serialization.

### Code Example

```javascript
/**
 * Asynchronously deep clones a circular object using MessageChannel
 * @param {any} obj 
 * @returns {Promise<any>}
 */
function deepCloneMessageChannel(obj) {
  return new Promise((resolve) => {
    const { port1, port2 } = new MessageChannel();

    // Listen for the cloned data on port1
    port1.onmessage = (event) => resolve(event.data);

    // Send the original object through port2
    port2.postMessage(obj);
  });
}

// --- Usage Example ---
async function runExample() {
  // Create a circular structure
  const nodeA = { id: "A" };
  const nodeB = { id: "B", sibling: nodeA };
  nodeA.sibling = nodeB; // Circular link: nodeA -> nodeB -> nodeA

  // Deep clone using MessageChannel
  const clonedA = await deepCloneMessageChannel(nodeA);

  // Verify preservation of circular references
  console.log(clonedA.sibling.sibling === clonedA); // true
  console.log(clonedA === nodeA); // false (Different memory reference)
}

runExample();

```

## 3. Supported Data Types Comparison

Both methods rely on the **Structured Clone Algorithm**, meaning they support a wider array of JavaScript built-in data types than `JSON.parse(JSON.stringify())`.

| Data Type                       | `structuredClone()` | `MessageChannel` | `JSON.parse(JSON.stringify())` |
| ------------------------------- | ------------------- | ---------------- | ------------------------------ |
| **Circular References**         | ✅ Supported         | ✅ Supported      | ❌ Throws `TypeError`           |
| **`Date` Objects**              | ✅ Preserved         | ✅ Preserved      | ❌ Converts to ISO String       |
| **`RegExp` Objects**            | ✅ Preserved         | ✅ Preserved      | ❌ Converts to `{}`             |
| **`Map` & `Set**`               | ✅ Preserved         | ✅ Preserved      | ❌ Converts to `{}` / `[]`      |
| **`ArrayBuffer` / TypedArrays** | ✅ Preserved         | ✅ Preserved      | ❌ Converts to `{}`             |
| **Functions / DOM Nodes**       | ❌ Throws Error      | ❌ Throws Error   | ❌ Stripped or `null`           |
| **Execution Sync/Async**        | **Synchronous**     | **Asynchronous** | Synchronous                    |

---

## Summary & Recommendation

* **Use `structuredClone()` by default:** It is synchronous, cleaner, supported across all modern browsers and Node.js, and requires no promise wrappers or event handling.
* **Use `MessageChannel` for legacy web worker patterns:** `MessageChannel` is useful if you are already passing messages asynchronously between web workers or need a fallback pattern in older browser worker threads.
