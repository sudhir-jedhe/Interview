The JavaScript **Fetch API** provides a modern, Promise-based interface for making asynchronous HTTP requests across web browsers and server runtimes (like Node.js). It replaced the older `XMLHttpRequest` API with a cleaner, more flexible syntax.

---

## 1. Basic Request (`GET`)

A standard `fetch()` request returns a **Promise** that resolves into a `Response` object representing the HTTP headers and status. To extract the actual data body, call a body-parsing method (e.g., `.json()`, `.text()`, `.blob()`).

### Using `async / await` (Recommended)

```javascript
async function getUserData() {
  try {
    const response = await fetch("https://api.example.com/users/1");

    // Important: fetch ONLY rejects on network failure, NOT on 404/500 errors!
    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`);
    }

    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Fetch failed:", error.message);
  }
}

getUserData();

```

---

## 2. Sending Data (`POST`, `PUT`, `DELETE`)

To send data or customize headers, pass an options object as the second argument to `fetch()`.

```javascript
async function createPost() {
  const payload = {
    title: "Understanding Fetch API",
    body: "Fetch is promise-based and native to JavaScript.",
    userId: 101
  };

  try {
    const response = await fetch("https://api.example.com/posts", {
      method: "POST", // HTTP Method
      headers: {
        "Content-Type": "application/json", // Inform server of payload type
        "Authorization": "Bearer YOUR_ACCESS_TOKEN"
      },
      body: JSON.stringify(payload) // Convert JS Object to JSON String
    });

    if (!response.ok) {
      throw new Error(`Failed to create post. Status: ${response.status}`);
    }

    const newPost = await response.json();
    console.log("Post created successfully:", newPost);
  } catch (error) {
    console.error("Error creating post:", error);
  }
}

```

---

## 3. Response Processing Methods

The `Response` body can only be consumed **once**. Choose the method matching your expected data format:

| Response Method              | Description                                              | Common Use Case           |
| ---------------------------- | -------------------------------------------------------- | ------------------------- |
| **`response.json()`**        | Parses response body stream as JSON.                     | REST APIs, JSON data      |
| **`response.text()`**        | Returns response body as plain string text.              | HTML, XML, Markdown       |
| **`response.blob()`**        | Returns response body as a `Blob` (binary large object). | Images, PDFs, media files |
| **`response.formData()`**    | Parses body stream into a `FormData` object.             | Multi-part form data      |
| **`response.arrayBuffer()`** | Returns body as a raw binary `ArrayBuffer`.              | Audio/video processing    |

## 4. Advanced Features

### A. Cancelling Requests with `AbortController`

You can cancel an in-flight fetch request (useful for auto-complete searches or page navigation cleanup) using an `AbortSignal`.

```javascript
const controller = new AbortController();
const signal = controller.signal;

// Initiate request with signal
fetch("https://api.example.com/large-data", { signal })
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => {
    if (err.name === "AbortError") {
      console.log("Fetch request was cancelled successfully.");
    } else {
      console.error("Fetch failed:", err);
    }
  });

// Cancel the request dynamically (e.g. after 2 seconds timeout)
setTimeout(() => controller.abort(), 2000);

```

### B. Requesting with Timeout Helper

You can combine `AbortSignal.timeout()` to set automatic timeouts without manual timer code:

```javascript
try {
  // Automatically aborts if request takes longer than 5 seconds
  const response = await fetch("https://api.example.com/data", {
    signal: AbortSignal.timeout(5000)
  });
  const data = await response.json();
} catch (error) {
  if (error.name === "TimeoutError") {
    console.error("Request timed out!");
  }
}

```

## 5. Critical `fetch()` Gotcha: Error Handling

Unlike HTTP libraries like Axios, **`fetch()` does NOT reject its Promise on HTTP error status codes (like 404, 401, or 500)**.

A `fetch()` promise only rejects when a network connection fails entirely or the request is blocked.

```javascript
// WRONG ASSUMPTION
fetch("/api/missing-page")
  .then(res => res.json()) // Still runs even on 404 Not Found!
  .catch(err => console.log("This will NOT trigger on 404!"));

// CORRECT PATTERN
fetch("/api/missing-page")
  .then(res => {
    if (!res.ok) { // Check if HTTP status is NOT 200-299
      throw new Error(`Server returned HTTP ${res.status}`);
    }
    return res.json();
  })
  .catch(err => console.log("Caught HTTP or network error:", err.message));

```

Explain how to upload and download files using JavaScript Fetch API with examples

Handling files using the **Fetch API** relies on working with binary data types: **`FormData`** (for multi-part file uploads) and **`Blob`** objects (for file downloads and local save triggers).

---

## 1. Uploading Files with `fetch()`

When uploading files, pass a `FormData` object containing the file reference into the `body` option.

### A. Uploading Single or Multiple Files

```html
<input type="file" id="fileInput" multiple />
<button id="uploadBtn">Upload Files</button>

<script>
  document.getElementById("uploadBtn").addEventListener("click", async () => {
    const fileInput = document.getElementById("fileInput");
    const files = fileInput.files;

    if (files.length === 0) {
      alert("Please select at least one file.");
      return;
    }

    // 1. Create a FormData container
    const formData = new FormData();

    // 2. Append file(s) to FormData
    // For single file: formData.append("file", files[0]);
    for (let i = 0; i < files.length; i++) {
      formData.append("files", files[i]); // 'files' matching backend parameter name
    }

    // 3. Append metadata if needed
    formData.append("uploadedBy", "User123");

    try {
      // 4. Send POST request
      const response = await fetch("/api/upload", {
        method: "POST",
        // CRITICAL: Do NOT set "Content-Type" header manually.
        // Browser automatically inserts multipart/form-data boundary!
        body: formData
      });

      if (!response.ok) {
        throw new Error(`Upload failed with status: ${response.status}`);
      }

      const result = await response.json();
      console.log("Upload successful:", result);
    } catch (error) {
      console.error("Upload error:", error.message);
    }
  });
</script>

```

---

## 2. Downloading Files with `fetch()`

To download a file (PDF, image, CSV, zip, etc.), process the response using **`response.blob()`**, create a temporary object URL, and trigger a programmatic browser download link.

### A. Simple File Download Trigger

```javascript
async function downloadFile(fileUrl, fileName) {
  try {
    const response = await fetch(fileUrl, {
      method: "GET",
      headers: {
        "Authorization": "Bearer YOUR_TOKEN" // Useful for protected server files
      }
    });

    if (!response.ok) {
      throw new Error(`Download failed: HTTP ${response.status}`);
    }

    // 1. Convert response stream into a Blob
    const blob = await response.blob();

    // 2. Create a temporary local URL pointing to the Blob
    const downloadUrl = window.URL.createObjectURL(blob);

    // 3. Construct a hidden <a> element to trigger browser download
    const link = document.createElement("a");
    link.href = downloadUrl;
    link.download = fileName; // Suggested filename for saved file

    document.body.appendChild(link);
    link.click(); // Programmatically click the anchor

    // 4. Cleanup temporary DOM node and object URL memory
    link.remove();
    window.URL.revokeObjectURL(downloadUrl);

    console.log("File downloaded successfully.");
  } catch (error) {
    console.error("Download error:", error);
  }
}

// Example usage:
// downloadFile('/api/reports/annual.pdf', 'Annual-Report-2026.pdf');

```

## 3. Advanced: Download Progress Tracking with Streams

Since `response.blob()` resolves only when the entire file finishes loading, use `response.body.getReader()` (**ReadableStream API**) to read incoming chunks and measure progress.

```javascript
async function downloadWithProgress(fileUrl) {
  const response = await fetch(fileUrl);
  
  if (!response.ok) throw new Error("Network response error");

  // Get total file length from response header
  const contentLength = response.headers.get("Content-Length");
  if (!contentLength) {
    console.warn("Server did not send Content-Length header; cannot compute progress.");
  }
  const totalBytes = parseInt(contentLength, 10);

  let receivedBytes = 0;
  const chunks = []; // Store raw Uint8Array chunks
  const reader = response.body.getReader();

  while (true) {
    const { done, value } = await reader.read();

    if (done) break; // Stream finished

    chunks.push(value);
    receivedBytes += value.length;

    if (totalBytes) {
      const percent = Math.round((receivedBytes / totalBytes) * 100);
      console.log(`Download progress: ${percent}% (${receivedBytes} / ${totalBytes} bytes)`);
    }
  }

  // Combine chunks into a single Blob once stream completes
  const blob = new Blob(chunks);
  const url = window.URL.createObjectURL(blob);
  
  const a = document.createElement("a");
  a.href = url;
  a.download = "downloaded-file.zip";
  a.click();
  window.URL.revokeObjectURL(url);
}

```

---

## Key Takeaways

1. **Uploads:** Use `FormData`. **Do not** manually set `headers: { 'Content-Type': 'multipart/form-data' }` because the browser needs to set the multi-part boundary string automatically.
2. **Downloads:** Read binary payloads using `response.blob()` or `response.arrayBuffer()`.
3. **Triggering Save:** Use `URL.createObjectURL(blob)` paired with an `<a download="...">` element to trigger native save dialogs. Clean up memory afterwards with `URL.revokeObjectURL()`.

Compare JavaScript Fetch API vs Axios for file uploads and downloads with code examples

Here is a comprehensive comparison of using the native **Fetch API** versus the **Axios** library for handling file uploads and downloads.

---

## Quick Comparison Summary

| Feature                        | Fetch API                                    | Axios                                       |
| ------------------------------ | -------------------------------------------- | ------------------------------------------- |
| **Setup**                      | Native (Built-in, zero setup)                | Requires installation (`npm install axios`) |
| **Upload Progress Tracking**   | Complex (Requires Streams API / XHR wrapper) | **Native & Simple** (`onUploadProgress`)    |
| **Download Progress Tracking** | Native via `ReadableStream`                  | **Native & Simple** (`onDownloadProgress`)  |
| **HTTP Error Handling**        | Manual check needed (`!response.ok`)         | **Automatic rejection** on 4xx / 5xx        |
| **Automatic JSON Parsing**     | Manual (`await response.json()`)             | **Automatic** (`response.data`)             |
| **Form Data Serialization**    | Pass `new FormData()`                        | Automatically converts objects if specified |

---

## 1. File Upload Comparison

### Fetch API Upload

When using `fetch()`, pass a `FormData` instance as the request body. You must avoid setting the `Content-Type` header manually so the browser can calculate the boundary automatically.

```javascript
async function uploadWithFetch(file) {
  const formData = new FormData();
  formData.append("file", file);

  try {
    const response = await fetch("/api/upload", {
      method: "POST",
      body: formData
      // DO NOT set 'Content-Type': 'multipart/form-data'
    });

    if (!response.ok) {
      throw new Error(`Upload failed: ${response.statusText}`);
    }

    const data = await response.json();
    console.log("Fetch upload successful:", data);
  } catch (error) {
    console.error("Fetch upload error:", error.message);
  }
}

```

### Axios Upload (With Real-Time Progress)

Axios simplifies file uploads by providing an **`onUploadProgress`** event handler directly in the configuration object.

```javascript
import axios from "axios";

async function uploadWithAxios(file) {
  const formData = new FormData();
  formData.append("file", file);

  try {
    const response = await axios.post("/api/upload", formData, {
      // Real-time upload progress callback
      onUploadProgress: (progressEvent) => {
        const percentCompleted = Math.round(
          (progressEvent.loaded * 100) / progressEvent.total
        );
        console.log(`Axios Upload Progress: ${percentCompleted}%`);
      }
    });

    // Data is automatically parsed
    console.log("Axios upload successful:", response.data);
  } catch (error) {
    console.error("Axios upload error:", error.response?.data || error.message);
  }
}

```

## 2. File Download Comparison

### Fetch API Download

With `fetch()`, you consume the binary response stream using `response.blob()`, then create a temporary object URL to trigger the browser's save action.

```javascript
async function downloadWithFetch(fileUrl, fileName) {
  try {
    const response = await fetch(fileUrl);

    if (!response.ok) {
      throw new Error(`Download failed: HTTP ${response.status}`);
    }

    // Convert response stream to Blob
    const blob = await response.blob();
    
    // Create temporary object URL
    const url = window.URL.createObjectURL(blob);
    const link = document.createElement("a");
    link.href = url;
    link.download = fileName;
    
    document.body.appendChild(link);
    link.click();
    
    // Cleanup memory
    link.remove();
    window.URL.revokeObjectURL(url);
  } catch (error) {
    console.error("Fetch download error:", error);
  }
}

```

### Axios Download (With Progress Tracking)

For binary downloads in Axios, specify `responseType: "blob"`. Axios also includes an **`onDownloadProgress`** hook out of the box.

```javascript
import axios from "axios";

async function downloadWithAxios(fileUrl, fileName) {
  try {
    const response = await axios.get(fileUrl, {
      responseType: "blob", // Request binary data as a Blob
      
      // Real-time download progress callback
      onDownloadProgress: (progressEvent) => {
        if (progressEvent.total) {
          const percentCompleted = Math.round(
            (progressEvent.loaded * 100) / progressEvent.total
          );
          console.log(`Axios Download Progress: ${percentCompleted}%`);
        }
      }
    });

    // Create object URL from response.data (which is already a Blob)
    const url = window.URL.createObjectURL(response.data);
    const link = document.createElement("a");
    link.href = url;
    link.download = fileName;

    document.body.appendChild(link);
    link.click();

    // Cleanup memory
    link.remove();
    window.URL.revokeObjectURL(url);
  } catch (error) {
    console.error("Axios download error:", error);
  }
}

```

## When Should You Use Which?

* **Use Fetch API if:**
* You want zero external dependencies and zero bundle size additions.
* You are performing simple file transfers where progress bars are not required.
* You are working in a modern browser environment or server-side edge runtimes (like Cloudflare Workers or Deno) where Fetch is native.

* **Use Axios if:**
* You need real-time **upload or download progress tracking** (like user file upload progress indicators).
* You want automatic HTTP error handling (rejection on non-2xx status codes) and request interceptors.
* You are managing authentication tokens, request timeouts, and global headers across a large web application.
